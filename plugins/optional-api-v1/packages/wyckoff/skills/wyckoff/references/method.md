# Wyckoff：量价证据与阶段假设

原著《Studies in Tape Reading》（Rollo Tape，Richard D. Wyckoff 的笔名，约 1910 年）的出版信息由大学图书目录核实。现代 Wyckoff Analytics 教学将 supply/demand、cause/effect、effort/result 用于价量研究。[书目](https://onlinebooks.library.upenn.edu/webbin/book/lookupid?key=olbp91804)；[教学机构原文](https://www.wyckoffanalytics.com/wyckoff-method/)。本包不复制其阶段示意图或原著章节。

## 原创研究程序

1. 先定区间边界、选择依据和最早可得时间。选择后冻结；随价格改动边界时必须记新修订。
2. 分开价格结果（推进、收盘、回撤）与努力代理（成交量及其真实单位）。大量不推进可能有多种原因：对手盘、新闻、被动成交或数据口径，不从形态确定参与者身份。
3. 以阶段/事件作为假设，而非必经循环。每项标签填写价格证据、量证据、缺少的信息、相反解释、后续确认与硬失效。
4. 穿越边界并返回时，先报告实际路径及闭柱证据，再讨论 Spring/Upthrust 候选；这不证明有机构诱导、未成交止损或保证反转。

Composite Man 是解释启发式，不是本数据可观测的人或账户。没有真实成交量时不能做“成交量确认”：tick 是报价计数，unknown 仍未知；可以交付明确缩小范围的价格阶段候选。成交量为手/股、币/合约时不可跨口径直接比较；换算需提供方真实规则。

本包没有自动阶段分类或量价因果检测器。若把阶段用于规则回测，先固定机械定义和人工一致性检查，不能先看收益再选择最合理的标签。
