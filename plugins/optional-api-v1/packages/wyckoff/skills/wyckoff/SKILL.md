# Wyckoff 量价与阶段研究

## 问题与证据

本方法回答“固定区间中的价格推进与成交量是否支持某个阶段候选，以及什么替代解释仍成立”。用户或工作流可根据这个局部问题选择本方法，不要求逐个点名，也不默认加载所有方法。

输入：已有固定价格与量、DataRef、量单位/种类、复权、时段、SourceTime、覆盖、区间边界及确认时间。优先复用调用者已有的固定证据；来源、时间、版本或覆盖存在缺口时，说明它影响哪项结论，并把具体补证需求交回调用者。不要为同一轮方法比较重复获取同一份资料。

## 判读原则

- 实际成交量、tick 计数和 unknown 分开；没有实际量时只给缩小范围的价格结构候选，不把 tick 数或 null 当真实资金量。量的单位和口径不同不能直接比较。
- 区间边界和阶段假设保留选择依据及确认时间。供需、努力与结果是待检验机制，一根放量柱不能确定谁在买卖。
- 阶段和事件不是必经循环。Spring/Upthrust 要有事先固定的边界与返回区间规则，穿越后反向不能直接证明操纵或阶段完成。
- Composite Man 只是启发式；保留普通波动、消息或口径差异等替代解释。缺日历或路径证据不补齐；没有一致分类和样本外验证不声称统计效力。

## 交接与组合

输出：价格事实/量证据/阶段或事件候选对照、替代解释、待确认资料、反证与硬失效条件。向调用者交回本方法的观察、解释、原始引用、反证、缺口和失效条件；可使用 Markdown 表或已有结构，不引入新的必填包壳。不确定、反对或不适用也是有效的局部结论，不为了完整外观补造事实。

price-action 可补价格结构，abu-volatility 可补波动尺度；二者不能补造真实成交量或参与者身份。共享价量上不同阶段标签是相互竞争的解释，不是独立证据。 复用计算时核对输入、参数、时间和实现版本，同源结果不重复计为独立证据。最终综合、补证优先级和报告由调用者负责；方法不会自行发布另一份最终报告或启动交易。
