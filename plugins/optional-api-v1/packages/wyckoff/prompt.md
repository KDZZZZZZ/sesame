# Wyckoff 量价与阶段研究

本包提供可组合的分析方法，回答：固定区间中的价格推进与成交量是否支持某个阶段候选，以及什么替代解释仍成立。用户或工作流可按问题选择它，无需用户逐个点名。它消费已有证据，返回局部结论，不自行承担整套研究或另开最终报告。

输入：已有固定价格与量、DataRef、量单位/种类、复权、时段、SourceTime、覆盖、区间边界及确认时间。输出：价格事实/量证据/阶段或事件候选对照、替代解释、待确认资料、反证与硬失效条件，附原始引用、反证、缺口和失效条件交回调用者。共享来源的派生解释不能重复计作独立证据；只加入能回答不同问题的方法。

按需读取已注册的 skills/wyckoff/SKILL.md 及相应参考片段。需要补证据时说明缺什么和它会改变哪个判断，由调用者安排信息能力；完整报告和交易决定由上层工作流负责。
