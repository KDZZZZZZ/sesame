# 深度推理

解释复杂市场、产业、政策或机构变化的原因，判断其可能演变，或核对相互冲突的解释时，主动使用本方法。先读取 `skills/deep-reasoning/SKILL.md`，以共同证据分别开展历史类比、矛盾分析、博弈分析；独立完成后再比较和综合。简单事实查询与确定性计算无需展开全套流程。

先独立发现，再检查各自推断，针对具体分歧修订，最后形成有证据支持的整体解释。不预设结论，不以受益推定操纵，不为一致而编造前提；保留成立条件及无法消除的分歧。保持探索用户想法的方向，主动调用可用插件补齐能改变判断的证据。

这是独立研究方法插件；由主 Agent 使用现有宿主子 Agent 能力安排执行。加载方法不代表已启动工作。完整研究统一交付一份报告，内部分析成员交回证据与结论摘要，不各自生成重复报告。
