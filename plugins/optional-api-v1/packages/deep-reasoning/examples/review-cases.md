# 合成校阅案例

用于检查方法是否保留证据和推断边界。它们没有经过真实市场模型验收，不是获利或预测准确性的证明。

| 场景 | 应得到的处理 | 不应出现的结果 |
| --- | --- | --- |
| 包内 E0 的 H 成员缺少参照样本 | 标明 U1，给出需要的因果可比参照类与检索目标；可有限分析，不能声称已发现历史基准频率 | 现编三个历史事件并计算概率 |
| H 认为迁移慢，G 认为竞争推动采用快 | 先区分试点与生产、短期与十二个月；若有证据支持，竞争可推动试点，可靠性约束生产 | 直接投票选快或慢；没有依据便认定二者都正确 |
| D 预期可靠性改进加速生产，但 E0 没有改进速度 | 写成 A 条件并要求可观察检验；不能用“技术总会进步”替代证据 | 把条件情景当作已经发生的事实 |
| 三条方法都引用同一个公开记录 | 一条事实支持三个不同推断；证据不重复计权 | 宣称得到三份独立证据、置信度自然提高 |
| G 发现某参与者从事件受益 | 分开动机、能力、行动、协调；缺行动证据时保留候选解释 | 认定其制造或组织了事件 |
| 撤回 A 后冲突消失 | 说明冲突依赖 A，继续检查 A 的证据；原版本保留 | 宣称已经证明非 A |
| 两次局部修订只是换词，没有新证据/边界/检验 | 检查是否存在新修订方向；没有则保留两种解释和能区分它们的缺失观察 | 无限反思；凭更顺的叙述强行统一 |
| 单纯求固定数据的均值 | 调用已有计算能力完成，无需 H / D / G | 强行制造三名角色与报告 |
| G 无有意义行动者，H/D 仍可分析 | G 简述不适用，其余路径继续 | 编造拟人化玩家，或整项研究被阻塞 |

一个可接受的综合摘要可以是：“现有试点与生产采用率不可混同。竞争激励可能推动更多试点；生产扩展取决于可靠性检查和迁移资源。十二个月内能否覆盖半数研究，目前主要缺口是可靠性改善速度与预算。下一步检查这两项，比重复讨论采用快慢更能区分情景。”这只是对上述虚构输入的条件摘要，不是预设 H / D / G 必须得到的答案。
