# 深度推理

独立插件 `sesame/deep-reasoning`，版本 1.0.0，API 2。用于解释复杂现象为什么形成、下一步可能怎样演变，以及不同机制解释为何冲突。

可直接向 Sesame 提出：“用深度推理分析这次市场变化的原因与接下来可能的演变。”Agent 发现并加载本插件后，从共同证据出发独立使用历史类比、矛盾分析、博弈分析，针对实质分歧复核，再形成综合判断。

## 输入与交付

输入是研究问题、可观察结果、范围、时间与现有证据。Agent 根据上下文整理，并通过当前可用的数据和搜索能力补齐。输出包括直接回答、关键证据、机制、条件情景、未解备选及下一项可区分观察。完整研究交付一份统一报告；内部分析阶段向调用者交回结果。

## 包的职责

- 功能分类为业务流程中的研究方法，实施形式为知识文档。
- prompt 提供触发条件与关键原则；SKILL 提供执行路线；references 按角色和阶段读取。
- 独立安装、挂载和发现，不依赖 Investment Research 或 orchestration 包，也不修改它们。
- 由 Agent 调用已有 `host.agent.run` 等工具实际并行；本包没有新的执行工具、后台调度器、行情连接、密钥或下单能力。加载不会自行启动研究。
- 研究资料与报告使用已有公开能力，按具体任务授予；插件本身不新增权限或配置。

## 本地安装

使用 `sesame/plugin-manager` 的 `plugin_install({path})` 安装本包，再 `plugin_load({pluginId:"sesame/deep-reasoning"})` 加载当前会话。已有安装用 `plugin_update` 并提供实际 `expectedRevision`。宿主在安装时检查包与声明。

包内 examples 全部为合成教学材料，不作为真实市场研究输入。来源与使用授权记录在 [PROVENANCE.md](PROVENANCE.md)。
