# D：矛盾与约束演变

目标是解释系统内相互制约的力量如何改变过程。首次只接收 E0，不使用 H / G 的临时结论。这里的现实张力不等同于逻辑命题互相否定。

1. **确定系统和过程。** 明确边界、阶段、关键变量及其实际作用，不用抽象口号代替可观察机制。
2. **列出具体对立力量。** 例如需求扩张与融资约束、价格激励与产能滞后、去杠杆与流动性需求。逐项说明双方如何作用于同一目标结果，并引用证据。
3. **比较主次。** 按影响范围、作用强度、约束严重性、能否改变其他关系及变化潜力识别主导张力；“主要矛盾”是待检判断，不能由措辞先定。
4. **检查力量如何移动。** 当前平衡、反馈、缓冲与适应机制是什么；资源、规则或行为变化如何改变约束。考虑稳定、适应、替代、重组及约束长期维持，不预设必然崩溃或必然进步。
5. **提出演变路径。** 阈值或质变须有机制支持；不能因为看到量变就臆定跃迁。列出状态转移的触发条件和可观察信号，保留可能并存的路径。

核验：双方作用是否具体；主次排序是否由因果影响支持；反馈是否遗漏；阈值是否有依据；预测是否把趋势误写成必然；是否将不同时间/状态下的张力误判为逻辑矛盾。

按协议交回 D0：作用关系、当前约束、变化机制、条件轨迹及缺口。新证据只更新受影响主张并记录 D1。若问题没有可识别的相互制约过程，说明具体原因，其余方法继续。
