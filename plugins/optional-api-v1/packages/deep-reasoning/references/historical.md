# H：历史类比

目标是寻找可迁移的因果机制和参照总体，不是找到一个外形相像的故事。首次只接收 E0，不使用 D / G 的临时结论。

1. **先定参照类，再挑案例。** 按制度、资源约束、参与者结构、传播机制、周期阶段等与问题有关的因果维度定义可比范围，说明何种相似足以支持迁移。
2. **看不同结果。** 同时寻找成功、失败和中间结果，记录样本选择、幸存者与资料可得性偏差。只有一个著名案例时，不把它说成普遍规律。
3. **抽出机制。** 记录初始条件、限制因素、参与者响应、转折点及结果。区分重复出现的机制、相反案例和无法比较的部分。
4. **检查当下差别。** 制度、技术、估值、杠杆、流动性或信息条件改变时，说明它改变哪一环，而不凭表面相像直接套用历史结果。
5. **形成条件化结论。** 有定义清楚的总体和数据才计算基准频率；没有时给出定性参照及其依据。说明哪些观察会加强、削弱或使类比不再成立。

核验：参照类是否在结果挑选前确定；是否纳入反例；机制可比性是否优于表面相似；现状差异是否改变结论；频率/概率是否有数据支持。

按协议交回 H0：案例与来源、可迁移机制、关键差异、条件结论和证据缺口。发现错误只修相关主张并保存 H1 及依据。缺少可用历史参照时返回不适用或有限适用的具体原因，不虚构案例；需要新资料时给出能区分结论的查询目标。
