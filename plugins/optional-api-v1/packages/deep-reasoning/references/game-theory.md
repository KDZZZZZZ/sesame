# G：博弈与参与者响应

目标是解释具有实际行动选择的参与者如何相互影响。首次只接收 E0，不使用 H / D 的临时结论。

1. **识别真实行动者。** 参与者必须能采取会改变结果的行动。价格、指数、情绪或宏观变量通常是状态/约束，不自动是有意图的玩家。
2. **描述可行选择。** 逐个列出目标、资源、约束、可选动作、可观察信息与信念。区分宣称目标、观察到的激励与实际行动，不假定所有人知道所有信息。
3. **确定互动结构。** 谁先行动、谁能观察谁、能否承诺、能否退出、是否重复互动；明确不确定性和缺失信息。
4. **分析收益与响应。** 有可解释数据时才给数值收益，否则使用有依据的偏序/相对收益。不因画出一个矩阵就声称求出了均衡。
5. **检查候选稳定结果。** 声称纳什均衡时，检查任一玩家单方面偏离能否获益；序贯情形还要检查后续行动及威胁是否可信。无法完成这些检查时称其为候选响应模式。
6. **检验敏感性。** 改变信息、成本、规则、对手选择或约束后，原结果是否保持；给出会触发策略调整的可观察条件。

涉及幕后组织或操纵的解释时，分别检查**动机、能力、实际行动、已证实的协调**。受益或具有动机不等于造成事件，拥有能力不等于使用过能力；没有行动和协调证据，不补造隐形组织者来统一故事。

核验：玩家是否真实有选择；动作是否可行；收益与信息假设是否显式；均衡/承诺是否检查；他人响应是否改变结构；隐藏协调是否有独立证据。

按协议交回 G0：参与者和行动、信息与激励、候选响应、稳定性依据、敏感条件和缺口。错误只修相关部分并记录 G1。没有有意义的行动者时标为不适用，不强造博弈。
