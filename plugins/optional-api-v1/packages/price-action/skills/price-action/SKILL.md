# Price Action 价格行为

## 问题与证据

本方法回答“当前价格更符合哪一种趋势或区间结构，以及什么闭柱观察会削弱该判断”。用户或工作流可根据这个局部问题选择本方法，不要求逐个点名，也不默认加载所有方法。

输入：已有固定行情或已确认摆动/突破结果、价格基础、周期、复权、SourceTime、覆盖、摆动窗口和收盘/影线定义。优先复用调用者已有的固定证据；来源、时间、版本或覆盖存在缺口时，说明它影响哪项结论，并把具体补证需求交回调用者。不要为同一轮方法比较重复获取同一份资料。

## 判读原则

- 趋势/区间属于候选判断还是可执行规则要明确；摆动、突破和失效定义可复核。“看起来明显”不能替代规则，单根大柱也不能替代上下文。
- 本包脚本用左右窗口的严格极值确认 pivot，再观察最新已确认 pivot 的首次收盘越界；它不识别完整 Brooks setup、自动判断市场状态或输出交易建议。
- 事件位置与 confirmed_at 分开，右侧柱不足时不能确认；高周期未闭合时不能拿它证明低周期信号。最早确认时间仍不等于实际收到数据或成交时间。
- 同柱 OHLC 不能恢复盘中先后顺序。人工边界和候选保留首次标注、反证及修订；作者经验概率不是本市场已校准概率。

## 交接与组合

输出：带源引用的推进/重叠/回撤观察、趋势/区间候选、确认时间、相反解释和失效条件。向调用者交回本方法的观察、解释、原始引用、反证、缺口和失效条件；可使用 Markdown 表或已有结构，不引入新的必填包壳。不确定、反对或不适用也是有效的局部结论，不为了完整外观补造事实。

abu-price-structure 可提供同窗口的摆动参考，abu-trend/abu-volatility 可补方向效率或波动尺度。只有规则、数据版本和确认时点匹配才复用；不同判据不强行合并，同源指标也不作为独立确认票。 复用计算时核对输入、参数、时间和实现版本，同源结果不重复计为独立证据。最终综合、补证优先级和报告由调用者负责；方法不会自行发布另一份最终报告或启动交易。

TR/ATR 数值使用 `abu_volatility_analyze` 或 `abu_indicators_analyze`，已有同输入同参数结果可直接引用。日线日期保留 YYYY-MM-DD，历史可用时间未知则 available_at 留空或 null；从结果取 true_range、atr、atr_percent。TR 包含相对前收盘的跳空，首柱没有前收时为 null，N 日简单均值需要 N+1 根输入；不能把单柱高低差当作完整 TR。计算能力负责数值，本方法负责解释它与结构、失效条件的关系。
