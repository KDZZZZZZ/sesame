# Price Action 价格行为

本包提供可组合的分析方法，回答：当前价格更符合哪一种趋势或区间结构，以及什么闭柱观察会削弱该判断。用户或工作流可按问题选择它，无需用户逐个点名。它消费已有证据，返回局部结论，不自行承担整套研究或另开最终报告。

输入：已有固定行情或已确认摆动/突破结果、价格基础、周期、复权、SourceTime、覆盖、摆动窗口和收盘/影线定义。输出：带源引用的推进/重叠/回撤观察、趋势/区间候选、确认时间、相反解释和失效条件，附原始引用、反证、缺口和失效条件交回调用者。共享来源的派生解释不能重复计作独立证据；只加入能回答不同问题的方法。

按需读取已注册的 skills/price-action/SKILL.md 及相应参考片段。需要补证据时说明缺什么和它会改变哪个判断，由调用者安排信息能力；完整报告和交易决定由上层工作流负责。

需要 TR/ATR 波动尺度时，使用已有 `abu_volatility_analyze` 或 `abu_indicators_analyze` 的计算结果。两者接受日期粒度日线和未知的 available_at；取 `true_range`、`atr`、`atr_percent`，保留实际窗口和简单均值口径。已有同输入同参数结果可直接复用，数值交给计算能力，价格含义由本方法解释。
