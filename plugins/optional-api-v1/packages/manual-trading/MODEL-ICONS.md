# Collaboration model icons

`assets/collaboration-icons.js` bundles static SVG path data for the collaboration UI model badges. The file exposes `window.SesameModelIcons.create(task)`, `window.SesameModelIcons.update(container, task)`, and `window.SesameModelIcons.resolve(task)`.

The bundled brand marks are copied from `@lobehub/icons-static-svg` version `1.95.1`, package `@lobehub/icons-static-svg`, repository `https://github.com/lobehub/lobe-icons`, license `MIT`.

Bundled slugs:

- `openai.svg`
- `claude.svg`
- `gemini.svg`
- `grok.svg`
- `deepseek.svg`
- `qwen.svg`

The neutral generic icon is local Sesame UI artwork, not a provider or model logo.

These icons identify model providers in the UI. Brand names and trademarks remain the property of their respective owners.
