# 研究决策与失败证据

把实验拆成数据/信号、目标仓位、风险、执行、状态恢复与结果引用；每一层写明确依赖和未知。
执行细节留给选定引擎，语言语义留给 strategy-authoring，不把某个平台模板当所有策略的结构。

| 风险 | 最少可复查证据 | 缺失时 |
|---|---|---|
| 前视/修订 | 字段实际 available-at、历史快照与发布版本 | 仅描述；不声称可交易历史 |
| 幸存者/退市 | 当时成分、退出样本、退市收益处理 | unknown；不要删掉缺失尾部 |
| 复权 | 价格/收益基准、因子 as-of、分红拆并股映射 | 不与原始成交价格混用 |
| 选择偏差 | 全部候选、方向、参数及失败账本 | 不计算假装完整的 DSR/PBO |
| 归一化/训练 | 每折仅训练拟合的参数及冻结源码 | 不用全样本统计量 |
| 成交与费用 | 下一可成交时点、滑点、费用、借券、停牌与容量 | 因子诊断不是实际净收益 |
| 样本外污染 | 冻结选择的时间/引用和预留数据摘要 | 见过后算验证集，另留真正新样本 |

先声明主要评价、基准和预算，再看结果；优化只花已授权预算。发现数据缺口先查真实可用
来源/后端，授权内复用或安装所需包；找不到就缩小研究问题，不能生成数据冒充。
多重检验不靠一句风险提示解决：保留所有试验，限制搜索，冻结选择，公开负结果和完整样本外；
统计显著性仍未证明。要做独立的 DSR/CSCV 分析时保留全部试验收益矩阵并核对原论文假设，
不把这些统计方法强加给只需简单实验的用户。

来源与许可见包根 `PROVENANCE.md`。这份流程和 CLI 为 Sesame 原创，未复制上游 GPL skill。
