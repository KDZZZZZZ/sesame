# 从问题到可复查的实验

目标是回答一个可检验问题：什么机制、在什么标的/期间/成本约束下优于何种基准，哪些证据会推翻它。
按缺口选择工作，不把下面的证据要求当成必须顺序执行的脚本。

用户明确要求“最大努力”“最大功率”“全力”或“高强度”研究时，发现并使用匹配的可执行工作流；
本知识指南不能代替实际工作流入口。明确要求“轻量研究”或“快速研究”时，主 Agent 可以直接
使用相关能力，不强制工作流或委派，研究报告要求仍然适用。

一般复杂研究按需委派独立或专业阶段，为每个阶段提供问题、输入证据、允许调用的能力、完成条件与报告
目的地。每个交付阶段都要实际生成并发布报告；数据量大或复杂的分析任务同样需要报告，
日常问答则可直接回答，不强制报告或拆任务。子 Agent 负责完成被分配的阶段，不默认递归
委派；工作流内部成员交接局部成果，由指定综合者发布阶段报告。

策略设计、因子组合、参数优化和回测验证的交付阶段声明
`output:{type:"report",space:"strategy",path:"策略回测报告.html"}`；市场走势、宏观和资料研究使用
`space:"research"`。用户明确指定的目录优先；工作流使用宿主调用选项 `task.output`。
未绑定任务的新报告发布时传 `report_publish.space:"strategy"`，不靠标题或 SVL 引用猜分类。
报告负责 Agent 获授 reports 的模板、
发布、渲染核验和读取能力，以及所需的 workspace 写作与固定数据读取能力，遵循统一视觉规则。
阶段结束要核验实际文件路径、发布状态与精确修订的 rendered 回执；固定数据和聊天总结不
代替报告，Run completed 本身不证明报告已交付。

独立阶段可并行启动。没有独立工作时，主 Agent 告知已启动的研究后结束当前回复，空闲等待
宿主完成通知，无需反复轮询。通知到达后简报阶段发现、主要边界和报告位置；若已有任务
授权内还有有价值的下一阶段，先实际启动再说明正在进行什么，不能把计划说成进行中。
没有有效下一步时收束本轮，用户明确的暂停、取消和范围仍有效。

来源层负责实际数据与固定引用，方法层负责具体解释/计算，本包负责实验比较和综合。用户未限定
方法时，可组合各有作用的方法，例如结构假设与成本/风险检验；不要求遍历全部理论。复用相同的
冻结输入与已有结果，只对缺失、过期或矛盾的事实补取证。同源指标、同样本和多个角色赞同不能替代
独立验证；结果分歧应归因到假设、输入口径或参数。

完整来源证据保留 schema、单位、时钟、coverage、复权、退市和历史成分，财报采用当时首次可得版本。
unknown/unavailable 留在结论中，不用现今成分或事后修订回填。方法产物带输入 DataRef、方法/版本、
参数、事实与条件解释、反证和边界，供下游直接消费；无需为每种方法另生成报告，阶段报告
由负责交付的子 Agent 或工作流综合者统一发布。

可比较的实验固定计划、数据/源码摘要、参数、成本和引擎版本。特征可得时间不晚于决策，标签末端及
可得时间不越过切分/隔离边界；滚动前推每折只用其训练窗口拟合。选择在开发集完成后固定，再作声明的
样本外评估；已经看过的样本不再称未触碰。尝试、失败、取消及未知均保留，未知的原生操作需对账而非重放。

策略表达由 strategy-authoring/SVL 或明确的原生源码承接，成交、费用和市场约束由已选真实引擎验证。
不能无损表达时标明 unsupported；方法诊断不证明回测或执行等价。因子问题可复用 factor-research，
实际计算使用已选 evaluator，避免重复实现。缺必需能力时保留已有成果并说明恢复条件。

本包无注册函数。若需要结构/时点/账本检查，可用公开 `scripts/experiment.mjs` 参考资源，精确输入见
`skills/strategy-research/references/execution.md`；证据解释见 `references/evidence.md`。通过
`plugin_read({pluginId:"sesame/strategy-research",part:"resource",path})` 读取声明路径，执行走既有 workspace 能力。
这是可选检查，已有等价的真实回执可复用；CLI 不核实外部历史，也不能发现被隐藏的试验。

综合结果说明相对基准、成本敏感性、回撤、换手/容量、稳定性及负结果。DSR/CSCV/PBO 不是本包工具，
需完整试验矩阵和满足假设的独立实现。最终成果引用固定数据/引擎回执，区分 observed、derived、demo，
并说明哪些方向应停止、哪些值得进一步验证；负责交付的子 Agent 或工作流综合者通过 reports
发布阶段报告并核验交付。研究通过不授权实盘操作。
