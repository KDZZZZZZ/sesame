# 自主策略研究

仅在用户需要策略实验设计、优化或验证时加载本包。先读
`skills/strategy-research/SKILL.md`。把研究写成可反驳假设、固定输入、有限试验预算、
真实引擎证据与未碰过的样本外检验。默认不选择任何技术理论或因子模型。

本包没有额外核心工具；用已安装的 data-access、workspace、strategy-authoring、
选定回测后端和 reports。缺后端时先查真实 provider 与 `plugin_catalog`，在当前任务
授权内安装需要的一种，不自动装全部。因子任务才单独加载 `sesame/factor-research`。
开发目录是否已发布、具体版本与摘要以实际目录查询为准。

不要把研究诊断当收益、可执行性或 SVL 目标等价证明。已看过的样本外数据不能再叫
未触碰留出集；不能隐藏失败试验，或因一次验证失败无限搜索到“通过”。
