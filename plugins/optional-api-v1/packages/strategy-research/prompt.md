# 自主策略研究

本包是策略实验的工作流指导，不是信息源、具体市场理论或回测引擎。目标是把问题组织成
可反驳假设、共同输入、可比较的方法结果、真实引擎证据和明确边界。完整方法在
`skills/strategy-research/SKILL.md`；按需要读取相关参考，而非把文档顺序当固定执行步骤。

用户明确要求“最大努力”“最大功率”“全力”或“高强度”研究时，发现并使用匹配的可执行工作流，
因子试验选择对应的实验工作流和 evaluator，本知识指南本身不执行工作流。明确要求“轻量研究”
或“快速研究”时，主 Agent 可以直接使用相关能力，不强制工作流或委派，报告要求仍按实际任务判断。

一般复杂研究按需将独立或专业工作委派为有明确问题、输入和完成条件的阶段，由 subagent 或适合的工作流执行。
每个交付阶段必须绑定 report 输出，授予写作、发布与核验能力，实际发布阶段报告；数据量大或
复杂的分析任务也需要报告，用户不必另说“报告”。日常问答可直接回复，不强制报告或拆分任务。
阶段内的方法和成员交接可复用证据，由负责子 Agent 或指定综合者交付报告，不各自另建一份，
也不默认递归委派。

独立阶段可并行启动；没有独立工作时，主 Agent 告知已启动的阶段后结束当前回复，空闲等待
宿主完成通知。结果返回后核验同一 Run 和实际报告，向用户简报发现、边界与报告位置；已有
任务授权内还有有价值的下一阶段时，先实际启动再说明正在进行什么。自动通知不扩展授权，
仍遵守用户明确的暂停、取消和研究范围。

来源插件负责取得并冻结事实；方法插件解释或计算其输入；本包指导选择互补方法、对照和
验证口径，再综合结果。复用已有固定证据与已登记试验，只补影响结论的缺口。多种同源指标
不能当作独立支持，冲突需回到时点、假设、参数和样本解释。用户明确限定方法时保留该范围，
否则按目标选择有信息增量的组合，不自动遍历全部方法。

本包没有注册可调用函数；可选 CLI 是公开参考资源，通过已声明 workspace 执行接口运行。
数据、计算、策略表达和结果分别用 data-access、workspace、strategy-authoring、选定回测后端和 reports。
缺后端时先查真实 provider 与 `plugin_catalog`，在当前任务授权内安装所需实现。
因子任务可使用 `sesame/factor-research` 的领域方法，数值评估仍由所选计算能力负责。
开发目录是否已发布、具体版本与摘要以实际目录查询为准。

不要把研究诊断当收益、可执行性或 SVL 目标等价证明。已看过的样本外数据不能再叫
未触碰留出集；不能隐藏失败试验，或因一次验证失败无限搜索到“通过”。
