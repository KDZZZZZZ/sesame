# 度量与研究边界

Rank IC 是每个同一决策截面的 Spearman 相关：相同值取平均秩；任意一边常量返回 null，
不以零替代。均值与样本标准差按有效时点给出，不年化、不假设 IID、不输出显著性。
冗余只在训练样本按同时有值的标的算各因子方向修正后的秩相关，再报告有效期数和均值。
没有行业/规模数据时不伪称做过中性化；不能只因冗余低就认定增量 alpha。

组合诊断每个不重叠标签期从空仓开始：高尾等权总 +0.5、低尾等权总 -0.5，gross exposure=1。
每侧目标个数 `max(1,floor(n*tailFraction))`；跨尾边界的整组同值不靠股票代码排序选一半。
任一侧空或重叠则 no portfolio，仍保留可计算 IC。至少 minAssets 个有值标的才计算。
每期毛收益 `0.5*mean(high returns)-0.5*mean(low returns)`，扣
`2*oneWayCostBps/10000 + 0.5*borrowBpsPerPeriod/10000`，即固定进出费用和每期空头借券假设。
这个成本不是实测冲击，不随实际换手/流动性自适应，不假装每期真实可成交。

curve 保留全部时点/覆盖状态；累计值仅复合可计算期，跳过的时期没有推造持仓收益。
valid period 数必须同报告；任何净期收益 <=-1 则累计值为 null，不继续负资产复利。
无风险利率、频率、资金、保证金和交易规则未定义，所以不产原生 Sharpe/账户权益/成交收据。
要判断实用性，冻结具体策略，在选择的真实引擎补上成本、停牌、涨跌停、卖空、撮合延迟与容量。

数据处理必须在评估之前解决：

- 用当时可得的历史成分和财报 vintage。只有报告期日期而无公布/修订时点的字段不可用于 PIT 声明。
- 停牌/不可得字段是 unavailable；退市收益和最后交易不得因数据缺尾被丢弃。缺失不可用零填。
- 记录 raw/split/total-return、拆分红利因子以及 as-of。事后重算的全部前复权价格未必当时可见。
- 标签窗口与训练/验证边界重叠需要 purge，后续间隔按事先定义的 embargo；全样本 winsorize、
  标准化、权重/方向选择同样是泄漏。多期限研究逐一计数，不把多个重叠 horizon 当独立样本。
- 不以 OHLCV 相关推出因果，不承诺收益。要用 Qlib/Alpha158、因果、遗传或其它特定模型，
  用户先选择该方法，另验证实现和依赖；本包没有这些执行器。

所有试验（含失败与人工筛选）要进账本。一个留出成功不抵消多重搜索；本版明确输出
`statisticalInference: not_performed`。DSR 需要额外试验分布/有效独立次数等，CSCV/PBO需要
完整候选收益矩阵及适当切分，输入不足就不算。统计假设需单独说明，不以曲线漂亮替代。
