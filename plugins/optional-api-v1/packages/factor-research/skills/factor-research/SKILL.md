# 因子创意到固定证据

目标是形成可反驳候选，并用真实计算区分数据不足、机制失效和仍值得检验的方向。本包是因子研究流程指南，
组织候选、评价、选择与样本外检验；具体理论提供局部解释，来源插件交付固定证据，计算/evaluator 交付实测结果。
调用工作流选择整体任务目标与信息范围。加载本指南不会启动团队、获取外部信息、注册数值函数或独立发布报告。

候选说明机制、反证条件、输入及单位、表达式、方向、窗口、available-at 和来源引用。用户明确限定的
方法范围继续有效；未限定时按目标选互补方法，解释各自信息增量，不自动堆叠全部理论。同源特征变换、
相同样本与相关因子不是独立支持。复用已有固定 DataRef 与计算回执，只有具体缺口才交来源层补证。

时点证据要求特征和成分在决策时已知，标签随后发生；不能用未来 shift、全期拟合或最终修订财报。
保留历史成分、退市、复权和公告版本；SourceTime 转 UTC 需有时区/authority/fold 依据。OHLCV 不能
推造财报、资金流、订单簿、借券或机构身份。未知字段直接影响适用性，不能靠删行或填零包装为有效样本。

评价由选定数值实现负责。已注册 factor-evaluator 的候选协议、门槛和实测回执可直接消费；不再另外
执行 CLI 重复同一评价。评审结合开发集 rank IC、覆盖、训练相关性、成本和反证，区分数据质量与因子优劣。
方法结论保留 evaluator/方法版本、输入引用、参数和失效条件；回执中的 eligibility 不代表未来盈利。

本包可选 `scripts/factor.mjs` 仅比较输入中的明确因子列，不执行 definition 文本。精确输入见
`skills/factor-research/references/execution.md`，方法解释见 `references/method.md`，来源见 `PROVENANCE.md`。
用 `plugin_read({pluginId:"sesame/factor-research",part:"resource",path})` 读取公开资源，再经已授权 workspace
运行。采用此 CLI 时，screen 读开发集，select 固定选择，holdout 只算选定因子；这种顺序源于防泄漏条件，
不是要求所有因子任务都走本地文件流程。

开发集用于选择，样本外仅检验冻结选择；已暴露数据不再称未触碰。每次表达式、窗口、方向或样本变化
保留在试验账本，失败、缺失、常量与负结果也计入。CLI 只有描述性统计，没有 p 值/DSR/PBO；正式推断
需要满足假设的实现与完整试验矩阵。组合拟合仅用训练段，本包不自动拟合权重、归一化或中性化。

交给上层工作流的是候选/方法、输入引用、真实指标、反证及局限。strategy-authoring 与真实引擎负责
策略表达和成交约束，简化 long/short 曲线不等于券商权益。最终报告由上层统一综合；strategy-research
可指导实验流程，judgment-evolution 可跟踪前瞻判断，两者各有独立责任。
