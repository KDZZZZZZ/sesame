# 因子研究

本包提供从候选假设到固定样本外检验的因子研究流程指南，不是局部理论知识、数据源或独立数值评估服务。完整流程在
`skills/factor-research/SKILL.md`。用真实可得字段形成候选，明确机制、表达式/方向、
可得时点和反证；按问题组合有互补作用的方法，用户明确限定的方法范围仍有效。

复用来源层冻结的数据与计算层返回的真实指标，保留输入引用、单位、时点及参数。
同一字段变换或同样本得分不算独立验证；新增方法要说明信息增量，结果分歧从机制、
时间口径和相关性解释。本指南组织候选、评价、选择与样本外检验；调用工作流决定整体任务范围和综合结论，不因加载指南另建团队或报告。

本包没有注册可调用函数。可选 CLI 参考资源通过 workspace 执行，比较调用者提供的因子值；
它不执行任意表达式，不发明不可用特征。使用已注册 factor-evaluator 时，遵循其数值契约，
复用其回执，不再运行本包 CLI 复制一套评价口径。
开发筛选→固定选择→单次声明的样本外检验分开。成本后的组合诊断仍非原生回测，交由已安装
的选定引擎验证成交约束。数据、SVL、报告和记忆复用核心插件；本包不会复制这些工具。
