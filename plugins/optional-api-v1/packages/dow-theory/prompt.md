# Dow Theory 趋势确认

本包提供可组合的分析方法，回答：预先定义的主要/次级趋势是否得到两个指数各自收盘的共同确认。用户或工作流可按问题选择它，无需用户逐个点名。它消费已有证据，返回局部结论，不自行承担整套研究或另开最终报告。

输入：各指数已有固定行情、成分与复权口径、SourceTime、真实闭市时间、次级反应锚点及判定版本；缺一指数只能做有限单序列描述。输出：各指数确认时间线、已声明极值规则、confirmed/non-confirmation/insufficient-data 状态及撤销条件，附原始引用、反证、缺口和失效条件交回调用者。共享来源的派生解释不能重复计作独立证据；只加入能回答不同问题的方法。

按需读取已注册的 skills/dow-theory/SKILL.md 及相应参考片段。需要补证据时说明缺什么和它会改变哪个判断，由调用者安排信息能力；完整报告和交易决定由上层工作流负责。
