# Dow Theory 趋势确认

## 问题与证据

本方法回答“预先定义的主要/次级趋势是否得到两个指数各自收盘的共同确认”。用户或工作流可根据这个局部问题选择本方法，不要求逐个点名，也不默认加载所有方法。

输入：各指数已有固定行情、成分与复权口径、SourceTime、真实闭市时间、次级反应锚点及判定版本；缺一指数只能做有限单序列描述。优先复用调用者已有的固定证据；来源、时间、版本或覆盖存在缺口时，说明它影响哪项结论，并把具体补证需求交回调用者。不要为同一轮方法比较重复获取同一份资料。

## 判读原则

- 明确采用 Hamilton/Rhea 传统的哪项操作约定。次级反应的选择规则、锚点、已知收盘极值和确认时间在判读前确定，不能按后续走势重选。
- 收盘越过按每个市场真实闭市时刻判断；盘中影线不是日收盘。两序列不按数组位置对齐；不同日期可先后确认，共同确认不能早于较晚的信息可得时间。
- 单边新高/新低或未越过只支持 non-confirmation，不能直接翻转主要趋势。三阶段心理故事属于解释标签，不是参与者动机证据。
- 替代传统 averages 时说明成分、市场覆盖、制度差异与改编规则；沿用的历史收益不能充当新组合的验证。保留反证和撤销条件。
