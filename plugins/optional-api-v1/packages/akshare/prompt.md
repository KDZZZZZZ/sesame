AKShare is optional and read-only. Mount sesame/akshare, call akshare_discover with configured Python first (or offline akshare_status). Compatible existing AKShare is reused readonly; explicitly call akshare_prepare only when no compatible existing dependency is available. Never install globally or during startup. akshare_catalog lists a small whitelist, sources, units and fixed connection versions. Use the generic sesame.market provider for paged A-share instruments and daily history. No subscribe capabilities, realtime claim, accounts or order placement. Network errors remain errors; never fabricate data or silently switch upstream.
