---
name: akshare-research
description: Prepare optional AKShare and obtain source-labelled A-share research data through tools or generic market history.
---
1. Discover/mount exact plugin id `sesame/akshare`. `akshare_discover` first verifies a configured existing Python with real AKShare import/version (or checks native candidates). `akshare_status` is offline. Reuse a compatible existing environment readonly; never upgrade or write it. Only if no compatible existing AKShare is available, call `akshare_prepare` explicitly; it creates a persistent plugin-data venv, pins AKShare 1.19.1, records resolved package URLs/SHA256/version receipts and runs pip check. Requires native 64-bit Python >=3.11; a bundled Linux guest executable cannot run directly on macOS.
2. `akshare_catalog` discovers supported read-only interfaces. `akshare_query` accepts only stock_zh_a_spot_em, stock_info_a_code_name, stock_zh_a_hist and stock_zh_a_daily, with declared string arguments. No arbitrary code, authentication secrets, trade/order APIs or realtime streaming.
3. Bind generic market provider `{pluginId:'sesame/akshare',providerId:'market'}` with configuration `{source:'eastmoney'}` or `{source:'sina'}`. Persist returned exact connection id/revision. Search instruments and use their actual sourceId/instrumentId; never infer an exchange for an unsupported code.
4. `queryBars` supports spec `{timeframe:'1d',priceBasis:'last',adjustment:'none'|'qfq'|'hfq',session:'regular'|'all',calendarRevision:{status:'unknown'}}`. Give explicit Asia/Shanghai wall SourceTime or UTC range. Daily bars represent aggregate 09:30–15:00 exchange sessions; pinned calendars and gap completeness are unavailable. Eastmoney quantity unit is lot (100 shares), Sina is share. Do not call tick volume real volume or multiply without an explicit unit conversion.
5. Drain `page:{limit,cursor}` using returned opaque cursor under the same binding/filter snapshot; cursors expire in 5 minutes. Keep source metadata, adjustment and observedAt. Upstream float values converted to decimal strings preserve supplied numeric values, not lost source precision.
6. Network/blocked-source errors are not empty datasets or fake quotes. If selecting another upstream, state the change and create its distinct binding. No streaming chart capability is declared; use history/read-only research results, not a realtime monitor. Research data use remains subject to upstream terms.
