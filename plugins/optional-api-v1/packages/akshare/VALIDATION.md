# AKShare 1.0.5 time-basis correction — 2026-10-10

The published 1.0.4 instrument description declared `zone: Asia/Shanghai`, but binding metadata and daily bar open/end times omitted it. An unchanged data-access 2.3.0 `market_read` rejected a range copied from that description with `INVALID_PROVIDER_DATA`. A real temporary Store + ProviderRegistry + HostContext + ContractArtifacts fixture reproduced this error before the patch; its worker returned controlled source rows, not live market observations.

Version 1.0.5 uses the same known Shanghai authority and zone in bind/search/describe, canonical daily bars, UTC-range responses and daily subscriptions. Legacy wall ranges omitting zone at both ends receive a non-mutating response projection after canonical revision calculation; the authority/time values, bar IDs and revisions remain unchanged. Bar-response `meta.source.timeBasis` and a warning preserve the known zone in retained evidence. Different clocks/zones and DST folds remain rejected. Independent review additionally reproduced an old fixed +08:00 conversion error for a July 1991 UTC query. The patch now uses the declared IANA zone, preserving historical DST and milliseconds. A later review finding also reproduced UTC endpoint wall-string reversal across the September 1991 rollback. UTC order, duration and filtering now compare original bounds with uniquely resolved source-bar instants, without choosing a fold. The host and data-access validator were not changed.

The final targeted run passed all 24 checks (including three host integration subtests): all 15 existing provider/environment checks, canonical metadata for three sources, zoned/zoneless immutable pagination and unchanged revisions, UTC/subscribe consistency after legacy reads, explicit mismatch rejection, historical 1991 Shanghai summer/standard offsets, millisecond half-open boundaries, UTC ordering across repeated/reversed rollback clocks and spring-forward, and rejection of ambiguous/nonexistent mixed wall boundaries, and actual data-access 2.3.0 publication of fixed DataRefs/datasets for zoned, zoneless and UTC inputs through temporary real host ports. Identical operation retries retained their references without another worker call; temporary bindings and provider snapshots were released. Decimal values and units were preserved. This is not a full Runtime/Agent/UI or upstream networking test. No dependency preparation, native terminal, credential access, trading or live application state was involved.
