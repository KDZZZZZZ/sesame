# 交易结果诊断

用 `abu_trade_metrics_analyze` 汇总给定权益与已结束交易的收益、回撤、风险和成本，解释数值对应的统计口径。

用 `abu_trade_results_audit` 审计已给出的订单/成交：先后顺序、未知订单、标的不一致、限价、超量成交、未成交与显式成本。它不要求权益曲线，bars也可省略；输入异常是待解释的审计结果，不代表已经重建策略或撮合。两个能力均只计算本次输入，独立返回固定输入和结果引用。

原生 MT5、Backtrader 或 vnpy 负责实际运行已编写交易规则。此包可诊断其真实输出或其它固定交易记录，不再次执行引擎。factor-evaluator 的理想化因子组合诊断不能替代真实交易绩效；审计通过也不能当作策略有效性或成交真实性证明。

CAGR 使用实际日历时长，Sharpe 使用声明的年内期数。资金进出和权益调整会改变收益解释，不能在缺少证据时声称没有外部现金流；本能力不重建券商账单。

这是可修改的研究基线。改进时保留假设、原结果与同一输入上的对照；合成数据保持演示标记。需要核对公式或设计改进时，可读 `skills/abu-trade-metrics/references/method.md`；参数、返回值与错误恢复由工具说明直接提供。

逐笔审计规则见 `skills/abu-trade-metrics/references/audit.md`。只在问题需要时选择绩效、审计或两者；不要为完成固定步骤补造订单、资金流或行情。

本能力属于数值方法层，消费调用者提供的已知输入。把 equity 回撤/收益统计及 closed_trades 归因交回策略或账户复盘；保留币种、资金流和年化口径，不另行重建交易或把同一权益曲线的多个比率当独立盈利证明。复用前核对输入版本、参数、截止时间与实现口径；已有匹配结果可直接引用。同源价格、成交或统计派生结果不能重复计为独立证据；计算只回答本项局部问题，方法解释与最终综合由调用者负责。缺少已声明的必需字段或真实时序时，交回具体缺口，不补造数据以通过校验。
