# Elliott 波浪候选

## 问题与证据

本方法回答“已知锚点是否符合声明的波浪结构约束，以及什么新观察能区分主候选和替代候选”。用户或工作流可根据这个局部问题选择本方法，不要求逐个点名，也不默认加载所有方法。

输入：已有固定行情和锚点引用、周期、价格基础、端点 high/low 或 close、确认时点、结构类别与级别；只有截图时缩小为示意候选。优先复用调用者已有的固定证据；来源、时间、版本或覆盖存在缺口时，说明它影响哪项结论，并把具体补证需求交回调用者。不要为同一轮方法比较重复获取同一份资料。

## 判读原则

- 标准 impulse 的规则不与 diagonal、延长或修正类别混用。硬约束检查通过只是必要条件，不证明计数唯一或下一浪必然发生。
- 保留主候选和可成立的替代；资料不够时替代可为“结构未完成/不适用”，不用编造点位凑出完整计数。
- 每条候选保留锚点 id/revision、价格、事件时刻、最早确认时刻、首次标注时刻与类别版本。右侧确认不可提前；新增极值或换类别产生新修订，旧失效仍保留。
- Fibonacci 比率是已声明的辅助描述，不能替代结构约束、变成确定目标或未经校准的胜率。输出反证与各候选失效边界。

## 交接与组合

输出：主/替代候选表、标准推动结构的逐条规则结果、端点版本、失效价位及区分候选的新观察。向调用者交回本方法的观察、解释、原始引用、反证、缺口和失效条件；可使用 Markdown 表或已有结构，不引入新的必填包壳。不确定、反对或不适用也是有效的局部结论，不为了完整外观补造事实。

abu-price-structure 的已确认摆动和价格水平可作锚点证据，但需核对窗口、时间与端点定义；同一组摆动的价格行为解读和波浪解读并非独立市场确认。 复用计算时核对输入、参数、时间和实现版本，同源结果不重复计为独立证据。最终综合、补证优先级和报告由调用者负责；方法不会自行发布另一份最终报告或启动交易。
