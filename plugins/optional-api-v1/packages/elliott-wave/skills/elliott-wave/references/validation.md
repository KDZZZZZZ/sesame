# 从解释到检验

这是方法研究的验收约定，不扩展 SVL。先区分人工候选、确定性观察、事前预测与交易规则；它们需要不同证据。

- 固定数据 DataRef、provider/connection/instrument/spec、SourceTime、可得时间及 coverage。当前修订不是历史当时所知；形成中柱不得当闭柱。缺量不填 0，tick 不转成成交量。
- 将参数、标签定义、确认/失效、样本切分在看结果前记录。人工标签保留版本和相反解释；所有尝试进入清单，不只留最好一张图。
- 做前缀检查：输入只到某时刻，结果不能含此后才能确认的标注。延迟确认画在过去位置时，决策时间仍在右侧确认之后。源修订会改变计算，应产生新结果而不是抹去旧结果。
- 检验预测能力时用独立时段/样本、简单基准、全部尝试数量及不确定性。随机切分会混入同一事件/重叠持有期时，改为符合信息顺序的切分。
- 交易效果还需明确买卖价、费用/滑点、未成交、同柱路径、交易时段与数量限制；用实际引擎/目标工具验证。没有这些只报观察/解释，不报回测净收益。

Lo、Mamaysky、Wang 的原始研究是将图形识别操作化的例子；Sullivan、Timmermann、White 的研究提醒技术规则检验中的多重尝试问题。它们不证明本包或所有作者方法有效。来源见 PROVENANCE；本包没有复制论文算法。

最小报告应包含：规则/候选定义、固定证据、确认时序、反证、输入不完整范围、实际运行范围。报告发布和渲染检查用现有 reports；需要执行策略才使用已存在的 strategy-authoring 与目标 profile，能力缺失明确 unsupported。
