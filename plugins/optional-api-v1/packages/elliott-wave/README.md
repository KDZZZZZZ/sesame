# Elliott 波浪候选

`sesame/elliott-wave`，版本 1.0.0，要求 Sesame `>=0.2.0-0`。独立可选、安装后 discoverable；`plugin_load` 只加载本方法。零 tools/providers，无自动联网/依赖安装/账户操作，也不依赖或注入其它方法包。

独立波浪研究：明确结构类型、级别、锚点、标准推动浪约束、替代计数和确认时刻；主观候选与验证分开。

从 [skill](skills/elliott-wave/SKILL.md) 和 [PROVENANCE](PROVENANCE.md) 开始。案例为原创虚构教学数据。取数使用 data-access 与用户已配置的提供方；画图使用 canvas-control，报告使用 reports，策略化使用 strategy-authoring 与明确选定的目标。这些现有能力不是本包重复实现。

本包提供具体研究步骤、证据要求和验收示例，不声称完整自动理论分类、经济效力或收益证明。引用外部文献不代表其作者认可本插件，亦不改变外部许可。
