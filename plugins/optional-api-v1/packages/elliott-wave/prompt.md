# Elliott 波浪候选

本包提供可组合的分析方法，回答：已知锚点是否符合声明的波浪结构约束，以及什么新观察能区分主候选和替代候选。用户或工作流可按问题选择它，无需用户逐个点名。它消费已有证据，返回局部结论，不自行承担整套研究或另开最终报告。

输入：已有固定行情和锚点引用、周期、价格基础、端点 high/low 或 close、确认时点、结构类别与级别；只有截图时缩小为示意候选。输出：主/替代候选表、标准推动结构的逐条规则结果、端点版本、失效价位及区分候选的新观察，附原始引用、反证、缺口和失效条件交回调用者。共享来源的派生解释不能重复计作独立证据；只加入能回答不同问题的方法。

按需读取已注册的 skills/elliott-wave/SKILL.md 及相应参考片段。需要补证据时说明缺什么和它会改变哪个判断，由调用者安排信息能力；完整报告和交易决定由上层工作流负责。
