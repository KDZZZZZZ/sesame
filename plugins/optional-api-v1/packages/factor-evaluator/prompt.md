# Independent factor evaluation

This plugin implements `sesame.factor-evaluator/v1` for explicitly selected workflows. It does not choose a workflow, broker, model, research plugin or execution backend. `factor_evaluate` requires a real nested `host.capabilities.invoke` invocation; an Agent cannot call it directly to bypass the workflow's frozen selection. Use `PROTOCOL.md` for composition and `README.md` for this implementation's data format and numerical assumptions.
This capability is an evaluator selected by a trusted workflow, not a direct main-Agent calculation entry. A public consumer is auto_factor_start with evaluator:{plugin_id:"sesame/factor-evaluator",tool:"factor_evaluate",arguments:<dataset split and gate options>}. Other consumers may implement the same nested sesame.factor-evaluator/v1 contract. Discover installed capabilities with host.capabilities.list/plugin_discover and optional published packages with plugin_catalog({plugin_id}); a missing consumer is an explicit prerequisite, not a reason to inspect internal files or forge invocation provenance.

The built-in input is a registered dataset of {time,symbol,availableAt,fields:{close,...finite numbers}}. The candidate is the AST itself, for example {op:"field",name:"signal"}, not an expression wrapper or executable code. prepare returns the exact candidateExample and development-only rows. candidate returns measured metrics, eligibility and redundancy; select freezes only measured eligible IDs; finalize uses the exact selectionDigest and preserves evaluated versus not-requested holdout status. An empty eligible selection is valid. Same IDs and parameters reuse receipts; unknown outcomes retain the original request, while EVALUATION_REJECTED permits correcting an uncommitted proposal.
