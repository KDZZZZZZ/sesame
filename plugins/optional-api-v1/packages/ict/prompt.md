# ICT 价格结构研究

本包提供可组合的分析方法，回答：固定参考区间中的价格分离、跨越和结构转变候选是否满足明确的观察定义。用户或工作流可按问题选择它，无需用户逐个点名。它消费已有证据，返回局部结论，不自行承担整套研究或另开最终报告。

输入：已有固定闭柱证据、SourceTime、时段与覆盖、参考高低点和判定定义；需要 session/kill-zone 时另需明确来源时区与历史夏令时规则。输出：源柱引用、三柱区间分离或其他明确规则的观察、确认时点、候选术语、替代解释及失效条件，附原始引用、反证、缺口和失效条件交回调用者。共享来源的派生解释不能重复计作独立证据；只加入能回答不同问题的方法。

按需读取已注册的 skills/ict/SKILL.md 及相应参考片段。需要补证据时说明缺什么和它会改变哪个判断，由调用者安排信息能力；完整报告和交易决定由上层工作流负责。
