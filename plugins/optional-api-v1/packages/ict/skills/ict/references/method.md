# ICT：术语与可验证观察

原作者 The Inner Circle Trader 的 2022 Mentorship Episode 6（2022-02-03）公开描述主题为 Fair Value Gap 与 Market Structure Shifts。本次核实了作者频道、标题和说明，没有取得完整视频转录，也未把课程当成统计效力证明。[作者视频](https://www.youtube.com/watch?v=Bkt8B3kLATQ)

本包把研究记录拆为三层：作者术语；事先明确的离散观察规则；研究者的情境解释。术语如“institutional order flow”不使 K 线数据包含机构身份或真实未成交订单。

## 本包唯一自动观察

在三根连续返回的已闭合柱 a、b、c 上：若 `c.low > a.high`，记录向上区间 `(a.high, c.low)`；若 `c.high < a.low`，记录向下区间 `(c.high, a.low)`。相等不算分离。确认时间为 c 的源 end_time，锚点是三根柱各自的 id/revision。这是本包明确公布的离散规则，并不声称完整重现作者的筛选、时段、displacement、偏向或订单执行方法。

“连续返回”不证明交易日历上连续：跨休市/缺数仍须检查 coverage 和时段，脚本把间隔情况留在结果，不将跨缺口观察自动命名为有效 FVG。源高低区间相交与价格回到区域也不能证明限价单可成交。脚本不预测回补、不更新区域为已成交。

## 手工研究卡

- 先固定研究区间的两个锚点、产生/确认时刻、reference high/low 与定义。
- 观察是否跨过参考价、影线/收盘各是什么；不要混用两个判据来挑有利样本。
- 需要结构转变或 displacement 时，先定义它的测量与确认条件；未给定义只允许 candidate。
- 若采用 session/kill-zone，保存明确的市场时区、历史夏令时与 session 定义；未知来源时钟不转成纽约时间。
- 每条结论列事实、候选术语、未观测信息、失效/撤销条件和替代解释（例如普通价格跳空）。

没有盘口/订单级证据时，“止损被扫”“机构补单”只能写未验证机制，不能写事实。使用本方法不自动授予下单权限，也不加载其它流派。
