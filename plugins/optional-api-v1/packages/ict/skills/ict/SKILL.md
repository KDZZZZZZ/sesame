# ICT 价格结构研究

## 问题与证据

本方法回答“固定参考区间中的价格分离、跨越和结构转变候选是否满足明确的观察定义”。用户或工作流可根据这个局部问题选择本方法，不要求逐个点名，也不默认加载所有方法。

输入：已有固定闭柱证据、SourceTime、时段与覆盖、参考高低点和判定定义；需要 session/kill-zone 时另需明确来源时区与历史夏令时规则。优先复用调用者已有的固定证据；来源、时间、版本或覆盖存在缺口时，说明它影响哪项结论，并把具体补证需求交回调用者。不要为同一轮方法比较重复获取同一份资料。

## 判读原则

- 作者术语、离散观察规则和情境解释分别写清；参考区间、影线/收盘选择、结构转变或 displacement 的测量先确定。未定义的部分只能作为候选。
- 本包脚本仅判断三根连续返回闭柱的区间分离，不构成完整 ICT 系统。“连续返回”不证明交易日历连续，跨休市或缺数的区间不能直接命名为有效 FVG。
- 价格跨过参考价只证明价格跨越；机构订单、未成交止损簇和真实订单流需要盘口或订单证据。没有此类资料时保留机制假设和反证，不能把术语当事实。
- 确认时间不早于必要闭柱可得时间，形成中候选单列；来源时区未知时不猜纽约时间。区间回访不证明限价成交或必然回补，改判新增修订。

## 交接与组合

输出：源柱引用、三柱区间分离或其他明确规则的观察、确认时点、候选术语、替代解释及失效条件。向调用者交回本方法的观察、解释、原始引用、反证、缺口和失效条件；可使用 Markdown 表或已有结构，不引入新的必填包壳。不确定、反对或不适用也是有效的局部结论，不为了完整外观补造事实。

price-action 可补趋势/区间语境，abu-volatility 可补波动尺度；它们不会证明机构动机。若已有同定义、同窗口和同版本的区间观察，直接复用其固定引用。 复用计算时核对输入、参数、时间和实现版本，同源结果不重复计为独立证据。最终综合、补证优先级和报告由调用者负责；方法不会自行发布另一份最终报告或启动交易。
