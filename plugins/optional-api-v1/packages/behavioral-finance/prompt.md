# 行为金融研究

本包提供可组合的分析方法，回答：参照点、注意力或预期偏差是否比信息变化、风险与交易约束更能解释当前观察。用户或工作流可按问题选择它，无需用户逐个点名。它消费已有证据，返回局部结论，不自行承担整套研究或另开最终报告。

输入：已固定的事件和预期资料、参与者样本或可观测代理、发布时间与研究截止时间；参与者总体、成本参照点或历史版本未知时保留 unknown。输出：行为机制候选、基线解释、逐环节证据与替代原因、支持/削弱/未区分状态及下一项可区分测量，附原始引用、反证、缺口和失效条件交回调用者。共享来源的派生解释不能重复计作独立证据；只加入能回答不同问题的方法。

按需读取已注册的 skills/behavioral-finance/SKILL.md 及相应参考片段。需要补证据时说明缺什么和它会改变哪个判断，由调用者安排信息能力；完整报告和交易决定由上层工作流负责。
