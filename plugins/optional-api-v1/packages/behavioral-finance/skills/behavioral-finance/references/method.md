# 行为金融：机制与可观测量

Kahneman 的 Nobel lecture（2002）及 AER 论文（2003）讨论直觉判断、参照依赖和有限理性。它们为提出假设提供依据，不允许从某根 K 线反推投资者的心理状态。[作者出版目录](https://kahneman.scholar.princeton.edu/publications)；[原始论文](https://econweb.ucsd.edu/~jandreon/Econ264/papers/Kahneman%20AER%202003.pdf)。出版信息及访问限制见 PROVENANCE。

可使用以下原创工作表，不预设哪一种解释为真：

| 候选机制 | 需要的可观测资料 | 主要混淆/反证 |
| --- | --- | --- |
| 注意力改变 | 带发布时点的报道、搜索/成交活跃度，明确样本 | 报道可能跟随价格；同稿转载不是新增注意力冲击 |
| 参照点/损失厌恶 | 有依据的参照价或参与者样本、持仓/交易设计 | 无持仓成本时不应拿任意整数价当群体参照点 |
| 过度自信/反应不足 | 截止前预期、可得信息、随后修正的预先规则 | 风险暴露、流动性或基本面变化也会导致同形价格 |
| 趋势追随/反馈 | 有方向和时序的申赎、仓位或委托证据 | 价格与成交量同升不能单独识别是谁追随谁 |

执行步骤：先给无心理解释的基线（信息改变、约束、风险补偿）；再加入一个行为机制，列出它多解释了什么、必须新增什么证据。不要诊断具体个人/群体非理性，不把事后挑出的故事当交易规则。若需检验，以预登记窗口、对照、公开可得时间和成本为基础；价格观察本身最多为相关性证据。
