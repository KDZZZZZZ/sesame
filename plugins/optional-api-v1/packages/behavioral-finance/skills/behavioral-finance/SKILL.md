# 行为金融研究

## 问题与证据

本方法回答“参照点、注意力或预期偏差是否比信息变化、风险与交易约束更能解释当前观察”。用户或工作流可根据这个局部问题选择本方法，不要求逐个点名，也不默认加载所有方法。

输入：已固定的事件和预期资料、参与者样本或可观测代理、发布时间与研究截止时间；参与者总体、成本参照点或历史版本未知时保留 unknown。优先复用调用者已有的固定证据；来源、时间、版本或覆盖存在缺口时，说明它影响哪项结论，并把具体补证需求交回调用者。不要为同一轮方法比较重复获取同一份资料。

## 判读原则

- 用信息变化、风险补偿或交易约束作为比较基线，说明行为机制增加了哪一项可检验解释。价格路径本身不足以诊断群体心理，论文结论不能替代本次数据。
- 参照价需要真实成本、调查或实验依据；整数价不能自动当作参与者成本。可观测代理的测量误差、中间机制与替代原因要说明。
- 截止前预期和实际发布值分开，前值不是预期；历史版本不明的调查不能进入事前检验。同稿转载不构成独立注意力样本。
- 结论可以支持、削弱或仍无法区分。给出反证和改变判断的观察，不对个人或群体作心理诊断，不把相关性写成已识别因果效应。

## 交接与组合

输出：行为机制候选、基线解释、逐环节证据与替代原因、支持/削弱/未区分状态及下一项可区分测量。向调用者交回本方法的观察、解释、原始引用、反证、缺口和失效条件；可使用 Markdown 表或已有结构，不引入新的必填包壳。不确定、反对或不适用也是有效的局部结论，不为了完整外观补造事实。

来源传播是否重复可交给 narrative-analysis；资金或制度约束可交给 institutional-analysis。它们回答不同的缺口，而不是为同一个故事增加赞成票。 复用计算时核对输入、参数、时间和实现版本，同源结果不重复计为独立证据。最终综合、补证优先级和报告由调用者负责；方法不会自行发布另一份最终报告或启动交易。
