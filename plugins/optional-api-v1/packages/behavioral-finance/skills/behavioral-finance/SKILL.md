# 行为金融研究

1. 先用 plugin_id=`sesame/behavioral-finance` 读取本 skill 的 `references/method.md` 与 `references/evidence.md`；不要为了行为分析自动加载其它解释方法。
2. 定义资产、事件、研究截止时间、参与者总体与问题。用现有数据/检索能力保留原始资料、固定引用、发布与采集时间；不知道参与者总体或参照点就写 unknown。
3. 先写无行为解释的基线：信息变化、风险或交易约束。再提出一个行为机制，逐项列可观测代理、中间环节、替代原因和反证。价格路径本身不足以诊断群体心理。
4. 将截止前预期与实际发布值分开；前值不是预期。历史版本不明的调查不能进入事前检验；重复稿件不算独立注意力样本。
5. 根据 method.md 的机制表，选择能区分解释的新增测量；例如参照价需要真实成本/实验依据，不能任意把整数价当投资者成本。代理变量存在测量误差时说明方向和局限。
6. 输出支持/削弱/未区分的结论及条件更新规则；不对个人或群体作心理诊断，不把相关性写成因果估计。计算用 workspace，结果用 research_register；论文结论不能替代本次数据。
7. 报告使用 reports；只有用户需要长期跟踪才使用 judgment-evolution。用户要策略时另走既有策略流程，本包不增加交易/账户能力。

所有相对参考路径位于 `skills/behavioral-finance/`；脚本、案例和 PROVENANCE 的路径相对包根，均经 `plugin_read` 授权读取。以下均为研究约定，不是新 SVL schema 或交易权限。先读 `PROVENANCE.md` 的实际访问范围与许可；示例是 demo，不得当真实行情。
