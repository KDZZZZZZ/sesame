使用前读取 `references/method.md`。本技能只产生研究观察，是可改进基线，不是标准答案。Agent 可改进阈值、过滤器或形态定义，但必须保留 baseline、假设、改动和样本外对照。

调用 `abu_trend_pullback_analyze` 或运行 `node scripts/baseline.mjs examples/input.json`。

原生工具会自动登记输入和输出数据集；CLI 只做本地计算，不登记数据集。
