# 市场叙事研究

1. 先读本 skill 的 `references/method.md` 与 `references/evidence.md`，plugin_id=`sesame/narrative-analysis`。只分析指定叙事，不自动加载其它理论。
2. 固定问题、地区/语言/平台/样本窗口及截止时间。用现有来源工具取得原稿，保留标题、作者、URL、发布时间、采集时间和转述关系；不能以采集到的几条消息代表全市场共识。
3. 把每个叙事压缩为可核查命题，区分直接引述、作者推断和研究者归类。原稿与转载归同一 source_cluster；不重复统计“独立确认”。长版权全文不复制到报告。
4. 列出支持、反对及缺失事实，并保留相反叙事。传播先后可能跟随价格，不能反推它引发了价格；先后的证据也不是充分因果证明。
5. 从命题提出条件情景：可观察触发、期限、预计会看到的证据、反证和更新时间。情景重叠则说明，不强行加总概率；没有校准记录不给伪精确百分比。
6. 先形成可审查的命题/来源簇表，再提交 reports。若用户需要持续概率预测，使用 judgment-evolution 的既有记录与结果核验流程；不创建第二套账本。
7. 对价格/成交量的并列图保留 DataRef 和 SourceTime；它最多展示相关的观测过程，不把叙事术语当真实资金方向证据。本包不执行交易。

所有相对参考路径位于 `skills/narrative-analysis/`；脚本、案例和 PROVENANCE 的路径相对包根，均经 `plugin_read` 授权读取。以下均为研究约定，不是新 SVL schema 或交易权限。先读 `PROVENANCE.md` 的实际访问范围与许可；示例是 demo，不得当真实行情。
