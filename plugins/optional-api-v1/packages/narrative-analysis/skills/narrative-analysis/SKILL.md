# 市场叙事研究

## 问题与证据

本方法回答“实际资料支持哪些市场命题、传播关系和竞争解释，下一项观察如何区分它们”。用户或工作流可根据这个局部问题选择本方法，不要求逐个点名，也不默认加载所有方法。

输入：已有的原稿或已提取正文、标题/作者/URL、发布及采集时间、转述关系、地区/语言/平台/样本窗口和截止时间。优先复用调用者已有的固定证据；来源、时间、版本或覆盖存在缺口时，说明它影响哪项结论，并把具体补证需求交回调用者。不要为同一轮方法比较重复获取同一份资料。

## 判读原则

- 区分直接引述、作者推断和研究者归类；同一原稿及转载归同一 source_cluster。几条消息不能代表全市场共识，重复转载不增加独立确认。
- 把叙事压缩成可核查命题。传播、预期更新、行为变化和价格之间逐段给证据；传播可能跟随价格，先后关系也不足以证明因果。
- 保留相反命题和不足以区分分支。条件情景包含可观察触发、期限、若发生会出现的资料及反证，涨跌横盘本身不构成机制解释。
- 情景重叠时说明，未经校准不强行给精确概率或凑成百分之百。用户明确要求主观概率时标注主观性和更新依据。

## 交接与组合

输出：命题与 source_cluster 表、支持/反对/缺失事实、竞争情景、触发与反证及更新条件。向调用者交回本方法的观察、解释、原始引用、反证、缺口和失效条件；可使用 Markdown 表或已有结构，不引入新的必填包壳。不确定、反对或不适用也是有效的局部结论，不为了完整外观补造事实。

behavioral-finance 检查注意力或预期机制，institutional-analysis 检查约束传导；方法可共用同一来源簇，不能把同一篇报道变成三份独立证据。 复用计算时核对输入、参数、时间和实现版本，同源结果不重复计为独立证据。最终综合、补证优先级和报告由调用者负责；方法不会自行发布另一份最终报告或启动交易。
