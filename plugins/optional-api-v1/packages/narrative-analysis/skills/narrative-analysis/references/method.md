# 叙事与条件情景

Shiller（2017）的 Narrative Economics 研究叙事传播及其经济相关性，并承认科学研究这些传播的困难。叙事热度不能单独证明价格方向或因果效应。[AER 原文信息和摘要](https://www.aeaweb.org/articles?id=10.1257/aer.107.4.967)

## 可执行记录

将叙事写成可核对的一句话及来源样本，记录首次可得时间、传播范围、转述关系、相反叙事、未出现的必要事实。把一家公司转载同一新闻归到同一 source_cluster；不得用重复数量抬高独立确认程度。只记录实际采集的平台/语言/时段，不能称为全市场共识。

从叙事提取可观测命题，例如“某投入成本持续下降”需要成本指标，而非“市场相信宽松所以一定上涨”。写清链条中未测环节：叙事传播 → 预期更新 → 资金/行为变化 → 价格；不能跳步。

## 情景卡

每个情景填写：前提、可观察触发、期限、若发生会看到的资料、反证、与另一情景的区分点、下一次检查时间。另设“不足以区分”的分支。涨/跌/横盘只是价格结果，不自动构成三种解释机制。

没有校准就使用有条件陈述，不分配 60/30/10 等主观精确概率。若用户明确要求主观概率，应标记 subjective、给更新依据并保存预测原稿；不把它称为历史胜率。可选 judgment-evolution 接管后续结果记录与评估。
