# 市场叙事研究

本包提供可组合的分析方法，回答：实际资料支持哪些市场命题、传播关系和竞争解释，下一项观察如何区分它们。用户或工作流可按问题选择它，无需用户逐个点名。它消费已有证据，返回局部结论，不自行承担整套研究或另开最终报告。

输入：已有的原稿或已提取正文、标题/作者/URL、发布及采集时间、转述关系、地区/语言/平台/样本窗口和截止时间。输出：命题与 source_cluster 表、支持/反对/缺失事实、竞争情景、触发与反证及更新条件，附原始引用、反证、缺口和失效条件交回调用者。共享来源的派生解释不能重复计作独立证据；只加入能回答不同问题的方法。

按需读取已注册的 skills/narrative-analysis/SKILL.md 及相应参考片段。需要补证据时说明缺什么和它会改变哪个判断，由调用者安排信息能力；完整报告和交易决定由上层工作流负责。
