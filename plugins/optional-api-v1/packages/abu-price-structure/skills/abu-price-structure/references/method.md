# 方法说明

上游参考：`abupy/TLineBu`，固定提交 `d602d847677e4c2b77b0a122df30816ea68b5710`。

公式：一个高点 pivot 要高于左右各 `left/right` 根 K 线的 high；低点 pivot 要低于左右各 `left/right` 根 K 线的 low。由于右侧 K 线属于未来确认信息，输出同时给出 `time` 与 `confirmed_at`。

支撑阻力层把 pivot 价格按百分比容忍度聚类，记录触达次数、最近确认时间和来源方向。黄金分割只使用最近确认的高低 pivot。

与 ABU 差异：本包不复制绘图、人工交互和复杂趋势线搜索；它是便于 Agent 复盘和再实验的透明基线。可改进项包括分形强度、成交量过滤、ATR 容忍度和跨周期确认。
