# 股票筛选基线

用 `abu_stock_screening_analyze` 在给定股票池中比较动量、趋势和价格效率，解释领先标的、分项得分与被排除样本。

排名只对本次股票池成立；历史不足的标的不参与排名。等权指标提供可比较的筛选依据，不能代替流动性、可交易性或后续收益验证。

这是可修改的研究基线。改进时保留假设、原结果与同一输入上的对照；合成数据保持演示标记。需要核对公式或设计改进时，可读 `skills/abu-stock-screening/references/method.md`；参数、返回值与错误恢复由工具说明直接提供。

本能力属于数值方法层，消费调用者提供的已知输入。把 all、top、universe_size 和排除原因交给候选池研究；池内多项价格派生得分不是独立证据，下一轮用可交易性、基本面等针对缺口的资料核验。复用前核对输入版本、参数、截止时间与实现口径；已有匹配结果可直接引用。同源价格、成交或统计派生结果不能重复计为独立证据；计算只回答本项局部问题，方法解释与最终综合由调用者负责。缺少已声明的必需字段或真实时序时，交回具体缺口，不补造数据以通过校验。
