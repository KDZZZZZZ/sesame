# 一项信息可以承担不同的策略职责

先说清这项信息改变哪一个决定。能预测未来方向的信号可影响预测正负和强弱。只在另一信号已触发时有解释力的状态特征适合作入场过滤。能描述未来波动或流动性、对方向帮助很小的量，仍可能适合控制仓位或交易速度。

| 用法 | 可检验的预测 | 合适的交易对照 |
| --- | --- | --- |
| 加权预测 | 在原信号相近的机会中，新特征还区分方向或延续幅度 | 用开发期已知的尺度统一预测，比较等权、加权及移除其中一个预测的完整策略 |
| 条件过滤 | 基线机会中，被放行的一组在同期限具有更好的成本后结果 | 基线、加过滤、同交易数或敞口的控制组，以及关闭过滤组 |
| 调节仓位 | 风险集中时降低敞口，同时保留主要预测机会 | 让两组入场时间和方向一致，比较资金回撤、风险分布及错失的上涨 |
| 切换规则 | 在当时可识别的状态下，规则间的相对优劣发生变化 | 比较每条固定规则和切换版本，计入切换成交成本与状态误判 |

到现有因子库查精确定义、评价使用的数据、期限和开发分区。独立证据足够时直接引用。再用包含迟到、修订、缺失和极值的时间点核对研究值与交易端实际读数。最后用完整策略检验该用途。独立评价通过、实时输入晚到和交易增量未证实可以同时成立。纯价格规则可以跳过这一环。[Qlib 的信号分析和组合分析记录](https://github.com/microsoft/qlib/blob/main/qlib/workflow/record_temp.py)
