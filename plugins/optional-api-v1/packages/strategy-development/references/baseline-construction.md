# 选一个能区分解释的基线

研究突破是否延续时，第一份可交易基线可以在收盘确认突破，在下一次可成交的时点进场，固定持有若干根 K 线后退出。固定持有期能把方向信号的衰减和退出择时拆开看。继续使用委托规定的仓位上限、成本和可交易时段。若信号的延续大多发生在成交前，先比较信号延迟和可成交性。

研究新过滤器时，用旧完整策略作为 A。若 B 降低了持仓时间，再选一个只减少敞口的 C。例如在相同日期、方向、波动区间的基线机会中预先确定保留比例和抽样种子，可以用多个预先登记的种子估计随机减少交易产生的差异。实测配对交易数、市场暴露时间和仓位大小，发现差异时把它列为尚存的解释。

研究仓位调整时，每组应共享相同的原始预测、目标数量算法、风险规则及引擎。以每个决策时点的账户、最新成交和当前持仓为起点。对新目标只改一个执行参数，观察总成交额、费用、风险偏离和成本后权益。还可以用恒定曝险、简单等权或固定持有期作参照，具体选哪一种取决于要剥离哪种收益来源。

本插件的可编辑原生示例 forecast_buffer 用单一股票型日线演示这项比较。它将快慢趋势差按价格波动缩放，以风险预算换算目标股数，限制敞口并管理待成交订单。buffer_fraction 取零时直接追踪目标，取正值时可以容忍目标附近的小幅偏差。单独核对涨跌停、点值、融资、保证金或交易时段等目标市场条件，特别是迁移到外汇、期货和贵金属时。[pysystemtrade 的系统阶段和仓位方法](https://github.com/pst-group/pysystemtrade/blob/develop/docs/backtesting.md)
