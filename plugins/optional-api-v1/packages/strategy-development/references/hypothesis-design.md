# 从市场行为推导第一条规则

从用户真正希望改善的交易行为入手。把“震荡期亏损”展开为几个会留下不同证据的解释。下面用黄金突破作研究假设，阈值、期限和市场现象均待实测。

| 竞争解释 | 如果解释成立，开发数据上应看到什么 | 第一个值得测试的改动 |
| --- | --- | --- |
| 突破经常是假突破 | 在相同波动、时段、方向和持有期限下，被标记为震荡的突破从最早可成交价起就少有延续 | 保持退出和仓位，只给原突破加一个事前可知的入场过滤 |
| 突破有延续，原退出交回利润 | 交易中出现过有利移动，原退出较晚。相同持有期的基准退出能保留更多收益 | 保持所有入场不变，比较一次超时退出或信号衰减退出 |
| 延续和退出都合理，小额调仓太频繁 | 方向和交易毛利尚可，目标数量在相邻交易日来回变化，成交额和手续费集中在这些调整 | 保持预测与基础费率，围绕原目标仓位设缓冲带 |
| 亏损来自风险规模 | 方向预测和单位风险收益相近，高波动日的头寸却贡献大部分资金回撤 | 固定方向和出入场，用事前波动率调整头寸，比较相近风险下的收益 |

先在开发样本给每次突破保存机会 ID、方向、决定时刻及最早成交价。固定一个与信号寿命相称的观察期限。分别统计方向调整后的远期价格变化、实际毛盈亏、成本后盈亏。远期价格只是检验标签。用价格变化来定义“震荡”时，只将决策时已完成的数据用于分组。若过滤器只是少交易，等量保留机会的对照也可能获得相同改善。这是能推翻“它挑中了较好机会”的结果。

同一思路可迁移到截面选股。高分组收益较好可能来自行业上涨。先固定当日可交易股票池、发布时间和调仓频率，在行业内比较排名，再用行业风险相近的组合做成本后检验。若行业内差异消失，下一次实验应考查行业配置的作用。

已有经济解释时，先写可观察预测和反例。需要从数据探索时，先确定候选家族、持有期限和搜索预算，保留试过但无效的候选。得到探索结果后，再为候选写出能用另一段数据推翻的解释。[Peterson 的假设与逐组件研究](https://www.braverock.com/brian/CapeR_2016_backtest.html) · [QuantConnect 研究指南](https://www.quantconnect.com/docs/v2/writing-algorithms/key-concepts/research-guide)

**从硬约束倒推规则。** 假设委托只允许在日收盘后决策，最早次日开盘成交。先把突破收盘到次日开盘，以及次日开盘到预定退出的方向收益分开估计。若延续集中在隔夜跳空，原假设即使能预测方向，也无法按这份委托取得那段收益。保留同一个突破定义，先考查开盘后的剩余期限。若扣除价差后仍无可交易的延续，可以结束这个方向的开发。

在固定的单标的开发行情上，strategy_development_study 可直接完成这项拆分。信号收盘必须严格越过此前窗口的最高价或最低价。把完整机会和样本末尾观察期不足的机会分别计数。先与同方向全部可用决策比较，再选择相同波动和交易时段的对照。连续几天突破可能属于同一段趋势，解释样本数时应核对这些机会的日期与重叠程度。

**组合两个预测前先找分歧。** 假设已有趋势预测，准备加入一个相近周期的动量排名。在相同的可交易品种和时刻，把两者方向一致、相反和只有一方有信号的机会分别列出，按可成交后的共同期限计量。固定原有风险预算与成本，比较旧预测和一个预先定权的组合。若两个预测在绝大多数时刻同向，分歧时新预测也没有改善选择，增加它的权重只会重复原有敞口。若差异只出现在高波动时段，可把风险缩放作为竞争解释，再设计一组等风险对照。
