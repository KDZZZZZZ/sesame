# 制度与经济历史研究

本包提供可组合的分析方法，回答：正式规则、执行与资金约束通过什么机制影响当前观察，历史类比在哪些条件下成立或失效。用户或工作流可按问题选择它，无需用户逐个点名。它消费已有证据，返回局部结论，不自行承担整套研究或另开最终报告。

输入：已有的规则原文及版本、生效与实际执行日期、地区/时期、资产与参与者资料、融资或结算证据及截止时间。输出：制度和资金传导链、逐环节证据、历史相同/不同/未知对照、替代原因与可推翻解释的事实条件，附原始引用、反证、缺口和失效条件交回调用者。共享来源的派生解释不能重复计作独立证据；只加入能回答不同问题的方法。

按需读取已注册的 skills/institutional-analysis/SKILL.md 及相应参考片段。需要补证据时说明缺什么和它会改变哪个判断，由调用者安排信息能力；完整报告和交易决定由上层工作流负责。
