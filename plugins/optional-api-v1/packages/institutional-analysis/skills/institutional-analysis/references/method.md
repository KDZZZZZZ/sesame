# 历史、制度与资金约束

North 的 1993 Nobel lecture 将制度描述为正式规则、非正式规范与实施方式，并强调时间中的演化。使用这一区分列出法律/结算/抵押品/资本约束，不以历史相似图形推断必然重演。[原作者 lecture](https://www.nobelprize.org/prizes/economic-sciences/1993/north/lecture/)

Adrian 与 Shin 的 FRBNY Staff Report 328（2008，2010 修订）研究市值计价资产负债表调整、杠杆与流动性关系。这里把它用作一项机制候选；特定中介样本的结果不等于所有资产的通用因果规律。[原始研究及版本](https://www.newyorkfed.org/research/staff_reports/sr328.html)

## 历史类比的执行模板

先选待解释的机制，再选案例；写出事先选择理由。并排比较：货币/汇率制度、通胀与供给约束、资产负债表、市场参与者、融资与保证金、政策权限、结算/交易规则、信息传播速度。每项列相同、不同、未知及出处。重大差异会打断类比；“都跌了很多”不是机制相同。

若引用历史危机，不从今日数据反推当时参与者已知全貌。报告保留当时材料与后来修订/研究两栏；幸存者、样本选择和政策反事实未被控制时，不声称识别因果效应。

## 资金链的最小检查

把机制写成可测的链条，例如价格变化 → 抵押品估值 → 保证金/融资条件 → 去杠杆压力 → 实际交易。逐箭头列证据和替代原因。只有价格和成交量时，中间三项通常仍未知。存量、流量、比率分开；交易量不是净流入，未平仓量不是方向，融资余额不代表实际强平。

输出至少一个能破坏原解释的事实条件，例如融资条件没有收紧、参与者净敞口方向相反、政策传导受制度约束。将后续取证交给现有来源/数据插件，不自动要求安装交易后端。
