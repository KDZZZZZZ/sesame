# 制度与经济历史研究

## 问题与证据

本方法回答“正式规则、执行与资金约束通过什么机制影响当前观察，历史类比在哪些条件下成立或失效”。用户或工作流可根据这个局部问题选择本方法，不要求逐个点名，也不默认加载所有方法。

输入：已有的规则原文及版本、生效与实际执行日期、地区/时期、资产与参与者资料、融资或结算证据及截止时间。优先复用调用者已有的固定证据；来源、时间、版本或覆盖存在缺口时，说明它影响哪项结论，并把具体补证需求交回调用者。不要为同一轮方法比较重复获取同一份资料。

## 判读原则

- 政策宣布、实施和实际受约束的时间分开；没有执行证据不能把宣布日当作机制全部生效。旧案例不能冒充现行规则，当前版本缺口交由信息层补齐。
- 案例按机制理由选择，比较制度、抵押品、融资、结算、参与者和信息条件。价格形状相似不构成机制相同；重大差异可能打断类比。
- 传导链逐箭头保留证据与替代原因。交易量不是净流入，融资余额不是强平金额；存量、流量、比率、币种和期间不同不能直接相加。
- 当时材料与后来修订分开。没有对照和反事实设计时不声称已识别政策因果效应；给出至少一项反证及需要的独立测量。

## 交接与组合

输出：制度和资金传导链、逐环节证据、历史相同/不同/未知对照、替代原因与可推翻解释的事实条件。向调用者交回本方法的观察、解释、原始引用、反证、缺口和失效条件；可使用 Markdown 表或已有结构，不引入新的必填包壳。不确定、反对或不适用也是有效的局部结论，不为了完整外观补造事实。

narrative-analysis 可区分政策原文和市场转述，behavioral-finance 可比较预期机制；制度事实、参与者解释和价格反应保持不同证据身份。 复用计算时核对输入、参数、时间和实现版本，同源结果不重复计为独立证据。最终综合、补证优先级和报告由调用者负责；方法不会自行发布另一份最终报告或启动交易。
