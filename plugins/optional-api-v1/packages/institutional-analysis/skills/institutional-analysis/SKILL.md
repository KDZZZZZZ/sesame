# 制度与经济历史研究

1. 先读取本 skill 的 `references/method.md` 与 `references/evidence.md`，plugin_id=`sesame/institutional-analysis`。经济史仅作这个方法的证据框架，不自动加入别的理论。
2. 定义地区/时期、制度问题、资产/参与者与研究截止时间。优先发布机关的规则、实施日期及适用范围；有法律时效要求时检索当前原始版本，不把旧案例当现行规则。
3. 写出正式规则、执行方式、非正式约束以及传导链条。政策宣布、实施、实际受约束的时间分别记录；缺执行证据就不能把宣布日视为机制全部生效。
4. 历史案例按事先理由选择，并排列制度/结算/抵押品/融资/参与者/信息条件的相同、不同和未知。只因涨跌形状相似不构成机制类比。
5. 对资金链逐箭头列直接证据与替代解释；交易量不是净流入，融资余额不等于强平金额。存量、流量、比率、币种和期间必须明确，不能混合相加。
6. 明确哪些制度差异会破坏类比，哪些后续观察能否定当前解释；不声称从两个历史案例已识别政策因果效应。必要时将正式因果设计作为单独研究任务。
7. 用 reports 提交机制表、历史对照、出处/版本和局限。现有数据/来源工具和 workspace 承担取数与计算，本包不增加数据后端或执行交易。

所有相对参考路径位于 `skills/institutional-analysis/`；脚本、案例和 PROVENANCE 的路径相对包根，均经 `plugin_read` 授权读取。以下均为研究约定，不是新 SVL schema 或交易权限。先读 `PROVENANCE.md` 的实际访问范围与许可；示例是 demo，不得当真实行情。
