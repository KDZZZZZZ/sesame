# 判断复盘与准则演进

使用方法与证据约束见本包的 `skills/judgment-review/SKILL.md` 和能力声明。判断概率的核验与准则前瞻验证不等同于交易收益，也不会自动成为用户风险授权。

## 包内职责

- `service.js` 保留原能力门面、判断台账、单一 SQLite 连接与事务、调用快照、导出和生命周期。
- `rules.js` 管理候选准则、前瞻独立样本块、评分与晋级/退休；通过原 service 访问台账、时钟和策略。
- `coverage.js` 管理回复覆盖审计、完整原文分页和复盘队列；仅消费本次调用快照，不调用模型或重新读取外部证据。
- `inputs.js` 在同步业务操作与事务开始前读取完整宿主输入；`evidence.js` 继续使用包内固定证据快照辅助实现。

`after_turn` 只为已完成的主会话回复建立待审计记录，排除自动化来源。全文哈希、连续分页进度、原命令幂等记录和已保存规则共用原数据库；不新增定时任务、数据库或公开能力。`independentBlocks` 保留从 `service.js` 导出的原入口。
