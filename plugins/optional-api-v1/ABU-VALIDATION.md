## 审查中修正的实质问题

- RSI 使用窗口内变化所需的前一根收盘；相似性对齐收益的两个端点；筛选并列值
  使用平均名次，历史不足与时间不齐显式处理。
- K 线衍生结果记录实际依赖的可得时点；退出逻辑排除入场前极值，持有期退出
  不受 ATR 暖机阻塞。
- 零或极小 ATR 不产生无穷仓位；区分数学风险敞口和有明确合约单位的数量；
  分数凯利系数参与计算，常量权益假设明确标记。
- 开发期参数选择与留出验证分阶段，保存参数、网格、目标及开发证据摘要。
  留出阶段不允许非选中参数的结果。摘要只校验自洽，仍需外部冻结开发记录来证明
  时间顺序，不能证明调用者从未看到留出数据。
- 历史交易评分使用可比较的收益口径；模型缩放只拟合训练数据，标签在评估前可得，
  并限制计算预算。
- 成交审计按品种分别给出总成交量、买入量、卖出量和净量，不跨品种相加。
- 共享封装保留 `baseline` 和证据字段的所有权；算法不能覆盖它们，且修改算法输入
  不会污染已记录的原始输入。

不同实现人员交叉审查了行情、信号、评估/学习及共享接口；发现的问题已由对应
实现修正并增加针对性回归。这里没有把自检记录伪装成外部认证。
