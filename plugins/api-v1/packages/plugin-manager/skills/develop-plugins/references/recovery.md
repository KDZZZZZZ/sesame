# 安装与恢复

本地包安装调用 plugin_install，固定目录包使用 plugin_install_catalog；两者均包含宿主对完整声明、实际绑定和精确内容摘要的安装检查。失败一次返回全部诊断，修复后使用新的内容再次安装。本地更新传当前摘要 expectedRevision，目录更新用 action:"update" 与当前 expected_digest；冲突先重新读状态，不跳过版本检查。

副作用 operationId 保持稳定，同一ID不能换参数。网络回执丢失时先读实际插件状态；固定版本和摘要一致可恢复，不重复执行安装。状态禁用或激活失败如实返回，不能借加载绕过。

草稿不覆盖已有目录。崩溃后仅当磁盘草稿与生成模板逐字节一致时恢复原结果；存在作者修改则保留，使用现有目录继续开发。

API 1 包与旧 tool_names、createTools、隐式贡献不兼容。不存在隐式兼容包装、伪造测试成功、旧工具自动转发或自动回滚业务数据。
