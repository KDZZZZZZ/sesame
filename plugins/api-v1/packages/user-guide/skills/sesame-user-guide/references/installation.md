# Sesame 安装

## 从通用任务开始

先从右上用户设置打开“模型与运行状态”，配置模型并用实际消息验证。内置通用插件涵盖工作区、产品帮助、协作、Ultra、记忆、数据研究、报告、SVL 与插件管理；配置和工作台操作插件按需加载。不预装 MT5、QMT、vn.py、AKShare 或它们的依赖。没有行情后端时也可以读取用户文件、计算和发布报告。

## 打开、关闭与更新应用

桌面启动时先显示开屏动画，工作台就绪后自动进入；动画会参考近期启动耗时调整播放速度，不能用动画进度判断任务或行情是否就绪。长时间未进入工作台时可继续等待，或使用开屏上的“重新启动”。

关闭主窗口会保留后台运行。点击系统托盘里的 Sesame 图标可重新打开；没有可用托盘的平台会保留任务栏最小化入口，macOS 也可从 Dock 打开。需要完全退出时使用托盘菜单“退出 Sesame”；关窗口不等于结束研究或退出应用。

支持应用更新的桌面版本会在后台检查并下载；在用户设置查看当前版本与更新状态，点击“重启并更新”才安装。存在运行任务时先完成或暂停，再更新。应用更新保留聊天、报告、插件和配置；开发运行或不支持自动更新的构建按界面提示处理。

手动备份时，先完全退出应用，再复制实际使用的数据目录和工作区；若工作区被单独放在其他位置，也一并备份。复用原数据启动新版时沿用这两个位置，不用新的空目录替代，不只备份程序文件。

## 按任务安装后端

打开右上用户设置 → Agent 插件 → 浏览插件与更新，按名称搜索并选择安装或更新。客户端核对应用兼容性、来源和内容后安装；版本与内容都相同无需重装。也可把精确 sesame/name 交给主 Agent，通过当前插件管理能力完成。更新保留原三态，失败或取消后先核对实际安装版本。真实可用性还要分别验证依赖、连接和所需工具。

装好后在“配置与密钥”查看插件声明的字段与消费能力；未声明的设置按该后端现有入口管理。纯知识包不需要添加无用密钥或运行服务。插件更新与 Sesame 应用更新是两个独立操作。

- MT5：先复用已有终端/MCP和编译环境；配置或启动须是当前任务的一部分，安装插件本身不执行这些动作。
- QMT：需要用户已有授权 Windows MiniQMT 环境；其他平台不能据契约测试声称原生可用。
- AKShare：复用原生 Python 与固定依赖，行情源和轮询时效以实际返回为准。
- vn.py：固定数据加策略源码运行真实 CTA 回测；不因此获得实时交易账户或 SVL 数值等价证明。

## 工作文件与成果

Agent 可以读取任务工作区，也可按任务访问本机其他文件，均使用当前用户权限。复用已有配置，确认缺项再准备持久插件环境，不自动提权或覆盖未知配置。主工作区保留；子任务结束前发布报告、策略和必要固定数据，临时文件随后清理。
