# 常见问题：给下一步，不堆错误

| 现象 | 最短排查与解释 |
| --- | --- |
| 找不到聊天或研究栏 | 三个窗口在同一横排，可能在屏幕外。离开输入框后按左右方向键，或让主 Agent 定位需要的窗口。 |
| 滚轮只缩放、不向下走 | 指针在图表绘图区是预期行为。移到缝隙、空白边缘或图表之外再滚动页面。 |
| 不小心滚动页面，想放大 K 线 | 把指针放回实际绘图区，或用该图组件栏的 ＋ / －。 |
| 图拖不动 | 确认未锁定、已展开、已从最大化恢复；双击时第二下按住再移动，或用拖动把手。不要在输入框或按钮上尝试双击拖图。 |
| 一条缝拖动了多张图 | 连续缝隙调两侧整个区域，符合平铺规则；不是每个细小交点都独立控制。 |
| 拖动回退或拒绝 | 可能仍有其他客户端/用户在调整、图被锁定或版本已变化。先读取当前状态，再重新做一次；Agent 不应循环覆盖用户操作。 |
| 一张或一组图消失 | 可能收起、关闭、被压到零，或在滚动范围之外。先查现状；收起可展开，关闭可重新添加。没有可承诺恢复任意旧布局的撤销按钮。 |
| 图表组件栏不见 | 把指针移到对应图内，或用键盘聚焦；收起图只有简化控制条。 |
| 没有行情或一直加载 | 先查已安装并启用的行情插件、实际 provider/connection、精确品种与周期、来源状态和请求结果。通用默认包不附带行情后端；缺少时按任务显式安装。已有插件配置可以复用，认证是否必需由该来源决定，不反复索要密码。 |
| 本地 MT5 / MCP 未连接 | 先检查已配置的 MT5 终端是否开启；在本次任务已有授权内启动或恢复，再验证插件连接、账户和报价。不要只反复重连，也不要因此切换账户或重放交易。 |
| Agent 说缓存不可用 | 分别核查提供方的缓存能力与实时连接。MT5 有自己的缓存入口；未发现通用缓存工具不能证明本机没有缓存。已有数据是否能用于研究，按品种、周期与实际覆盖范围判断。 |
| MetaEditor 未启动 / 市场数据未启用 | 若当前只是看券商行情，这是可以正常出现的状态，不要求全部连接。 |
| 显示已安装或已保存密钥，但做不了任务 | 环境存在和认证资料存在还不是实际调用成功。按该任务检查所需服务、工具或账户，而不是笼统称整个 Agent 不可用。 |
| 已安装，但模型不知道这项能力 | 查 Agent 插件的三态。可发现不会自动加入工具和 SKILL 正文，需按任务显式发现、读取或加载；希望默认可见时改默认挂载。不可使用不能绕过。 |
| 插件更新失败或取消后版本不确定 | 先刷新当前版本和状态；校验/激活失败保留旧版，取消可能晚于提交。不要直接反复安装；需要回退时在详情核对可回滚版本。 |
| 临时改流程后，后续任务也跟着变了 | 读取 user/workflow 正文和版本，检查是否误存成长期偏好；根据真实用户要求修订。当前一次调整应只进入本次冻结计划。 |
| 改了代码没有曲线 | 检查该图已有行情、脚本是否返回有效序列、是否报错、是否放在副图或当前视野之外。Agent 先修复脚本并查回执，不能把发布成功当渲染成功。 |
| @ 列表为空 | 看 Research / Strategy 分类与名称筛选，确认已有报告；@ 不用于选择文件、品种或 subagent。 |
| /clear 不能使用 | 等当前生成结束，或先按停止并等待停止完成；/clear 本身不会取消生成。它只清屏，不清上下文或记忆。 |
| /skill 没执行预期流程 | 查完整名称、当前会话是否已加载所属插件及主/子范围。不存在的名称是普通文本；按需加载后重试，不绕过禁用策略。 |
| 生成失败或显示重试 | 看实际模型错误：认证、余额、限额或网络等。供应商设置保存成功不证明能回复。已有完成操作先核对，不盲目重放有副作用的步骤。 |
| 研究暂停或中断，怎样继续 | 先读取原任务的状态和具体阻碍，修复后恢复原任务，复用已完成的阶段成果；不要重开同一研究或重放已完成操作。不要把结束后的清理规则套到暂停任务。 |
| 任务结束后找不到临时文件/子任务过程 | 已结束子任务可能已清理临时工作区和过程对话。到研究/策略成果和主工作区找封存产物，并核对该任务的实际清理状态；需要继续时基于保留成果新开一轮。不能承诺恢复已销毁的中间过程。 |
| 设置不能保存或模型没立刻改变 | 先区分等待应用、版本冲突、认证失败与任务占用。Agent 提交的模型变更可能排队等待当前回复结束；随后核对实际模型，不重复提交。需要等待时保留当前任务，不擅自取消别的任务。 |
| 关闭窗口后任务仍在运行 | 桌面主窗口关闭后保留后台，这是预期行为。托盘图标可重新打开；要完全退出则使用“退出 Sesame”，不是反复点窗口关闭。 |
| 启动停留在开屏 | 工作台准备好后才切换；长时间未完成时可继续等或点“重新启动”。先检查具体启动错误并保留原数据，不把空白新工作区当成恢复。 |

排查用真实返回值，回答只保留用户能理解的原因与下一步。不能确认时说尚未确认；不要编造连接、数据、渲染、回测或清理成功。
