# 设置与插件连接

右上用户设置提供语言、主题，以及“模型与运行状态”“Agent 插件”“配置与密钥”。在 Agent 插件中打开“浏览插件与更新”搜索官方目录、安装插件或检查更新，也可从这里进入“配置与密钥”。策略与回测报告从报告目录的 Strategy 分类查看。

## 安装与更新

选择目录里的插件和版本，客户端检查应用兼容性，下载并校验后安装。界面显示当前安装版本和可更新版本；同版本但内容不一致时先核对来源，不覆盖。更新保留原来的插件三态，包括不可使用状态。

请求未完成或取消后，先核对界面刷新的实际版本；取消不保证提交尚未发生。校验或激活失败保留原可用版本，已有历史版本可在插件详情回滚，也可卸载。回滚版本不等于撤销插件此前造成的文件、账户或其他外部副作用。

也可直接让 Sesame 查找、安装或更新指定插件；本机插件包需要先验证再安装。具体调用方法由 `sesame/plugin-manager` 的 `manage-plugins` 技能维护。结果不明时先核对当前状态，避免重复提交。

## 三态决定自动上下文

| 状态 | 对 Agent 的含义 |
| --- | --- |
| 默认挂载 mounted | 在适用会话自动装配公开能力、提示和 SKILL 入口正文；参考文件仍按需读取。 |
| 可发现 discoverable | 能力和 SKILL 正文不自动进入上下文；主 Agent 可显式发现、读取或加载，再按任务调用。 |
| 不可使用 disabled | 禁止执行、加载或读取插件知识；管理界面仍能读取状态并调整策略。 |

可发现与未安装不同。显式会话加载也不等于把全局策略改成默认挂载；策略变化会清除旧会话加载。子 Agent 只获得明确选择的知识和 allowedCalls 指定的工具，不能借发现、读取或再次委派扩大范围。

## 配置与密钥

统一入口列出字段含义、是否为密钥、配置状态及依赖它的能力；按实际任务编辑、检查、保存或显式清除。密钥只显示是否已有配置，不回显已存值，未编辑的密钥保持原值。不要把凭据写进聊天、报告或长期记忆。

字段属于原插件并复用原配置存储和版本检查。是否必填按消费能力与本次输入决定：某个收费来源缺密钥，不应阻止无需该密钥的本地计算或公共来源。当前统一声明覆盖以目录实际返回为准；没有声明的后端继续使用其现有配置能力，不能声称所有设置已集中完成。

保存成功只证明配置已记录，认证、运行环境和连接健康需要实际检查。MT5、QMT、AKShare 和 vn.py 分别核验，保留原来源、连接与账户身份；改配置不能静默换掉已冻结的执行账户。当前任务因缺配置中断时，补齐后核对原任务的中断原因并按原目标恢复，避免另建重复执行；不自动恢复历史暂停任务。

模型与偏好可通过界面查看和修改，也可让 Sesame 使用配置插件处理。模型修改若显示等待应用，需等当前运行回复结束后核对实际结果，不在同一轮反复提交。界面提示设置被占用时先保留当前任务；具体原因以返回结果为准。已授权且可自行修复的依赖直接处理；只有缺少用户资料或决定时才请用户补充。
