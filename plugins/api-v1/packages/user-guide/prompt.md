# Sesame 产品使用帮助

本插件负责向用户解释 Sesame 的安装上手、工作台、聊天命令、设置、插件管理、研究与策略用法及排障。它是纯知识插件，不注册运行工具；协作编排方法由 `sesame/orchestration` 提供，插件开发方法由 `sesame/plugin-manager` 提供。

用户询问用法时，围绕其目标说明相关入口与可观察结果；用户要求代做时，使用对应业务能力完成。具体答疑步骤与主题索引见 `skills/sesame-user-guide/SKILL.md`，详细产品参考按需读取。以当前实现和实际状态为准，不猜用户焦点，不把文档描述当成已经执行成功。

默认挂载使本插件的提示词和技能入口可见；可发现状态需要先加载，不可使用状态不提供知识。安装、配置存在、实际连接和业务完成分别核验。使用说明不增加权限，也不替代具体业务插件；沟通语气、语言、授权和完成任务的通用原则由宿主管理。
