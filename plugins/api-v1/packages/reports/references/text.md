# 文字职责与图文编辑

## 面向读者组织

读者需要理解市场及自己的问题。用初稿中的事实、证据、解释和条件重新组织成文，而非把研究记录原样发布。开头直接回答，正文按发现及其相互关系推进，不按工具、数据源或子研究的执行顺序罗列。原结构已有清楚主线就沿用，不强行换模板。

每段集中讲清一个判断：先让读者知道要点，再用关键证据解释其依据与意义；信息顺序随问题调整，不是固定三句格式。相邻段之间建立实际的支持、转折或递进，不用“此外、值得注意、综上”等空泛连接代替关系。列表只用于并列项目、选择或步骤，不能代替连续分析。

图承担比较、位置、分布与条件的展示，文字解释发现为何重要、不同证据怎样共同支持或限制判断。图内重点和相邻段落要说同一件事，避免一边画原始值、一边在正文讨论未标出的阈值或差距。正文只引用解释所需的关键数字，不再逐点复述图；同一数字不在首屏、图、表和段落中反复排队。

## 准确而自然

- 用具体对象与动作解释，保留金融术语；专业读者熟悉的术语无需逐个科普，少见缩写首次用短语说明。不要把概念改成含糊的口语或夸张比喻。
- 先说证据支持的判断，把会改变理解的时点、条件或反例放在相关发现旁，只交代一次。保留原意是保留判断及其成立条件，不是保留初稿的每条否定句或核查记录。缺口确实影响本题时，说明它改变了什么判断；无关缺口留在研究记录。
- 区分已发生事实、机制解释和未来条件，用词强度与证据一致。历史数据支持历史解释，延续到未来要保留条件；标题、lead、highlights 不能比正文更确定或更新。不能为了流畅把“可能”改成“将会”、把相关改成因果。发现原稿本身矛盾，交研究者复核。
- 日历、持有期、数据截止等影响判断的时间应保留，以读者需要的精度表示。除非秒级信息影响判断，不把抓取时间精确到秒塞进开篇；不能混淆观察、发布时间和预测期限。
- 冻结记录、共同证据代号、Agent 分工、工具调用和校验状态留在已有成果引用中。确需提供下载时用“历史样本明细”等读者能理解的标签，隐藏内部代号不改变文件身份。无需新增方法、限制或附录章节来安放所有内部记录。

## 条件服务于判断

检查限定句时，问“去掉它会让读者误解哪一项具体结论？”有明确影响就保留这项影响，没有就删去这句，而不是统一换成更委婉的否定或挪到折叠块。

- 初稿已有观察条件时，直接写观察对象、触发变化与对应判断，或放进现有条件树。不要在树后再解释每条路径为何尚未成立，也不要添加“行情不会每小时如此”“日历可能调整、不能覆盖所有意外”等通用防御。确有时间变更或遗漏的关键事件则说明具体影响。
- 历史解释与未来条件用时点和条件句区分。数据缺口直接改变结论时，简短说明一次实际影响；不能把“没有查到”改写成“没有发生”，也不能把尚未确认的条件写成已满足。缺少目标价依据就不补造目标；用户明确要求目标时，应直接说明目前可支持的范围与精度。
- 材料的范围用正面信息表达，例如会议日期、讨论主题和重点观察项。未取得、与本题无关且未用于判断的材料，不逐项列出来证明自己没有误用。已有反证或会推翻主判断的关键未知仍须保留；“没有新增鹰鸽判断”“保留全部案例”等作者自述不代替市场信息。

仅编辑初稿时不引入新研究结论；确需补证的事项交回研究环节，不把内部待办变成报告正文。

## 表达示例

下例只演示如何编辑已有材料；其中数值不得复制为其他任务的证据，也不是必填写作模板。

| 初稿表达 | 面向读者的表达 | 编辑目的 |
| --- | --- | --- |
| “已冻结样本13涨10跌，少数大跌拖累均值为负；本轮均线条件未核实，不能当作本次胜率。” | “这组历史样本中反弹次数较多，但少数大跌使平均收益为负，反弹机会与尾部风险并存。本轮与这组样本的均线条件匹配仍待确认。” | 将计数与均值的张力解释清楚，保留影响参照价值的匹配缺口；图同时呈现次数与收益分布，不改成未来概率。 |
| “截至12日实际收益率回升、持金机会成本增加，可解释此前下跌；研究判断若未来美元和实际收益率续升，反弹可能受压；17日尚未核实延续条件。” | “截至12日，实际收益率上升提高了持有黄金的机会成本，有助于解释此前下跌。未来几天重点观察美元和实际收益率：两者若继续走高，黄金反弹仍可能承压。” | 时点限定历史解释，观察与条件句保留未来尚未确认的含义；不再额外附一句核查待办，也不把宏观条件写成已经成立。 |
| “A模块验证价格从近期低点回升，B模块给出第一道修复区；当前价格仍在该区下方，站稳与否待观察。” | “价格从近期低点回升，但仍低于第一道修复区，反弹能否站稳尚待观察。” | 对象改成市场，保留初稿已有路径；主图同时标出实际低点、当前值与修复区，读者无需跨段找数字。 |
| “营收增长8%、利润增长20%、毛利率提高2个百分点；初步分析毛利改善可能贡献了利润增长，但尚无贡献分解。” | “利润增长快于收入，毛利率改善可能是原因之一。” | 图显示不同量纲，正文表达已有联系；“可能、之一”保留归因强度。若用户追问贡献金额，再说明尚无分解，不能补出份额。 |
| “纪要对应10月27—28日会议，早于本次CPI，不能解读为CPI后的50基点承诺；看点是紧缩讨论和成本权衡是否超出已知。另一场讲话尚未取得，日历可能调整。” | “纪要记录了10月27—28日、此次CPI公布前的讨论，重点看紧缩幅度与成本权衡是否超出已有信息。” | 直接交代适用时点和阅读重点；未用于判断的讲话缺口与通用提醒留在工作记录。 |

## 展示位置

title 是页面标题，section.title 标识问题或发现，chart.title/table.caption 给视觉命名；相邻同名标题自动去重，不用多层同义标题。完整报告的 lead 是直接回答核心问题的一小段，highlights 随后展示 1–6 项简短标签和醒目数值或定性结果。最后依据完成的正文校准首屏，不能用 summary 替代 lead；summary 只作索引元数据。

正文与必要解释用 paragraph/markdown。一句已有重点可用 judgment，并列判断可用 judgments；不把每段都做成卡片。图内只留标题、轴、图例、单位、数值标签和节点/连线含义，长解释在相邻正文，不重复成图注小字。formula、metrics、range、scores 不接收独立 note/caption。

出处用实际链接、固定 references 或确需下载的 attachments 保留。details 只放读者确需查阅的明细，默认收起；内部研究记录不自动变成读者明细。维持现有背景与蓝灰强调，涨跌/盈亏红绿保留，不以文字改写改变金融颜色含义。

## 成品通读

用户只看成品，是否知道主回答、核心依据及会改变判断的条件？段落能否自然接续，图内重点是否与邻近判断一致？合并重复、重写不清楚的句子，再与初稿核对事实、数值、时点、反例及条件。保留有用信息，不以字数、图数或禁词计数替代编辑判断。
