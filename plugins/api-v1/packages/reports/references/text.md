# 文字职责

报告 title 是页面标题，section.title 标识章节，chart.title/table.caption 给视觉命名。相邻同名标题自动去重。

报告正文开头直接给出回答用户核心问题的一小段关键结论，再展示支撑它的图表、证据和解释。用 paragraph/markdown 或一句 judgment 即可，无需固定“摘要”标题；目录、背景与工作过程不占据开头。

正文与必要解释只用 paragraph/markdown。一句重点可用 judgment，并列已有判断可用 judgments。图表标题后不重复结论、来源小字、通用说明或工作过程。formula、metrics、range、scores 不接收独立 note/caption；需要用户阅读的内容放正文。

图表承担各组数据证据，正文解释最重要的发现、原因与决策意义。解释放在对应图表附近，只引用理解结论所需的关键数字；不先用长段落复述全组数据，再画同一组数据。完成后检查正文里的数字串：若它们仍在承载一组比较、范围或敏感性结果，应移到对应图表中，保留简短解释。

轴、图例、数值单位、数据标签、节点和连线含义属于图本身，按需保留。金融术语可以使用；工程状态、数据处理过程和无信息量的免责声明不写入页面。

出处以实际链接、固定 references 或用户需要下载的 attachments 提供，不自动添加附录/来源页。details 仅放用户确实需要展开阅读的明细，默认收起。主题强调为蓝灰，涨跌/盈亏红绿保持；不因负数把回撤、净值改成盈亏色。
