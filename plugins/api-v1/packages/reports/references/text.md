# 文字职责与图文编辑

## 按问题组织文章

读者需要先得到自己问题的答案。编辑前安排全文骨架：本次要回答什么，主要判断是什么，哪些论点支持、限制或改变它。开篇和紧接的正文先完整交代主回答及必要条件，后续再解释依据；不能用一句方向性 lead 代替用户真正需要的判断信息。前景问题先交代前景与改判条件，原因问题先讲主要解释，对比问题先交代取舍，结构随问题而变。

正文按论点及其关系推进，不按工具、数据源或子研究的执行顺序罗列。每节有明确任务；同一节需要分别解释支撑因素、相反证据或补充机制时，用简短小标题分清这些任务，而不是将它们压缩到一大段。标题说本次实际的问题或发现，不把“支持—反对—总结”变成所有报告的固定章节。

连续解释用段落：一句点明中心意思，证据与必要解释展开，再交代它与下一论点的关系，不机械套三句模板。可独立浏览的并列证据或选择用列表；要逐项横向比较的情景、取舍和精确数据用表格；变化、分布、模式及复杂关系用图。段落、列表、表格和图表可以共同完成一个论点，不默认全文段落，也不为增加形式数量切碎推理。

编辑目标是降低理解成本。减少文字后若不同论点挤在一起，就应重新分层，必要时补一句衔接或解释；不把篇幅更短当成质量更高。相邻段之间说明实际的支持、转折或递进，不用空泛连接词代替关系。

图承担它比文字更清楚的展示任务，文字解释发现为何重要、不同证据怎样共同支持或限制判断。图内重点和相邻论点要说同一件事：比较差距就让差距可见，讨论阈值就有对应参照。图标题可直接点明有依据的发现；必要单位、时间范围和图形编码由轴、图例或已有标签交代，不强制每图另外写一段结论与图注。正文只引用解释所需的关键数字，不逐点复述；同一信息不在图、表和段落重复排队。

## 向读者重新解释

初稿提供事实、判断及其依据，不限定成品的句子。用自然中文重新向具有基本金融知识的读者解释同一份研究，允许重组句子和段落。先想清楚这一段要让人明白什么，再写它；只替换几个词、压短句子或保留原来的概念串，未必完成了重写。

- **写出对象和动作。** 说明什么价格、公司、机构或政策发生了什么变化，再用必要术语概括。让“谁、怎么变化、意味着什么”在句子里可见，不让“主倾向、条件性约束、判断更新”等名词替代整个解释。这些词不是禁词，有精确含义时仍可使用。
- **展开初稿已有的推理。** 写清发现为何重要、已有机制怎样连接事实与判断；需要补一句解释就补，不要求每句都短。金融术语保留，少见概念首次以短语交代；不要为了口语化改成含糊比喻。解释仅展开原稿已有含义，不能另添市场心理、政策期限或新因果。
- **直接给出判断。** 原稿支持偏空就说偏空，支持哪条主要路径就说明哪条路径。不用多层委婉语压低已有判断，也不为顺口把“可能”改成“更可能”或“将会”。把不确定性写在实际相关的价格、时间与条件中，不把主判断、所有反例和核查事项挤成一句话。
- **讲市场意义。** 正文解释行情、企业表现或投资选择，不向审查者叙述自己如何取数、排除误用和完成复核。样本归属、单位、区间等必要口径可由图题、分组或标签清楚交代，正文解释结果的差异；确实改变结论的限制仍在相关发现旁说明一次。
- **保留时间和强度。** 区分事实、已有机制与未来条件。相对时间以报告观察时点为准，不因生成日期改变“上周/本周”；跨事件的统计窗口不能全部描述为事件之后。分支的精确阈值和且/或关系不能为顺口而缩约；标题、lead、highlights 与正文同样遵守。历史分化不自动证明未来无规律，相关和频数不变成因果和概率。发现原稿本身矛盾，交研究者复核。

冻结记录、共同证据代号、Agent 分工、工具调用和校验状态留在已有成果引用中。确需下载时用“历史样本明细”等读者能理解的标签，隐藏内部代号不改变文件身份。日历、持有期、截止时间保留到影响判断的精度；通常不用抓取到秒的时间。无需新增方法、限制或附录章节来安放所有内部记录。

## 条件服务于判断

检查限定句时，问“去掉它会让读者误解哪一项具体结论？”有明确影响就保留这项影响，没有就删去这句，而不是统一换成更委婉的否定或挪到折叠块。

- 初稿已有观察条件时，直接写观察对象、触发变化与对应判断，或放进现有条件树。不要在树后再解释每条路径为何尚未成立，也不要添加“行情不会每小时如此”“日历可能调整、不能覆盖所有意外”等通用防御。确有时间变更或遗漏的关键事件则说明具体影响。
- 历史解释与未来条件用时点和条件句区分。数据缺口直接改变结论时，简短说明一次实际影响；不能把“没有查到”改写成“没有发生”，也不能把尚未确认的条件写成已满足。缺少目标价依据就不补造目标；用户明确要求目标时，应直接说明目前可支持的范围与精度。
- 材料的范围用正面信息表达，例如会议日期、讨论主题和重点观察项。未取得、与本题无关且未用于判断的材料，不逐项列出来证明自己没有误用。已有反证或会推翻主判断的关键未知仍须保留；“没有新增鹰鸽判断”“保留全部案例”等作者自述不代替市场信息。

仅编辑初稿时不引入新研究结论；确需补证的事项交回研究环节，不把内部待办变成报告正文。

## 研究记录如何改写

下例展示相同信息如何重新组织；数值和判断仅属于各自示例，不得复制为其他任务的证据。左栏包含改写所用的全部事实与解释。右栏可以与图表共同表达，数字仍在图或正文保留；不是要求报告套用这些句子。

| 研究记录式表达 | 面向读者的表达 | 转换要点 |
| --- | --- | --- |
| “未来72小时偏空，较支持反弹受压后再试3831附近，同时保留修复窗口。” | “未来三天偏空。金价可能在反弹遇阻后再次回落至3831美元附近，但仍有向上修复的可能。” | 主判断与可能路径分别说清；实际改判条件在紧接的正文交代，不凭此句补造条件。 |
| “当前价仍低于3876.75—3880.70；第一道修复区用于检查反弹进展。” | “金价还没有回到3876.75—3880.70美元。接下来先看能否重新站稳这一区间。” | 把变量用途改成可观察的价格变化，保留精确区间；不升级成确认反转的门槛。 |
| “若持续收复3901.40—3923.35，且美元、实际收益率回落，则改判为修复上行。” | “如果金价重新站稳3901.40—3923.35美元，且美元与实际收益率回落，短线判断就转为金价继续回升。” | 一句写清触发与判断，保留联合条件；不拆成互不相干的提醒。 |
| “周跌幅没有呈现全部回撤；周一上涨，随后四天连续回落。” | “金价周一上涨，随后连跌四天。周一的涨幅抵消了后面一部分跌幅，因此只看全周涨跌，容易忽略后半周跌得有多深。” | 展开同一组涨跌关系，不用抽象评价代替过程。 |
| “官员表示若核心通胀达到一定水平应考虑加息50基点，使市场重估更强紧缩的理由更具体。” | “这位官员提出，如果核心通胀达到相应水平，应考虑加息50基点。讲话给出了考虑更大幅度加息的具体条件。” | 用发言者与发言内容解释，不补写市场开始相信什么，也不改成政策承诺。 |
| “实际收益率上升、持金机会成本增加，支持利率压力解释；黄金不支付利息。” | “黄金不支付利息。有息资产的实际收益提高后，持有黄金的机会成本也随之增加，这有助于解释金价为什么承压。” | 展开原稿已给出的机会成本机制，不把实际收益换成名义利息，也不写成唯一原因。 |
| “官员已讨论继续加息的成本，政策讨论并未只剩进一步加大幅度这一条方向。” | “不过，也有官员在讨论继续加息的代价。” | 把多重否定改成具体行动；不添加态度转向的起始时间。 |
| “上周CPI和鹰派表述已有进入价格的机会。” | “市场已经有时间消化上周的通胀数据和鹰派讲话。” | 说明信息已公布一段时间，不升级为已充分计价。 |
| “偏弱倾向来自低点下移及美元、实际收益率的条件性约束；若两者续升，反弹可能受压，最新方向未核实。” | “金价低点继续下移，是目前偏空的依据。接下来若美元和实际收益率继续走高，黄金反弹还可能受到压制。” | 分开已知价格事实与未来条件，不把尚未取得的数据写成当前事实。 |
| “近期三例已包含在23例中，同组样本内部存在分化：明显反弹、小涨、继续大跌。” | 图中标明“23例，其中近期3例高亮”；正文写：“最近三次类似急跌之后，一次明显反弹，一次小幅上涨，另一次继续大跌。仅看这三次，急跌后的方向并不一致。” | 图承担样本归属，文字解释行情差异；三例分化不外推为市场不存在稳定规律。 |
| “样本13涨10跌，少数大跌拖累均值为负；本轮均线条件未核实，不能作为本次胜率。” | “这组历史样本中，上涨次数比下跌多，但少数大跌仍使平均收益为负。次数占优，并不意味着平均能赚钱。本轮是否符合这组样本的均线条件，还需要确认。” | 解释次数与收益为何不同，保留影响本次参考价值的缺口；计数同时见图，不转为预测概率。 |
| “营收增长8%、利润增长20%、毛利率提高2个百分点；初步判断毛利改善可能贡献了利润增长，尚无贡献分解。” | “利润增长快于收入，毛利率改善可能是原因之一。” | 图保留三项数字及不同量纲，正文解释已有联系；不补出贡献份额。 |
| “10年实际收益率11月6—12日升23基点，与11月10日CPI后的金价压力吻合。” | “11月6日至12日，10年期实际收益率上升了23个基点。这段时间跨过11月10日CPI公布日，利率走高与金价承压的方向一致。” | 如实交代统计窗口，不把整段变化说成数据公布后发生或由CPI造成。 |
| “纪要对应10月27—28日会议，早于本次CPI，不能当成CPI后的加息承诺；看点是紧缩幅度和成本权衡。另一场讲话未取得，日历可能调整。” | “纪要记录的是10月27—28日、此次CPI公布前的讨论。重点看官员怎样考虑加息幅度，以及继续加息的代价。” | 具体讲阅读重点和会期；未用于判断的讲话缺口与泛泛日历提醒留在工作记录。 |

## 展示位置

title 是页面标题，section.title 标识问题或发现；章节内小标题用 markdown 的 ###，列表也可放在同一 markdown 块中。小标题与紧邻 chart.title 不重复同一句话，Markdown 标题不会参与图题自动去重。chart.title 可点明图中有依据的发现，table.caption 可选。完整报告的 lead 直接回答核心问题，highlights 随后展示 1–6 项简短结果；必要条件在紧接的正文展开，不藏到全文末尾。最后依据正文校准首屏，summary 只作索引元数据。

正文与必要解释用 paragraph/markdown。一句已有重点可用 judgment，并列判断可用 judgments；不把每段都做成卡片。图内只留标题、轴、图例、单位、数值标签和节点/连线含义，长解释在相邻正文，不重复成图注小字。formula、metrics、range、scores 不接收独立 note/caption。

出处用实际链接、固定 references 或确需下载的 attachments 保留。details 只放读者确需查阅的明细，默认收起；内部研究记录不自动变成读者明细。维持现有背景与蓝灰强调，涨跌/盈亏红绿保留，不以文字改写改变金融颜色含义。

## 重写后另读一遍

先逐段审读，不边写边默认它已合格：这一段要让读者明白什么？是否直接说出来了？读者能否跟上已有的理由？具备金融知识的人会这样向读者解释吗？遇到合乎语法却生硬的句子，指出具体问题并改写，例如主语缺失、抽象名词代替动作、多个意思挤在一起、推理跳步、多重否定，或把核查过程当成市场信息。不要只要求“再简洁一点”。

再连读全文：只读开头是否已得到主问题的回答及关键条件？小标题能否分清论证，段落能否连起来？图是否让相邻判断的依据可见，还是只摆原始值？检查需要分层的长段、需要连接的碎片和重复的图；修改后对照初稿核对事实、数值、时点、反例及条件，特别检查顺口的改写是否悄悄增加了确定性或新解释。审读属于同一个图文编辑步骤，不要求增加独立 Agent，也不输出审读清单。不以字数、图数、列表或禁词计数替代编辑判断。
