---
name: visual-compose
description: 将已有文字、数值和关系组织为报告或回答的统一视觉组件。
---

1. 先安排支撑关键结论的数据视觉，再写解释。主要论据中的比较、趋势、区间、分布、构成和关联必须实际入图，不能停留在数字段落或表格；合并回答同一问题的数据，再按关系选图型。区间端点与参照放同一范围/位置图；同单位的有序序列合为多线；两个状态的差距用哑铃，连续敏感性用折线，增减贡献用瀑布，关联用散点，类别大小才用柱形。不默认逐指标画柱形图，也不为凑种类换图。不熟悉时按关系查询 components_list，再 describe 所需组件。
   原值与变化率、基准与目标优先结合在同图的必要标签中；重复推导出的表达不再独立占图。单位不同且必须对照时用共享顺序的并排小图，明确各自尺度；不能强放同轴。单个事实可用文字/指标，精确查数才另配表格。
2. 完整报告一次提供 title、lead 和正文 content.sections；component/components 便捷形式同样加 title、lead。lead 用一小段直接回答用户问题，渲染在标题后、章节前，不另写摘要标题。正文按本次问题展开，无编号、无固定业务章节；target=answer 的独立组件不需要报告骨架。图表与对应解释相邻，正文补充主要发现、原因和意义，不复述整张图。说明只放 paragraph/markdown，图内只留简短必要标签；合并图表后不把冗余数字串挤进标题，可从图直接读出的派生表达不必全部列出。数据用实际 rows 或已声明固定 data_id，图文同源。
3. components_show 一次展示；target=answer 用于对话内组件，默认 report。需要先检查时用 components_validate。
4. 修改沿用原数据与报告，只修复诊断指出的字段或布局；缺少分析交回生产者，不在视觉层补算或虚构。

完成：确认标题、开篇回答和正文均已实际呈现；逐项对照核心判断和原始结果，确认支撑判断的关键数据关系已用适合的视觉完整呈现，同时检查能否合并重复图；不是有一张图就完成，也不是每组数字各画一张。图型须匹配关系：区间没有被拆成无关类别，变化率没有重复原值占图，敏感性保留既定输入条件。核对基准、端点与参照，单位在实际轴、标题或数据标签可见，数值准确、布局可读。组合见 references/composing.md，数据见 data-binding.md，交互见 interactions.md，文字见 text.md。
