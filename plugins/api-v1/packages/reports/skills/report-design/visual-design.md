# 图型选择与蓝灰视觉

按「要回答的问题 → 已有证据 → 图形编码」设计报告。参照用户提供的《全部图型与配色指南》的蓝灰与编辑式图表原则，保留 Sesame 的字体、页面底色和章节骨架。下面是独立实现的适配规范，不包含上游模板代码，也不表示原指南的全部图型都已经内置。

## 选择图型

一张图回答一个独立问题。报告可以组合时间、位置、对比、分布、日程和决策结构；不要只把所有信息改成折线，也不要为凑图数重复同一结论。数据只适合一种图时就用一种。

| 问题和真实数据 | 推荐表达 | 实现与边界 |
|---|---|---|
| 单序列的走势；趋势与参照序列 | 细线折线，直接标注末值 | `reportKit.chart` 的 `line`；缺失留空，序列时区明确，不用双纵轴制造关联 |
| 一个周期内的开高低收 | 默认行情蜡烛图 | 直接调用 `candlestick`，见 [行情图契约](market-charts.md)；复用工作台 Lightweight Charts，不重画 SVG 或空心样式。四个价格必须确实存在；涨跌沿用原红绿色 |
| 当前值与支撑、阻力、阈值的位置 | 共同数值轴上的区间与点标记 | `custom`；位置按价格比例，不把各价位等距画成量尺。长标签独立排布 |
| 分类数量或排名，尤其长中文 | 刻线横排、单位点阵或水平条 | `units` 或 `hbar`；每单位含义一致、柱从零起。不把聚合点冒充个体记录 |
| 同口径的前后或成对比较 | 哑铃图 | `dumbbell`；连接的是两个比较值，不伪造中间时间轨迹 |
| 起点如何经增减得到终点 | 瀑布图 | `waterfall`；增减能对账，不用于无序类别 |
| 逐条观测的离散与尾部 | 散点条、直方图、箱线图 | `strip` / `histogram` / `boxplot`；写明样本、分箱和分位定义 |
| 多组连续分布的差异 | 山脊或小提琴 | `ridgeline` / `violin`；有固定密度结果、带宽和样本数，少量样本改用原始点 |
| 日期上的覆盖、数量和异常 | 日历；少量已知事件用日程轴 | `calendar`；日程轴用 `custom`。未知精确时刻就显示日期区间，不补时间和零值 |
| 同一批对象的多维差异或排名变化 | 平行坐标、排名线 | `parallel` / `bump`；共享对象全集、单位和并列规则，交叉不是因果 |
| 非负总量中的层级构成 | 矩形树图 | `treemap`；父子不重复计数，不画负权重 |
| 已记录的路径、守恒流量、关系 | 交易链路、流向、网络 | `threads` / `flow` / `network-*`；需要真实关联，不用关系图制造因果 |
| 如果条件成立，下一步观察什么 | 条件决策树 | `decision-tree`，见 [参数与例子](decision-tree.md)。判断在内部节点，条件在分支，叶子只写结果或行动；不添加未经估计的概率 |

先查 [现成图表完整目录](chart-catalog.md)，复用已有 kind 和默认样式。只有事件轴、价格位置区间等尚无独立 kind 的表达需要在 `custom` 中补充，不需要改宿主接口或添加联网图表库。参考图型的名称不是可直接传入的 kind；用 `SesameCharts.kinds()` 核对当前已加载类型。

## 色彩与版式

`assets/editorial.css` 默认提供以下蓝灰角色，不依赖报告的根节点属性；报告宿主重建文档后仍然生效。宿主主题切换会更新暗色角色。

| 角色 | 浅色 | 用途 |
|---|---|---|
| `--report-data` / `--report-accent` | `#334EAC` | 一个主要序列或重点 |
| `--report-context` | `#787878` | 比较序列和背景对象，只用于图形 |
| `--report-ink` | 宿主正文色 | 标题、数字、关键文字 |
| `--report-muted` | 宿主次级文字色 | 可读的次级文字与轴标签 |
| `--report-line` | 宿主分隔线 | 辅助网格与分隔；重要连线用 context，不能只靠淡网格传意 |
| `--report-ramp-1…5` | `#7586C2` → `#253054` | 有序值或连续大小，配尺度与单位；不是五个无序类别色 |
| `--report-paper` | 宿主背景/表面色 | 与现有页面同底，不采用参考指南的纸灰背景 |

默认 `reportKit` 的前两个系列对应蓝色重点、灰色参照。多个无序类别优先用直接标签、形状、虚线、位置或分面；不可把渐深蓝色当作类别身份。正负收益、警告和行情涨跌继续沿用明确的产品语义，并配文字或形状，不为了蓝灰装饰改写状态含义。

颜色表达盈利/亏损时使用 `--success` / `--danger`，柱图使用 `tone:'signed'`；蜡烛影线、实体与成交量使用 `--chart-up` / `--chart-down` 及对应 volume 色。自定义图同样遵守此规则：深浅绿只有在表达主题或普通序列时替换成蓝阶；盈亏、涨跌的红绿色保持原样。

图表直接落在页面上，用留白、字重、细线建立层级。保留当前背景与主题渐变，报告图内不用卡片底、装饰渐变、阴影或发光。单序列一支蓝色、一个重点加灰色都可以；不为满足颜色数量制造信息。

浅色报告主色和灰色图形在现有浅底上按至少 3:1 检查；正文和小标签按 4.5:1 检查。有序阶至少可辨认，不能借用浅色数据阶写小字。暗色使用 CSS 中独立的浅蓝与灰角色，重新检查实际背景，不把浅色值原样倒过来。

## 阅读与交付

- 长时间标签在轴上简写为日期/时刻，完整值保留在可见说明、明细或提示中；不展示一排重复截断的 ISO 字符串。
- 图题和图注按需要使用：轴、图例或元信息已经给出的单位、区间与读法不重复说明，不添加操作教程。影响判断的条件与数值放在对应位置；来源与完整明细可展开追溯，不让 hover 成为唯一入口。
- 每句话服务于市场理解和下一步决策，不单列泛泛的“时效与覆盖”或检查过程。截止时间与时区放元信息，必要边界写成具体事实或待确认条件，其余口径和来源收进折叠方法区。正文、图注、节点说明和折叠区都去掉无用的免责声明、适用范围及重复否定，避免以搬位置代替删除。
- 条件情景适合做报告最后的主体章节，方法与来源可以继续折叠在末尾。决策逻辑由内部节点和分支表达，叶子不再含“如果、否则、才、失效条件”等嵌套判断；需要继续判断就展开下一层。默认紧凑横向树使用细竖判断标记、小圆点叶子、灰色曲线和蓝色选中路径。窄屏继续保留完整树，通过缩放、拖拽、双击实际尺寸及适配全图阅读；节点文字正常换行，不裁掉失效条件。图内仅保留小型缩放与适配图标，不增加操作教程、百分比或重复路径说明；研究条件、结果和来源正常保留。打印展开全树，PNG 使用初始全图概览，均需检查静态成品的可读性。
- 选择有意义的交互：系列切换、原始记录选择、明细展开。阅读型报告不添加无目的的播放、重播和筛选工具栏。
- 改版复用原报告的固定数据、观测时点与来源；只因重新排版不能把旧证据写成新行情。发布同一报告的新版本，核对桌面/窄屏和明暗主题，检查当前版本的导出能力。
