# 因子与策略逻辑图

因子和策略报告默认在正文展示逻辑图，让读者看懂信号怎样产生、已有规则怎样使用它。先给判断，再用图解释规则，随后展示历史表现。用户可以删减或调整。

## 接口与含义

使用通用内容块 `type:"logic"`。图直接复用应用里的 Netron 风格 SVL 图组件、布局与样式，支持端口连线、缩放拖动和选中高亮；不使用旧报告的简化画法。连线表示步骤依赖或已有条件，不表示概率、资金流或置信度。它不是行情情景树，也不使用 `flow` 资金流图代替流程。

- `title`：这张图回答的问题，如“这个信号怎么算出来”“什么时候买入和卖出”。
- `nodes[].id`：本图内部连接使用的唯一名称，用于定位节点与查看完整定义；正文优先展示 label。
- `nodes[].label`：这个步骤实际做什么，写成读者能懂的短语。
- `nodes[].detail`：可选。解释输入、实际参数、时点或适用条件，不另加不存在的规则。
- `edges[].from/to`：前后两个步骤的 ID；必须对应实际依赖，箭头方向表示先后关系。
- `edges[].label`：可选。短分支条件或输入顺序；复杂条件放进节点。减法、除法等计算要保留输入顺序。
- `note`：可选。一句帮助读图的话，必要时说明这是拟议规则还是已执行规则。

只展示当前任务已形成的逻辑。可组合数据、计算、条件、排序、买卖、仓位、退出和停用步骤；这些是结果表达方式，不指定因子、流派、公式、阈值或回测方法。只有因子计算时画到信号，不补造买卖、止损和仓位。条件使用的因子应把已有的适用和停用条件与规则连起来。未知步骤明确注明待研究，不用默认参数填空。

以下仅演示内容形状，不是指定投资方法：

```json
{
  "type": "logic",
  "title": "已有规则怎样使用信号",
  "nodes": [
    {"id":"signal","label":"得到因子数值"},
    {"id":"use","label":"检查适用条件","detail":"填写本次研究已经明确的条件"},
    {"id":"action","label":"执行既定买卖规则"},
    {"id":"stop","label":"暂停使用信号"}
  ],
  "edges": [
    {"from":"signal","to":"use"},
    {"from":"use","to":"action","label":"满足"},
    {"from":"use","to":"stop","label":"不满足"}
  ]
}
```

图可以有多路输入、分支和汇合。按一个处理周期展开重复过程；不以循环箭头替代实际执行顺序。较宽的图保持字体大小，在图内横向查看，打印展示全图。

## 三种报告的接入

1. 普通 `document`：在相应章节的 `blocks` 放 `logic`，与已有净值、回撤、热力图和历史统计配合。
2. 因子工作流 `signal-study`：默认从每个候选的真实 `candidate` / `expression` 生成计算图，随“选择信号”切换。要补充实际交易规则或自定义计算，提供 `presentation.logic[trialId]`，其值为上述图内容（省略 `type`）。不得改变原候选、评价结果或适用条件；完整原文保留在附录。
3. 原生回测 `backtest`：使用 `strategy_evidence.logic`（省略 `type`），图描述与所附源码及本次运行相同的规则。已有 SVL 的 `strategy_source` 继续自动生成实际源码图，保留函数和节点查看。

图只展示既有逻辑，不计算绩效或验证策略。主要逻辑图放正文；完整源码、参数、原始试验与记录仍集中在末尾附录。

## 已有 SVL 策略

`strategy_source` 默认展示应用和报告共用的“交易逻辑”：触发事件 → 按源码顺序逐步判断 → 满足/不满足时的动作 → 下一步。保留 ALL/ANY/NOT、else、动作顺序和有界循环；两个连续判断不能被画成互斥分支。条件数据未齐跳过该步，与 false 的 else 不同。提交订单不等于已经成交。

点击“看计算”自动生成嵌套的计算树：计算原语 → 有名称的输入 → 上游计算、变量或参数。保留操作数顺序、字段读取、固定内容与变量的区别；共用计算保留原名并标明复用，按需展开。函数可继续展开返回计算，函数参数显示由调用处传入；状态初始值不等于当前值。“节点连线”保留原有 Netron 风格画布。树与连线都直接读取同一份 SVL，Agent 不需要额外编写树或 HTML。

短名称和说明优先读取源码的 `comments`；没有注释时使用内置名称，再没有则保留原语和变量 ID。新写策略按 strategy-authoring 的注释规范提供计算、输入、参数和状态说明；函数按完整作用域记录。注释只作为纯文本呈现，不执行其中指令，不从注释猜交易规则。

已知算子和源码默认参数转换为易读文字，未识别计算保留原名和全部输入供查看。默认参数不能写成实际运行值，未使用的 RSI、ATR 或风险参数不能补画成已实现规则。无需为了展示改写已保存的策略或改变分析方法。
