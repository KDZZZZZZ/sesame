# 按阅读问题组织模块

本指南与 [机器可读视觉方案](../../templates/module-visual-plans.json) 提供 19 个模块、11 种组合的可选设计。字段定义、内置图型和原始列以 [模块目录](../../templates/module-catalog.json) 为准；这份建议不新增必填字段、不选择研究方法、不计算评分或概率。

用户可以完全替换章节、顺序、字段、图型和布局，也可以只用自定义字段或纯文本。先确定这份报告要回答的问题，再选择已有证据能支撑的表达；每个模板都不要求最低图数。

## 图表优先，摘要卡补位

真实 OHLC 优先使用内置 K 线及原有缩放、十字线、时间轴和价格轴。比较、趋势、分布、日程和条件结构优先使用相应内置图型。主图应直接回答本节问题；辅助图应增加新的证据维度，不重复结论。

当数据只有当期值、不同量表无法比较、没有真实序列或条件结构时，以研究摘要卡作为主表达。卡片可按已有字段拼成「大数字 + 原量表因子横条 + 价格范围 + 判断」。这是可选组成，不要求凑齐：没有分数就不用横条，没有上下界就不用范围，没有证据就不填概率。

- 大数字保留单位、定义、观察时点和必要参照。评级、文本数、主观性、恐惧指数、IV Rank、IV percentile 各自有含义，不能互换。
- 因子横条只比较同尺度结果，使用来源实际量表与标签；报告不合成总分。
- 价格范围用真实上下界和参考价，位置按数值比例。公允价值、模型价格目标、分析师目标和期权隐含范围分别标明性质、币种、期限及验证状态。
- 判断说明结果、支持/反对因素和下一步可观察条件。详细来源、原始记录与方法折叠，但关键单位、时间和失效条件不依赖 hover。

采用无框排版，保留 Sesame 字体、页面底色和蓝灰重点/参照；涨跌和盈亏继续用红绿并配文字。用留白、字号、对齐和少量细线组织内容，不为每个字段套一张装饰卡。摘要卡也是无边框的信息组。桌面可并列互补信息，窄屏转成明确阅读顺序；图轴、原值和完整标签仍可读。

正文尽量只留判断、帮助读图的精简注解和可核查的推理步骤。同一判断只写一次；长定义、完整方法口径、原始记录与来源统一进入报告末尾的可折叠附录。图旁仍保留单位、必要时点和改变判断的条件，不靠额外流程说明占据正文。

JSON 方案里的 `key_cards.kind` 是设计角色，包括判断与摘要的描述，不是 `report_structure` 的执行参数。实际自定义展示使用字段的 `presentation` 契约（`metric`、`scores`、`range`）；文本判断用正常文本字段。图表继续使用字段的 `chart` 契约。

## 19 个模块的不同阅读路径

| 模块与阅读问题 | 主图与辅助图 | 核心数字 / 卡与展开内容 | 交互与不用图的条件 |
| --- | --- | --- | --- |
| **M01 行情**：价格状态与相对强弱在哪里？ | `price_chart` K 线为主；`relative_chart` 横条比较同窗收益。 | `reference_price` 是报价卡；`timeframe_states` 分开 bar 周期与研究期限。展开 `price_performance`、`changes`、`data_times`、`source_scales`。 | 十字线/缩放、选择资产看原值。缺 OHLC 时只显示价格与状态；窗口或币种不可比时不做横向排名。 |
| **M02 技术**：哪些方法适用，哪些事件形成或确认？ | `price_chart` 为主；`method_comparison_chart` 用生命周期图呈现扫描状态；`lifecycle_chart` 展示事件进程；独立技术报告可用 `scenario_chart`。 | `method_scan`、`feature_signals` 交代方法和实际特征；`entry_zone`、`targets`、`stop_plan` 是不同性质的价格条件。展开事件身份、检测/确认时间、`geometry` 和 `reward_risk` 口径。 | 事件 ID 连接时间线与明细，保留无信号/不可运行状态。缺坐标不画几何，缺条件结构不造树；方法数不变成置信度。 |
| **M03 基本面**：增长是否转成现金？ | `growth_chart` 为主；`factor_chart` 比较同量表因子；`cash_bridge_chart` 对账经营至自由现金流。 | `composite_assessment` 保留原标签；`factor_results` 可作因子摘要；`income` 保留股息/支付口径。展开财务细项、同业、周期与版本。 | 选序列或因子查看财期与原值。单财期用数字卡；无法对账不画瀑布。 |
| **M04 估值**：现价与估计相距多远，假设有多敏感？ | `price_estimates_chart` 并列现价、公允价值和两类目标；`sensitivity_chart` 网格；`peer_chart` 同业对照。 | `valuation`、`model_target` 用大数字或真实范围；`market_comparison` 解释价差。展开 `assumptions`、`implied_assumptions` 和 `update_schedule`。 | 选格查实际假设与结果；不在前端重估。单估值用卡，未计算网格不补值，不平均性质不同的目标。 |
| **M05 共识**：预期怎样修正，分歧和覆盖怎样变化？ | `revision_chart` 哑铃为主；`ratings_chart` 数量；`dispersion_chart` 实际估计散点。 | `target_prices`、`target_dates` 提供价格与期限；`analyst_count` 和 `coverage` 是覆盖量。展开修正记录、评级原标签及实际对照。 | 选估计看来源日期；不可比前后样本用当前摘要。没有逐条估计不造分析师散点。 |
| **M06 事件**：公布值相对当时预期的意外是什么？ | `event_price_chart` 真实事件窗 K 线；`reaction_chart` 本次与参照路径。 | `event`、`expectations`、`release`、`surprise` 并列；展开 `previous_values` 和 `reaction_windows`。 | 保留事件/价格时间分别查看，修订不覆盖当时值。尚未公布时仅显示日程/预期，反应未知。 |
| **M07 新闻**：什么主题新增或升温？ | `attention_chart` 为主；`themes_chart` 比较去重主题覆盖。 | `attention`、`novelty`、`impact` 分开报道量、新信息和解释。展开 `news`、`coverage_details`、`source_mix`。 | 主题或时间点定位原新闻。文本少、去重不稳或覆盖改变时用主题摘要，不伪造趋势。 |
| **M08 情绪**：方向、主观性、恐惧与拥挤有何分歧？ | `sentiment_chart` 为主；`fear_chart`、`subjectivity_chart` 独立分面；`crowding_chart` 用已结算样本。 | `fear_index`、`subjectivity`、`evidence_volume` 各自保留尺度，`trend_indicator`/`divergence` 解释状态。展开覆盖与来源。 | 分面选点查原尺度。只有快照则用卡；不同量表不叠轴，没有历史结果不造拥挤收益关系。 |
| **M09 波动**：期限、偏斜与历史位置怎样定价？ | `term_chart` 为主，`skew_chart` 同截点；`iv_history_chart` 看 IV/HV，`expected_move_chart` 看方法给定范围。 | `iv_rank` 与 `iv_percentile` 分开；`iv_history`、`expected_move` 可作范围卡。展开报价、流动性、曲面和锥。 | 选择报价点看日期/期限，不拟合新曲面。单到期或过期报价用快照；缺值不插补。 |
| **M10 期权结构**：终值如何转成净损益？ | `payoff_chart` 为主，零损益线清楚；`cost_chart` 对账成本。 | `max_profit`、`max_loss`、`breakevens` 明示每组与条件；`profit_probability` 使用本结构历史净损益证据。展开各腿、Greeks、流动性与交割。 | 选终值点查原结果。成本/各腿不完整时不造曲线；无界损失不填有限数。 |
| **M11 筛选**：哪些候选通过，差异在哪里？ | `ranking_chart` 为主；`tradeoff_chart` 比较可比连续特征。 | `universe`、`criteria`、`follow_up` 说明范围与下一步。展开 `selection_logic`、`rank_rules`、`candidate_details`、`backtest_refs`。 | 候选选中查条件命中与缺项。少量定性候选用摘要/表格；没有通过项不造排名。 |
| **M12 风险**：集中、关联与预算约束是什么？ | `exposure_chart` 非负层级构成；`dependence_chart` 矩阵；`stop_chart` 距离/规模取舍。 | `concentration`、`budget`、`position_size` 给关键值，`stress` 保留假设性质。展开持仓、止损变体、成本与保证金。 | 选资产对查看依赖窗口，选方案看计算条件。负净敞口不塞进树图，缺相关性不填零。 |
| **M13 历史**：可比历史真的支持哪些推断？ | `outcome_chart` 结果分布；`baseline_chart` 同目标基准；小样本优先 `cases_chart` 逐次原值。 | `sample`、`uncertainty`、`validation` 说明样本和不确定性；`feature`、`matching`、`applicability` 说明适用条件。集中展开 `inference_evidence`。 | 分箱/案例定位固定记录，每项推断有独立依据。无匹配则说明实际检索状态；无基准不补基准。 |
| **M14 综合**：最终判断、目标和期限是什么？ | 有完整支持时使用紧凑 `outlook_chart`；`evidence_chart` 默认让位给 M13 的完整证据。 | `summary`、`target`、`confidence`、`supporting`、`opposing` 为核心；`overlap` 交代重复证据处理。 | 历史摘要定位同报告真实 M13。没有概率支持时用定性判断，不填 50%，不平均特征置信度。 |
| **M15 监测**：什么条件触发下一步行动？ | `action_chart` 作为报告最后主体；`monitor_chart` 比较同单位当前值与阈值。 | `objective`、`constraints`、`review_at` 简洁在前；展开 `watchlist`、`scenario_terms` 和来源。 | 树保留全图、缩放/拖拽、完整文字。单条任务用卡，定性阈值不编数值距离。 |
| **M16 复盘**：冻结预测与实际结果差多少？ | `calibration_chart` 已结算分组；`evaluation_chart` 同指标方法/基准。 | `original`、`actual`、`settlement` 并列，`explanation`、`follow_up` 在结果之后。 | 校准组查原预测与结算。单次预测不称整体校准；待结算不作零频率。 |
| **M17 日历**：何时关注哪些事件，安排怎样变化？ | `timeline_chart` 为主要路径；`calendar_chart` 显示已覆盖日期的密度。 | `scope`、`coverage`、`schedule_changes` 贴近日程；展开分类日程和原始时区。 | 选事件/日期看计划与实际状态。少量事件或未知精确时间用日期区间卡；未覆盖不当零。 |
| **M18 回测**：冻结策略的收益、成本和稳健性怎样？ | `equity_chart` + `drawdown_chart` 成对；矩阵、双参数面、敏感性、留出、阶段计数和 P&L 对账按问题追加。 | `metrics`、`window`、`costs`、`validation` 给核心结果；`hypothesis` 和 `selection_rule` 给研究条件。正文展示应用现有的 Netron 风格 SVL 渲染的策略逻辑图；`parameter_trials`、运行证据和逐笔明细放末尾附录。 | 完整交互沿用原生策略浏览器，见下节。只有汇总不反推平滑净值，只有叙述不编执行逻辑。 |
| **M19 构建**：从当前到目标要改什么？ | `weights_chart` 哑铃为主，`changes_chart` 增减百分点。 | `objective`、`action_status`、`rebalance` 在前；展开约束、规则、成本、表现/风险引用。 | 选资产查变更原因与状态。未算目标时用目标/约束卡；不同分母不画虚假变化。 |

| --- | --- | --- | --- |
| **R01 资产概览** | 当前状态与变化来自哪里？`M01.price_chart` → 事件事实 → 新闻变化。 | `M01.relative_chart`、`M07.attention_chart`；报价、意外与新信息卡。 | 展开周期状态、事件窗、新闻来源；记录定位明细。只有快照时保留价格与事实摘要。 |
| **R02 综合行情预测** | M14 综合摘要 → 行情/技术 → 驱动 → M13 完整历史 → M15 结尾情景。 | `M02.price_chart` 为价格主证据；综合概率、相对强弱、事件反应、历史分布和基准各自分工。 | M14 只链接 M13 依据；M02 默认不重复情景树。没有概率支持用定性摘要，末尾只有一个综合树。 |
| **R03 事件冲击** | 事件实际/预期与 `M06.event_price_chart` → 同期状态 → M13 → M14 摘要 → M15。 | 反应路径、基准对照、小样本案例；公布意外与样本卡。 | 事件 ID 串联窗口与匹配记录；历史只在 M13 完整展开。尚未公布时保留日程/预期。 |
| **R04 公司价值** | 财务趋势 → 价值/目标 → 共识 → 催化 → 条件计划。 | `M03.growth_chart`、`M04.price_estimates_chart` 为主；因子、敏感性、修正与评级补充。 | 点击假设格查模型与期限；展开财务/目标口径。历史不足用财务摘要，未算网格不画网格。 |
| **R05 日报扫描** | 相对表现 → 简短日程 → 新闻主题 → 候选跟进。 | `M01.relative_chart`、`M17.timeline_chart`、`M07.themes_chart`、`M11.ranking_chart`；事件与后续卡。 | 展开候选筛选逻辑，不重复每项 K 线。覆盖不足时用事件/候选摘要。 |
| **R06 期权与波动** | 期限/偏斜 → 历史与价格范围 → 净损益/成本 → 预算 → 条件计划。 | `M09.term_chart` 与 `M10.payoff_chart` 为主；IV 位置、最大损益和预算卡。 | 展开报价、各腿、交割与保证金。没有完整报价和成本时保留结构及待核实项。 |
| **R07 组合诊断** | 当前暴露 → 关联/压力 → 行情背景 → 监测行动。 | 敞口/依赖图、相对表现、阈值哑铃；集中、预算与复核卡。 | 选资产对查风险窗口。持仓不全时说明覆盖部分，不伪造组合图。 |
| **R08 预测复盘** | 冻结预测/结算并列 → 校准 → 基准 → 改进任务。 | `M16.calibration_chart`、`evaluation_chart`；原值/实际/状态卡。 | 组内记录连接原预测与结算证据。单条或未结算时不画校准曲线。 |
| **R09 事件周历** | 时区与范围 → 时间线 → 密度日历 → 分类明细。 | `M17.timeline_chart` 为主，日历辅助；改期/取消/覆盖卡。 | 事件/日期可看原始时区与状态。少量、不确定日程用表格；需冲击研究再拼接 M06。 |
| **R10 筛选回测** | 筛选假设/候选 → 冻结策略与模拟条件 → 净值/回撤 → 稳健性/成本。 | M18 净值与回撤为主；候选、市场矩阵、参数面、敏感性、留出、计数与 P&L。 | 真实策略逻辑和全部参数下钻在原生浏览器。无运行证据时完成筛选部分，不冒充回测。 |
| **R11 组合再平衡** | 目标/状态 → 当前/目标权重 → 变更 → 当前风险 → 原组合历史。 | M19 权重哑铃为主；变更、M12 当前敞口/依赖、M18 原组合净值/回撤。 | 引用显示真实组合与规则版本。新权重未评估时保留待评估，不把旧净值改标为新方案。 |

## 历史证据与情景树的职责

M14 的综合概率和置信度必须有自己的联合情景/综合方法依据；逐项特征的支持率不能平均成综合置信度。M13 集中保存同类历史匹配、完整结果分布、基准、样本和每项 `inference_evidence`。摘要链接只能指向同报告实际存在的历史章节，不能用“见历史”暗示没有提供的证据。

R02/R03 默认仅末尾 `M15.action_chart` 表达综合触发、失效和后续观察。技术章节不重复画树，综合摘要不展开第二份历史统计。方法与来源可以在树后折叠；正文主体以条件情景结束。节点保留完整文字，内部节点负责判断，叶子只写结果或行动。

这些都是默认阅读建议。用户可以要求独立 M02 的树、独立 M14 的证据对照、多个树、不同章节顺序或纯文字；显式字段覆盖默认项，不在后台补回未选择图表。

## M18：模块摘要与原生策略浏览器

M18 的八种候选图没有替换原生 `backtest-template.js` / `assets/backtest-explorer.js`：

| 字段 | 数据与阅读约束 |
| --- | --- |
| `equity_chart` / `drawdown_chart` | 同基数、币种、期间和冻结结果；成本与回撤观察频率一致。前端不重新计算净值或回撤。 |
| `market_matrix_chart` | 品种 × 周期；每格使用已登记选中参数组的同样本指标。选优规则与颜色指标分离，失败/缺失保持缺失。 |
| `parameter_heatmap` | 仅两个已测试参数轴，其余参数固定；未测试格不填补，留出不参与挑参。 |
| `parameter_sensitivity_chart` | 每点保留试验身份和完整参数组；相同横坐标不静默平均。 |
| `validation_chart` | 冻结后的训练与独立留出结果；累计收益的期间长度不同不能直接比优劣。 |
| `funnel_chart` | 同一运行的去重阶段计数和排除原因；阶段是否包含关系必须明确，不称为命中率。 |
| `pnl_chart` | 同账户、期间和币种，毛损益、负费用与净损益对账；不重复扣费。 |

原生策略报告继续保留以下完整能力：

1. 从真实源码生成的操作节点、函数展开、事件处理器与循环结构。源码修订、图与运行引用必须一致；只有本次实际使用 SVL 才关联 SVL，不能把自然语言策略补造成真实执行源。
2. 品种 × 周期热力图及颜色指标切换。切换 Sharpe、最大回撤或净利润只改变显示，不重新选择获胜参数；分页与缩放保持全局色阶。
3. 点格查看该品种/周期的全部参数试验，保留分页、逐条参数明细、原始精度、失败与缺失状态。参数名即使与 `net_profit` 同名，也不能覆盖指标。
4. 参数敏感性保留 Sharpe、最大回撤、净利润三项结果；参数选择和试验明细可达。鼠标、键盘、桌面与窄屏均能读到同一份证据。

`logic_graph`、`parameter_trials`、`selection_rule` 和 `artifacts` 用来连接对应真实源与运行证据。模块摘要有原行检查，不能声称具备原生浏览器全部下钻功能。若需要对参数选优做完整审查，保留原生报告入口和固定引用。
