# 技术研究结果的组织形式

Report 只规定可承接的结果形式和证据语义，不选择指标、流派、算法、参数、插件或研究执行顺序。研究侧可以自由组合方法与知识；同一段 K 线可能产生不同性质的特征。下述字段用于组织已经得到的结果，不构成必须运行的研究清单。用户可删除、调整或拼接字段。

## 同源结果与方法差异

| 结果形式 | 建议保留的内容 | 展示含义 |
| --- | --- | --- |
| 价格观察 | 固定 OHLC 引用、品种、周期、区间、截点、单位、末根是否收盘 | 内置 K 线呈现原观察，不从图表中重新识别信号。 |
| 方法结果目录 `method_scan` | 已用方法/版本、输入引用、参数、状态和结果引用 | 区分检出、未检出、不可运行、未运行；方法数量不是证据强度。 |
| 特征 `feature_signals` | 名称、数值、单位、位置、成立/失效、首次可得时间、方法引用 | 数值、几何区间、事件状态与方向判断分别表达；不要求每项都有多空方向。 |
| 几何与事件 | 方法已给出的价位、区间、形成/确认/结束时间 | 作为 K 线叠加或时间线；坐标缺失不补画。 |
| 条件判断 | 触发条件、判断、目标期限、相反证据与失效条件 | 承接研究结论，不让组件选择隐含某种分析方法。 |
| 历史参照 | 对应特征定义、样本、实际后续结果、基准、可比性和不确定性 | 每项推断使用自己的参照，综合结果使用自己的联合依据。 |

FVG 的几何区间、ATR 的波动尺度、均线的位置只是不同结果性质的例子，不是推荐、默认或必算指标。同名指标也可能有不同定义，保留实际 method_ref/参数即可；Report 不替换实现。多个方法共用行情时保留共同引用与真实输入范围；依赖的成交量或订单簿缺失时照实保留状态。

`method_comparison_chart` 对齐已提供的时间与状态，不补算统一评分。K 线叠加层只绘制已有价格坐标；非价格量纲使用合适的独立图或数值。需要后续 K 线确认、重绘或修订的特征，位置时间与 first_available_at 分开保留。

## 历史参照的结果结构

历史匹配和统计由独立方法完成。报告承接以下结果，不实现检索器或固定相似度算法：

- 匹配定义和版本、目标、期限、数据截点及当时可得信息。
- 检索范围、执行状态、固定成果、匹配/排除/已结算/待结算数量。
- 当前品种近期优先的选择记录；完成检索且零匹配后才使用跨品种样本及可比性说明。未检索、失败或样本少不等于零匹配；用户覆盖时保留理由。
- 实际后续结果、同目标同期限基准、失败案例及已有不确定性估计。
- 重叠样本、重复特征、多次尝试和筛选偏差的已有处理记录。不能将多个相关信号当作独立投票，也不平均各自置信度得到综合概率。

M13 承接完整参照；M02 可引用关键差异，M14 承接已有综合结果。匹配数量、历史频率、预测概率与置信度分别表达。纯描述或确定性复算保留输入和规则即可，不强迫产生预测概率。历史不足的推断保持 pending/unavailable 与具体原因，报告不填中性概率。

## 精简推理与知识对照

`reasoning` 表达可核查的业务推导摘要：observations 是关键观察，steps 是从这些观察到判断的简短关系，conclusion 是判断，history 说明实际历史参照状态。它不要求完整思考记录，不指定推理算法；正文先给结论，再用已有图表、短理由和必要历史对照说明，不要求逐格重述这些字段。

可选 `knowledge_basis` 保存研究侧给出的知识机制与历史对照：

| 字段 | 结果含义 |
| --- | --- |
| theory_refs | 实际使用且可核对的知识来源；可以为空，不为填字段虚构引文。 |
| mechanism | 已提出的作用机制，区分定义、假设和已有证据。 |
| assumptions | 该机制成立的条件。 |
| expected_observation | 机制成立时应观察到的结果及可反驳情形。 |
| agreement | supporting / conflicting / mixed / insufficient，由研究结果给出。 |
| interpretation | 支持或冲突对判断的影响，精简表达。 |

历史支持不自动证明因果；没有可比样本时机制可以保留为假说，agreement 为 insufficient。完整机制、知识来源和方法版本可展开，正文只保留关键推导与对照。Report 不查找理论、不重判支持关系、不生成权重或重估置信度。

字段来源性质和插件可覆盖性属于 Agent 内部资料，不显示获取/计算/推断徽章。用户可以隐藏或删除任意展示字段；固定结果中的来源与验证语义不因排版而改变。


## 末尾证据附录

正文保留判断、主要 K 线/热力图/统计图、关键数字、精简读图说明、推理步骤与影响决策的条件。来源、真实原始数据、样本清单、复核计算、参数和完整方法细节统一集中在报告末尾可折叠附录；正文只留小锚点，点击展开对应附录并可返回。不要把主图或全部指标移入附录，不改变研究方法、数据或结果。

原始证据使用 `details` 内容块，或放入 `content.appendix` 中的 `details`。Report 集中到末尾并生成正文与附录的往返锚点，保留完整原值与固定引用，不复制样本或重新计算。正文的主要图表、必要控件和关键条件保持可见；验收锚点往返、窄屏及打印完整性，不自行编写 DOM 标记。
