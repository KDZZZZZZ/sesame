# 回测报告：从结果比较到策略解释

回测报告属于 **Strategy**。用 `report_publish.strategy_source` 传入实际回测对应的完整 `strategy.source` 引用；插件会自动加入 `related.role="strategy"` 并保留固定来源。关联真实 translation、run、result；不要把回测报告当普通 Research 发布，也不要另造一次策略来补引用。策略还未登记时，先通过 strategy-authoring 登记实际使用的 SVL。

## 每份回测报告必须有的内容

1. **策略逻辑图**：从该固定 SVL 源生成图，包含数据依赖、事件、条件、动作与仓位/风控逻辑；函数可展开，节点可查定义。使用 `report_backtest_template`，或调用 `strategy_graph` 把返回图接进自己的 HTML。图与运行结果必须来自同一源码修订；原生翻译不支持的逻辑、缺失的执行回执如实说明。不能凭文字手绘一套与执行代码无关的流程。
2. **品种 × 周期热力图**：每格是该组合按事先声明的优化规则选出的最优参数组的结果。颜色默认展示选优指标；可切换夏普、最大回撤、净盈亏，切换颜色不重新选优。写清目标、样本、约束和并列规则。用正负与数值表达结果，不能把全亏损中的最优格解释成盈利。
3. **点格子查看全部参数组**：保留每组参数、夏普、最大回撤、净盈亏、试验 ID、状态及其他真实统计。支持分页和明细，不只列 Top N；失败、未运行、指标未定义分别显示，不能写成 0。
4. **参数敏感性**：逐个参数可切换，图示夏普、最大回撤、净盈亏如何随参数改变。每个点能回到完整参数组；多个参数同时变动时，固定/筛选其他参数或明确每点其他参数不同。相同横坐标不能被静默平均，排序不等于因果。类别参数按类别展示。

这四项是内容下限，不是整页布局上限。先回答“策略是否有效、在哪些范围稳定、主要风险是什么”，再选有帮助的净值/回撤曲线、成本分解、逐笔交易、滚动样本外、参数平台与过拟合诊断。沿用原版 reportKit 字体、间距、颜色与结论层次，按 report-design 加入合适的 Lieflat 风格统计、排名或关系图。不要为填满模板发明数据；只有一个品种、一个周期、一组参数时如实显示 1×1 和单点，并说明不能推断稳定性。

## 数据与选优

优化、指标计算和获胜组选择都在可追溯的后端/登记计算中完成，报告只读冻结结果。样本内负责选择，样本外负责验证；不能看过样本外后再挑最好的一组。分开不同样本、资金口径、币种、成本模型和不兼容的年化规则；只有经过登记的口径转换后才能共用色阶。

默认模板的一个固定 `data` 绑定包含全部试验行（最多 100,000；更多时在报告分成具名分页绑定，不删数据）。每行字段：

| 字段 | 内容 |
| --- | --- |
| `trial_id` | 全报告唯一的真实试验 ID |
| `symbol`, `timeframe` | 品种和周期，字符串 |
| `sample` | 同一比较样本/区间标识；不要混合训练和样本外 |
| `status` | `completed` / `failed` / `not_run` |
| `selected` | 登记计算已选定的获胜组 `true`，其余 `false` |
| `parameters` | 全部实际参数的对象，保留原值 |
| `sharpe` | 原统计值或 `null`，说明年化/无风险利率口径 |
| `max_drawdown_pct` | 非负百分比幅度（12.5 表示 12.5%，不是 0.125），或 `null` |
| `net_profit` | 已扣规定费用、统一币种的净盈亏，或 `null` |

金额、精确小数和票据保持字符串。默认模板要求每个有成功试验的品种/周期恰好一个已登记选中组；全失败/未运行的组合没有获胜者。如果约束导致无合格试验，使用自定义空状态明确展示“不满足约束”，保留全部试验，不假选一个。无对应试验的组合显示缺失；不会自动补造一次运行。

`source_note` 写引擎和版本、数据来源、起止区间/时区、样本划分、币种/初始资金、费用/滑点、成交模型与指标定义。把真实 result/run/translation 的完整引用放来源区。结论有交易数和样本外证据支撑；不足时限制结论强度。

## 开始编写

- 用 `report_data` 冻结登记数据，或使用已有固定 DataRef。
- `report_backtest_template` 传 `strategy_source`、`data_id`、`parameters`、`selection_metric`（夏普/回撤/净盈亏，默认夏普）与 `selection_rule`、`source_note`、`currency`、真实 `title/summary` 与 `locale`。模板会读取该源码、生成实际图并内联原版风格的可编辑 HTML。仅演示数据使用 `demo:true`。
- 选优指标不属于默认三个指标时，按已登记该指标扩展模板与图例，保留三个必备指标。修改章节、增加解释和图表不需要改宿主接口。
- `report_publish` 使用上述 `strategy_source`、固定数据绑定和关联证据；随后 `report_check` 检查新 ref。源码或 HTML 更新都需要新修订和新检查，不能沿用旧成功回执。
- 检查矩阵选中至少两个真实存在的组合、参数切换、完整试验分页、缺失/失败状态、键盘/触屏以及窄屏。只在真实回执 `rendered` 后交付“已渲染”；发布成功本身不代表交互无误。
