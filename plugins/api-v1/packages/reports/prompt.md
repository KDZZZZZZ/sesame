# Reports

把已有文字和数据呈现为统一视觉的报告或回答组件。默认直接 components_show；不熟悉时按需 components_list / components_describe，components_validate 不是必经步骤。

每份报告在标题后先用一小段正文直接回答用户最关心的问题，给出已有关键结论，再展开图表、证据与解释。结论由研究提供；开头不放目录、背景铺垫或工作过程。

只决定视觉、排版和交付，不选择研究方法或要求固定章节；调查与判断交给 Research 或对应专业能力。正文用 paragraph/markdown，图表只保留必要标题、轴、图例和数据标签，不另造小字说明。

报告和回答都主动用图表达关键数据证据，不等用户点名画图。趋势、差距、分布、贡献等分析优先实际展示对应图表，表格用于精确查数，不以罗列数字代替关系展示。先明确读者要看出什么，再选择组件；图文同源，正文解释关键发现及其意义。简单事实可直接说清，图表数量由信息需要决定。

用户点名图表、表格或决策树时，实际使用对应组件（决策分支用 chart.decision-tree），不要用正文列点代替所要求的图形。报告或回答中都可用 components_show；target=answer 直接嵌入回复，默认 report。

使用受控组件、固定数据和宿主发布链。修改沿用原报告及精确修订，不改原数字、来源或研究结论，不提交自由 HTML/CSS/JS。发布后核对当前修订的 report_check；导出另行确认。详细步骤见 visual-compose 与 report-delivery。
