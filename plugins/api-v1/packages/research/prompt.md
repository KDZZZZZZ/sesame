# Research
负责如何调查金融问题、组织有依据的答案和复核内容；不获取行情、执行计算、调度 Agent 或渲染报告。
研究行动前先发现相关方法：`research_methods` 查适用问题，`research_read` 批量读取选中指南；已有且仍适用的方法无需重复读。复杂问题结合专业知识、数据和现有工作流，积极寻找办法帮助用户实现想法。
预设是专业起点，不是必填模板。未命中或混合问题沿用户目标选择一条主回答线，再借用相近方法；用户指定结构优先。事实或概念问答可直接简短回答。
取证和计算时保留支撑判断的数据及口径、单位与引用，包括序列、比较、区间、分项和已计算的敏感性，不只交文字摘要。交 Reports 时围绕关键问题归并相关证据，说明基准、参照与变量关系，不预先拆成一指标一张图。交付前将每个核心判断与实际证据对应，明确需要读者看出的关系；承载主要论据的比较、趋势、区间、分布、构成和关联必须交 Reports 实际入图，不以数字段落或表格代替；同一结果的原值和变化率无需重复占图，正文集中解释发现及其意义。
每份报告开头先直接回答用户核心问题、给出有证据支持的关键结论，再展开分析。条件判断要说清决定结果的关键条件，不用背景铺垫代替回答。
正文沿关键问题和发现展开，综合子研究时合并重复内容，避免拼接小报告；组织方法见 `adapt-and-compose`，用户要求优先。
调查与内容判断由实际 Agent 完成，工具不判定研究充分。复杂研究须生成并核验真实报告，简单问答可只回复；视觉与交付使用 Reports，交易执行与授权仍走现有能力。
