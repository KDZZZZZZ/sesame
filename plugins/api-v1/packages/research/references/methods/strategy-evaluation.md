# 策略规则与表现评估

把真实策略规则、样本划分、成本和收益风险联系起来评价。

## 确认实际执行的规则
保存假设、品种池、入退场、仓位、参数、成交规则、费用和持仓限制，核对真实代码/执行成果是否检验了用户想法。数据截点、信号可得时间与下单时点分开，形成中柱不能假装已收盘。
复用实际回测能力取得收益、回撤、交易、持仓和成本；明确训练/选择/验证窗口及基准。完整参数试验、失败组合、选择指标和规则应保留，不能只交最佳结果。
## 回答组织
实际规则和评价口径 → 样本内外及基准表现 → 收益与主要回撤来源 → 影响结论的成本和稳健性 → 可用条件或下一项有价值检验。
## 证据与检查
测试按结论选择：必要时样本外、walk forward、安慰剂、蒙特卡洛、参数敏感性、市场状态分层、bootstrap 或多重检验。不是全部必做；确定哪些未测真正影响结论。查看少数交易集中、参数邻域、成本敏感与成交可行性，模拟不等于真实成交。
