# 事件与价格变化解释

用信息到达、预期差和竞争解释调查涨跌，而非新闻与价格简单配对。

## 建立时间与预期关系
固定事件、发布时间、事前预期、旧值/修订值和反应窗口，区分信息首次出现与转发。比较相关市场及同期事件，检查反应是延续、反转还是消退；异步市场不能伪装成同步因果链。
财报看经营差异，央行看决定、措辞、预测与利率路径，政策看范围、生效日和受影响主体。新闻量、语气、主观性、拥挤和价格方向是不同对象；有需要再量化，不能相互充当概率。
## 回答组织
信息与价格的先后 → 最有力的传导渠道及证据 → 其他同期解释 → 能区分解释的关键事实。用户只查事件事实时保留事实，不追加整套研究。
## 证据与检查
把观察反应与解释区分，参考同类事件时保留当时可知条件、期限、基准和反例。不能仅凭同时发生断言因果，也不能因未严格证明就否定所有条件性解释；证据不足说清具体受限结论。
