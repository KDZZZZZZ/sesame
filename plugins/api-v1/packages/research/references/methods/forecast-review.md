# 预测复盘与概率校准

把当时可知的预测与实际结果比较，区分条件、数据和推断偏差。

## 从原始预测记录开始
取得当时实际给出的对象、目标、期限、条件、方法、时间和概率（若有），冻结原文及版本；不能事后补写预测或更改结算标准。核对实际结果和未结算案例，缺失与失败分开。
将偏差定位到输入、条件变化、推断或执行；按品种、市场状态、期限或方法分组比较适合的基准。只有真实事前概率且样本适合时才计算校准、Brier 等，方向判断不能补成 50%/100% 来凑评估。
## 回答组织
原来判断了什么 → 实际偏差 → 哪些条件或过程产生偏差 → 下一次应怎样具体修正。若评价新校准映射，比较旧映射和新映射在未参与拟合的数据上的表现。
## 证据与检查
分母、结算窗、排除和相关样本是否一致；选择后的历史命中率不等于未来概率。校准变差应如实记录，不因“已校准”标签提高信心；保留有条件适用的结论与停用/复核依据。
