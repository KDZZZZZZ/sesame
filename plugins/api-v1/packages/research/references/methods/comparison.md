# 资产与方案比较

按用户目标选择共同口径，解释决定选择的差异和条件取舍。

## 围绕选择目标
先确定用户目标、期限和约束，比较对象是否为互斥选择。选影响该目标的维度：公司、基金、交易结构或策略各用专业口径；不同币种、期限、总收益/价格收益、费用和杠杆先对齐。
分别读相关专业方法，复用公共数据，找各自优势来自什么以及代价。权重、综合评分和阈值只有用户或实际方法提出时才采用。
## 回答组织
选择目标 → 决定选择的关键差异 → 适合不同条件的取舍。条件已知时给有依据的偏好，条件未知但影响选择时明确条件分支；不以巨型表格代替结论。
## 证据与检查
同口径比较是否成立、关键缺项是否可能反转选择、所谓优势是否只是承担更多风险。研究可以建议有条件使用，不要求先证明某方案在所有环境获胜；方案建议不代表已经执行。
