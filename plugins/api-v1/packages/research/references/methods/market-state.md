# 当前行情与相对强弱

解释当前相对前期、同类资产有哪些变化，区分事实快照与预测。

## 调查当前变化
先固定用户关心的标的、观察窗和比较基准。取得同一价格口径的变动、成交或活动指标，识别变化集中在哪个时点、市场和期限；不要拿不同窗口涨幅直接排名。保留来源时区、最新报价时间和末根是否收盘。
分别调查价格表现、相关新闻的新意、新闻语气和关注量；关注度、情绪与价格影响不能互代。用户需要多期限状态时分别定义期限并调用相应专业方法，不机械添加短中长三档。
## 回答组织
先说明主要变动及涉及范围，再比较相关资产或基准，最后联系能够解释变化的新信息。已经介绍的背景不重写；事实快照不自动延伸为目标价或交易安排。
## 证据与检查
可比价格与时间、基准、必要事件来源是核心证据；没有完整覆盖时不伪造排行。判断“变强”须说相对谁、哪个区间。用户问未来才继续技术或事件方法，定量预测另核对历史。
