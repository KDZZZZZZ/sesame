# 技术结构与条件路径

围绕观察期限、关键分界、触发、目标及相反路径组织技术判断。

## 从问题选择方法
先区分用户要描述结构、检验形态还是制定条件判断，记录 bar 粒度、观察窗、目标期限和截点。主动发现 ICT 等适用知识及真实计算能力；同一行情可以共用，方法不能因为图形组件存在而被固定。
保留每种方法/版本、输入、参数、检出/未检出/不可运行/未运行；特征值、几何位置、生命周期和方向分别解释。需要未来柱确认或会修订的形态，其位置时间与首次可得时间分开。
## 回答组织
说明当前结构与期限，再给最有区分力的关键分界；解释条件满足后的路径及目标，相反条件如何改变判断。用户只问走势时不额外加入仓位或下单步骤，不强制目标数量和情景数量。
## 证据与检查
叠加坐标来自实际分析，不凭图补造。推断主动找同目标、同期限的历史结果与基准，保留样本状态；多个相关信号不是独立投票，联合概率不能平均各自置信度。缺历史仍可保留机制解释和具体条件，不制造数值概率。
