# 期权结构与条件损益

比较合约成本、条件损益，以及时间、波动和到期因素的取舍。

## 用目标约束结构
确定方向/波动/保护目的、期限、资金和现有持仓。取得真实合约身份、行权价、到期、买卖方向、数量、乘数和同截点报价；检查价差、流动性、行权方式与结算规则。
通过实际计算能力核对净成本、盈亏平衡、有限或无限最大损益；到期损益与持有期间估值分开。按问题调查 Delta/Gamma/Theta/Vega 等敏感性及事件溢价，不拿一个希腊字母代替全部风险。
## 回答组织
候选合约组成与成本 → 条件损益及盈亏平衡 → 时间/波动变化 → 到期、提前行权或指派影响 → 用户目标下的取舍。
## 证据与检查
报价不是保证成交价；成本口径与组合腿数量一致。盈利概率需明确模型与分布，风险中性概率不同于实际发生概率；不能由损益图直接编概率或预期收益。
