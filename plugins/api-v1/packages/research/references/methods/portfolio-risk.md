# 组合风险与集中暴露

区分持仓权重、共同暴露、风险贡献和压力损失。

## 从实际持有开始
使用用户指定账户、公开组合或明确的假设组合，确认持仓时点、价格、币种、衍生品乘数、现金与杠杆；来源不足先查配置和数据能力，不把假设持仓当真实账户。
分解行业、地域、币种、风格及相关风险因子，识别共同暴露和相关变化。风险贡献需要实际模型与协方差等依据，大权重不自动等于最大风险贡献。
## 回答组织
实际暴露 → 风险集中在哪里 → 相关冲击影响哪些持仓 → 能改变风险结构的调整及代价。只研究与持仓有关的风险，用户需要损益解释时转归因方法。
## 证据与检查
压力情景是条件损失，不是发生概率；VaR/ES、波动和最大回撤不能互代。保证金、止损、流动性和执行成本按账户适用性分析，止损价不保证成交损失；风险建议不自动下单。
