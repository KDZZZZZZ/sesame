# 商业模式与经营质量

解释收入、利润和现金怎样产生，增长与竞争优势能否持续。

## 调查价值怎样形成
从公司披露和实际经营资料拆分产品、客户、价格、数量、业务组合与投入，建立收入到利润再到现金的关系。检查应收、存货、资本开支、负债和回报是否支持账面增长，而不是仅罗列财务比率。
竞争优势用客户选择、定价能力、成本、替代难度和资本回报的证据解释；区分行业周期与公司自身优势。需要共识时保留分析师覆盖、原口径和预测日期。
## 回答组织
收入和利润来自哪里 → 增长由什么驱动 → 现金转化和财务承受力 → 竞争条件与资本运用能否持续。用户只问某个环节就保留相关链条，不因研究公司就必须给目标价。
## 证据与检查
对齐财期、会计口径、币种和一次性项目，区分财期结束与公开时间。增长率不能替代质量，价值风格评分不能替代估值。首次覆盖和已有研究更新采用不同展开程度；重要经营判断应能指向具体证据或待核查假说。
