# 宏观主题与资产传导

解释冲击通过何种渠道、时滞和相反力量影响目标资产。

## 沿渠道取证
确定核心变化是已经发生、预期变化还是用户假设，再拆需求、供给、现金流、贴现率、融资和资本流动等实际相关渠道。明确受影响对象、方向、时间差和相反力量，不能给每个资产复制同一传导结论。
调查价格已经反映多少变化需要真实预期与价格证据，不能仅用“利好出尽”概括。必要时调用公司、估值或组合方法，复用相同宏观输入。
## 回答组织
核心变化 → 具体传导路径及谁受到影响 → 相反力量和时滞 → 已反映部分 → 下一项有区分力的观察。围绕目标资产，不先铺完整全球综述。
## 证据与检查
机制假说与已观察结果分开；地区、成本转嫁、监管或融资结构可能改变方向。未知参数影响哪条链就补查哪条，数据充分但方向相抵可明确无单一优势，缺数据不能直接判断“没有影响”。
