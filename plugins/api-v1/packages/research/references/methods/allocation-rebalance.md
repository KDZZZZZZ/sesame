# 配置与再平衡

围绕目标、约束、当前持仓和调整成本比较配置方案。

## 从目标偏差决定工作
确认投资目标、期限、可用资产、现金流、预算及用户约束，读取当前权重与已有风险/历史结果。判断是简单规则再平衡、备选配置比较还是确需优化；不因可调用优化器就强制运行。
预测收益、风险估计、约束和权重规则各自可追溯。考虑调整成本、流动性、税费或最小交易单位等实际相关条件，不凭空补账户参数。
## 回答组织
现状与目标差距 → 候选配置的取舍 → 调整前后暴露和成本 → 实施顺序与触发条件。计划、模拟和已经执行分别记录。
## 证据与检查
权重与现金、借贷/杠杆口径可核对；约束是否满足，结果是否依赖敏感估计。复用回测结果时核对同规则与成本，不把历史最优当未来保证。研究方案本身不授权交易。
