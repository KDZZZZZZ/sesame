# 组合损益归因

解释已实现表现来自哪些资产、时段、配置和交易变化。

## 重建实际损益
对齐期初期末持仓、期间交易、外部现金流、分红、费用和汇率；把绝对金额与收益率分开。先使资产/时段贡献与总损益可核对，再按用户需要比较基准。
若解释配置、选择或交互贡献，使用实际适用的归因模型与基准权重；没有这些输入时只作可支持的资产/交易贡献，不伪造专业归因名称。
## 回答组织
主要损益来源 → 发生时段和资产/交易贡献 → 适用时与基准差异 → 值得处理的具体变化。不要把前瞻风险敞口当成已实现亏损原因。
## 证据与检查
核对现金流与收益计算、净/毛收益、费用和货币换算；未解释残差保留并调查，不为凑合计随意分摊。与策略退化有关时再检查规则和执行变化，不由单次亏损断定因子失效。
