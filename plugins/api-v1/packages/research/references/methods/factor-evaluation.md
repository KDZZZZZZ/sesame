# 因子信息与稳定性

评价因子描述或预测什么、在哪些样本成立，以及是否提供增量信息。

## 先明确因子角色
区分因子值、交易信号和完整策略。确定金融假设、公式/参数、输入来源、首次可得时间、预测目标与期限；先查现有因子库，需要新因子才由现有挖掘能力提出搜索空间并计算，不在 Research 重建搜索器。
横截面排名与单品种时序使用适合的评估。按问题检查 IC/Rank IC、分组或分状态关系、覆盖、稳定性、换手、冗余和相对已有因子的增量信息。
## 回答组织
含义与计算口径 → 与目标的关系 → 分组/状态差异 → 稳定性与互补 → 因子库中的成果与评价状态。策略是否采用由策略研究决定，并反馈因子池；某个应用收益不佳不能直接判因子无效。
## 证据与检查
记录搜索尝试和筛选过程，避免信息泄露、重叠标签和多重检验偏差；选择样本外、walk forward、安慰剂、bootstrap、参数敏感性等与结论相关的检验。未适用/环境不可测不阻塞其他结果，未测不称通过。
## 参考
[Alphalens 文档](https://quantopian.github.io/alphalens/alphalens.html)提供信息、收益关系与换手的独立分析入口；不要求调用整套分析。
