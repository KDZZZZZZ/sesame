# 波幅、时段与波动定价

研究何时更活跃、不同持有期可能波动多大，以及期权波动定价差异。

## 选择波动问题
区分日内/星期活动差异、持有期范围、实现波动和期权隐含定价。先确定交易日历、时区、观察频率、收益或价格单位与用户持有期，再用实际数据和对应计算插件求分布。
研究期权时对齐期限、行权价/Delta、报价截点与流动性，必要时比较期限结构、偏斜、事件溢价。IV Rank 与 IV Percentile 定义不同；范围、ATR、实现波动率也不能静默替代。
## 回答组织
时段问题先说活跃/平静差异，再给相应期限范围与持有期含义；定价问题先比较哪些期限或尾部更贵，再解释与实际波动及事件的关系。波幅不是方向预测。
## 证据与检查
记录样本窗、分组、极端值和区间含义；条件范围注明覆盖统计或模型定义，不照搬厂商宣称的概率。报价陈旧、样本不均和交易时段变化影响哪项比较就核对哪项，不要求所有波动问题都研究期权。
