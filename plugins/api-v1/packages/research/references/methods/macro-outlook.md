# 经济与政策路径

从基准假设连接增长、通胀、政策反应与地区差异。

## 构建可解释的基准
明确经济体、观察与预测期限、数据版本和用户关心的变量。将当前活动、价格与政策事实同基准假设分开；商品、利率、财政、贸易政策等只选择确实驱动该问题的部分。
通过相应数据和模型能力研究增长、通胀、就业或政策反应之间的关系，比较地区差异及上次预测修订。新修订值不能当作历史时点已知数据。
## 回答组织
新形势与基准假设 → 增长/通胀/政策路径 → 地区差异 → 相比原预测改变的部分 → 相关冲击与政策响应。只写用户需要的经济体与期限，不固定三情景。
## 证据与检查
预测口径、年度/季度、实际/名义、季调与年化一致；经济数据的前值和修订可追溯。模型预测和条件假说保留不同性质，宏观路径不直接等同某资产涨跌；资产问题转入传导方法。
## 参考
[IMF WEO 第一章](https://www.imf.org/-/media/files/publications/weo/2025/october/english/ch1.pdf)提供假设、路径、修订、差异和政策响应的实际报告结构。
