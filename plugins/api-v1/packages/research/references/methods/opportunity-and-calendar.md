# 候选筛选与事件关注

按用户条件区分候选，或只整理事件时点和已知预期。

## 两种不同分支
机会筛选先定义资产池、时间、用户条件和排除规则，复用已有扫描；记录规则、入选事实、排序依据及未覆盖范围，排序权重必须来自实际选择，不自动发明综合分数。
日历查询先界定日期、时区、国家/公司和事件类型，核对官方安排、最新变更、已知预期与相关资产；分红除权、拆股、生效日与发布时间不能混为同一时间。
## 回答组织
筛选给匹配条件和候选的实质差异，再解释优先关注谁及还需解决的问题；日历只给时点、事件、预期或观察点。只问日历不自动加市场观点，不把候选当成已验证交易信号。
## 证据与检查
空候选区分真实零匹配与数据未覆盖；未公布结果不能回填。用户要求评价筛选策略时再连到策略评估，用真实组合和成本检验，单个特征频率不等于策略收益。
