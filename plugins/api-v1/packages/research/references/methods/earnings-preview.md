# 财报前瞻

围绕事前预期、待揭晓经营变量和公布后的解读安排调查。

## 锁定尚未发生的信息
确认公司、财季、公布时间与既有研究。保存当前指引和事前共识的日期、覆盖及分歧；没有共识时寻找明确可用的历史或指引基准，不伪造市场预期。
按商业模式选能区分结果的经营指标，如销量与价格、用户与变现、订单与交付、成本与产能。把驱动连接到收入、利润、现金或未来指引，判断哪些结果会改变已有观点。
## 回答组织
事件与预期基准 → 最值得看的经营变量 → 驱动如何影响结果 → 公布后怎样解读。必要时再调查已计价程度和期权隐含波动；不固定三种情景，不把未来结果写成已观察事实。
## 证据与检查
关键预期能追溯到当时版本，区分管理层指引、分析师估计和自己假设；明确尚未揭晓什么。无需重复完整公司背景，用户只问一个经营指标就聚焦该链条。
