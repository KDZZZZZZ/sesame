# 财报点评与预期修订

解释实际相对事前预期的差异，以及经营判断具体发生的变化。

## 先解释新增信息
取得实际结果、事前指引和带日期的共识，按同财期、币种、会计口径比较；事后更新共识不能倒填为事前预期。区分同比、环比、实际/预期以及报告利润/核心利润。
把差异归到量、价、业务组合、成本、一次性因素和关联企业等实际来源，必要时拆地区和业务；再核对指引、预测和原经营判断的修订。
## 回答组织
关键实际预期差 → 差异来自哪些经营或一次性贡献 → 新信息改变了哪项原判断和预测。股价反应只有用户问到时接入事件解释，不重写整篇公司介绍。
## 证据与检查
差异计算有原值和分母；持续性结论有经营证据，不能把一次性收益外推。不同来源“核心利润”定义不同就核对调整项，不能只看标题“盈利增长”。
