# 估值与价格隐含假设

比较当前价格要求的经营表现、可支持假设和价值敏感性。

## 先选择合适的估值对象
确定权益、企业、基金或其他资产以及用户期限，再选适用方法和真实计算能力。现金流、倍数、资产或其他模型按资产性质选择，不给所有品种套公司现金流模型。
用经营驱动、融资和资本成本连接模型输入；反推价格隐含的要求并与经营证据、同行口径比较。价值估计、指定期限的模型目标价和分析师目标共识分别记录，不平均成一个总目标。
## 回答组织
估值对象与比较口径 → 价格要求的增长/利润/回报 → 哪些假设有证据支持 → 价值区间及最敏感的变量。只有改变判断的假设才展开，不用大量微小场景制造精确感。
## 证据与检查
保留财期、净债务/股数、币种、模型版本和敏感性口径；同业业务和周期差异影响可比性。缺输入时先查数据插件，采用替代时说明含义变化，不能把估值区间当成价格必然到达的区间。
## 参考
[Morningstar 官方样例](https://advisor.morningstar.com/Enterprise/VTC/EquityResearchReportv2.pdf)；价格隐含要求是围绕用户问题的分析扩展。
