# 策略退化与执行诊断

定位表现变化的时间、贡献来源和竞争原因，再确定值得修改的部分。

## 比较发生变化的部分
先读取原规则、基准表现、最近交易与执行记录，确定退化从何时开始及衡量口径。拆分品种、方向、时段、市场状态和交易贡献；区分样本波动、成本变化、信号信息衰减、实现偏差与数据变化。
对竞争原因提出能区分它们的证据，优先复用原回测和固定输入；需要反事实复算时保持其他规则可比，不把一次修改后的最佳结果当作因果证明。
## 回答组织
变化起点与幅度 → 哪些交易/状态/执行贡献变化 → 原因检验与支持程度 → 值得修改、保留或进一步验证的部分。
## 证据与检查
是否真实发生结构变化，还是样本不足或口径改变；参数、数据供应商、费用、成交和账户条件的修订有记录。亏损不自动等于因子失效；修复只重验受影响假设及必要回归，不盲目重新挖全部因子。
