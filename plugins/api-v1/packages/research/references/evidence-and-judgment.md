# 证据与判断

## 先确定研究关系
用户问题、对象、时点、期限和比较口径决定取证；不要因已有数据或预设字段就增加无关任务。用户观点有边界时先确认其含义，沿该方向寻找机制、条件和证据，不以自己暂时缺少知识否定观点。

## 来源、时间与含义
- 观察事实、统计、机制假说、模拟、预测和行动主张分别保留性质。获取方式与内容性质独立：取得分析师预测仍是预测；计算 ATR 不等于方向预测。
- 记录实际方法及版本、固定输入和输出引用。完整 id/revision/digest/kind/schemaVersion 用现有成果机制保留；链接、裸 ID 或文字说明不能冒充固定执行证据。
- 观察、首次可得、发布/修订、获取和生成时间不同。财期结束不表示已公开；形态位置不等于确认时点。历史研究只用当时可得信息，保留闭合柱、时区、交易日历和复权口径。
- 单位、分母、币种、原尺度、对象、观察窗和目标期限不能悄悄替换。bar 周期与预测期限分开。缺失、未执行、失败、已执行但零匹配、已知零值分别记录。
- 来源专有分数保留原定义与覆盖；自算结果不能称为 Trading Central/Autochartist 的原结果。值、标签、模型目标、公允价值、分析师共识不要混合成一个“总目标”。

## 有依据的解释
围绕问题说明目前更有力的关系及证据，比较机制、时间顺序、同类实际结果和竞争解释。相关不自动证明因果，尚未严格证实也不等于已被否定。存在冲突时解释分歧，不能只罗列两种可能；不能区分时说明具体缺口，缺数据不填中性、50% 或虚构倾向。
对外只给可核查的关键观察、业务推导摘要与结论，不要求完整思考记录。假说记录来源、机制、成立条件、可观察预期、反驳情形，以及证据支持/冲突/混合/不足的实际状态。

## 历史、概率与验证
行情预测和可检验推断应主动寻找同目标、同期限、当时可知的历史实际结果、基准和反例；没有可比资料时保留具体状态，仍交付已有证据支持的定性内容。纯事实、概念解释和确定性复算不强制变成预测检验。
- 记录样本选择、检索范围/状态、匹配、已结算、待结算、排除及有效样本量；互斥结果计数与已结算分母核对。未结算结果不能计为成功。
- 默认优先当前品种近期同类样本；跨品种经验保留同品种检索记录、可比性与采用原因。未检索、不可用、样本少不等于零匹配；用户指定范围优先并留理由。
- 处理重叠、重复事件、相关信号、多次尝试与筛选偏差；多个相关证据不是独立投票，不能平均各自置信度得到综合概率。
- 历史条件频率、原预测概率、预测置信度、风险中性定价概率、校准结果和供应商证据量评分含义不同。每个数值估计保留方法、目标、样本、区间含义；综合结论需要自己的联合依据。
- 未验证、历史探索、样本外、前瞻检验是不同阶段；格式齐全或固定引用存在不等于结论有效。选择与问题相关的检验，不要求每项研究全部通过。

正文保留影响用户理解和决策的事实、金融术语、数字与条件；原始记录通过成果引用保留，不自动加免责声明、来源性质徽章或重复小字。
