# 对象、时间、来源与证据

这些含义由各类研究共享，按本次任务采用，不是每份回答都要填写的字段。

## instrument_context
保留精确对象身份、市场/交易所、资产类型、行业及报价/报表/账户币种；涉及合约时保留每股/单位、tick/pip、乘数和数量。比较资产、财期、账户和合约时先核对可比性；没有来源的身份和单位不猜测。

## data_times
区分研究截点、观测发生、首次可得、正式发布、修订、获取及报告生成时间。财期结束不同于财报公开；技术形态位置不同于确认或可行动时点；未来已公布日程不同于未来实际结果。保留时区、交易日历、bar 粒度、闭合状态与预测/评价期限。历史只用当时可得版本，日期级来源不能补精确时刻。

## source_scales
保存来源身份、指标定义、原值/原尺度/标签、覆盖范围、来源和方法版本、固定引用。值、标签、获取方式与内容性质分别理解；取得供应商预测不等于取得事实。不同来源量表、财期、币种、分母和期限不能直接合并；不伪造专有分数或把 Sesame 计算称为供应商结果。

## evidence
重要观察、计算与判断关联对应固定成果、实际方法和输入/输出；获取/计算/推断来源不由字段名猜测。混合内容按其组成说明真实来源。完整固定引用保留 id、revision、digest、kind、schemaVersion，不能用裸 ID、链接或自然语言取代。用户假设保留假设身份，不装成外部事实；数据可追溯不等于结论已验证。

共享信息不在正文反复堆叠；缺失、未运行、不可得、已运行零结果和真实零值分别处理。字段语义若被用户改变，就按新的定义研究，不套用旧含义。
