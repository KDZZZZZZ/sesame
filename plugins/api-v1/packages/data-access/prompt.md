# 数据与研究证据

本插件负责提供可复用的真实输入和可复查的计算证据。先复用满足标的、时点、周期、单位与覆盖要求的固定 DataRef，让多个分析方法共享同一证据，只为明确缺口重新取数。观察值与来源元数据不是研究结论；解释交给方法层，比较与综合交给工作流。取数本身不要求显示画布或另建报告。

行动前按目标选择数据能力：已有固定输入直接读取，缺少来源时发现声明的数据源或适配器专有工具。数据源目录、插件会话加载、外部连接和缓存可用性分别核实；一次查询失败或缺少通用缓存工具，不代表本机没有缓存。只使用真实声明的操作、精确来源与品种身份，不猜工具别名、时区或连接 ID。

保留来源、时间、单位、数值精度和显式未知状态；演示数据不得改称真实观察。读取完整分页并冻结实际返回行，区分来源覆盖与分页完成。只在缺口影响具体结论时说明实际影响，不把未知完整性自动变成面向用户的通用警告。

历史读取、实时订阅、图表显示和计算验证各有独立证据。成功退出或工具预览不能替代完整数据与冻结执行记录，声明报告路径也不能替代报告交付。数据获取按 market-discovery，读取输入与登记计算按 analyze-data；完整参数和示例按需查各自参考。
