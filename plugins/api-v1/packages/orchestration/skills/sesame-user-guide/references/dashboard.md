# Dashboard：把需要的内容放在眼前

## 三个水平窗口

| 区域 | 对用户的作用 |
| --- | --- |
| 左侧图表区 | 同时看多个品种或同一品种的不同周期；叠加已发布指标与研究曲线。 |
| 中间 Agents | 对主 Agent 说目标、追问、纠正或要求它调整视图。初始页面是 Open Sesame，输入提示为 Whisper your wish…。 |
| 右侧研究栏 | 居中顶部的 Research / Strategy 切换研究与策略成果；打开报告、交互图表和任务对话。报告的“继续对话”可接着修改成果。关闭标签页只是收起视图。 |

窗口总宽度可以超过屏幕，并不意味着丢失。焦点不在输入框、菜单、弹窗或分隔线等控件上时，按 **←** 看左边内容（整排向右移动），按 **→** 看右边内容（整排向左移动）；按住会连续平移。也可在图表之外横向滚动。编辑文字时左右键仍用于移动光标。

外层窗口之间只有一条竖线。拖这条线只改变它**左侧相邻窗口**的宽度，右边窗口整体让位，不被一起压窄。三个外层窗口不能交换顺序或拖成浮动窗口。用键盘聚焦分隔线后，左右方向键可微调宽度。

## 浮在角落的控件

- 左上是 Sesame 标识；Mac 桌面窗口控制与可拖动区域保留在这一侧。
- 右上钱包图标打开“账户与交易”；右上 User 人像打开设置。它们是悬浮玻璃控件，没有占高度的整条顶栏。窄窗口里券商文字会隐藏，图标仍在。
- 账户面板可选择已连接的账户，显示余额、净值、浮动盈亏和可用保证金，并分别展示持仓与挂单；明细未获取、部分返回或提供方不支持时保留对应提示。查看账户和看图本身不下单。

## 图表的新增、排布与关闭

1. **新增**：双击图表之间或外缘的可插入缝隙，新图插在所选缝隙。新图沿用相邻图的品种和周期，再在它自己的设置里更换。完全空白的图表区有新增入口，也可让 Agent 添加。
2. **移动单张图**：在图表上双击，第二下按住并拖动；或按住本图组件栏的拖动把手。靠近另一张图的左、右、上、下边缘，灰色玻璃预览会显示松手后的插入位置。满意后直接松手；按 Esc 可取消本次拖动。
3. **调宽高**：拖图表之间的竖缝调宽，横缝调高。连续缝隙会调整两侧完整区域，不是任意单元格都独立缩放。键盘聚焦缝隙后，可沿相应方向用方向键微调。
4. **压到零删除**：把一侧宽或高拖到零后松手，该侧图表会关闭；若是一整组，该侧多张图都可能被关闭。想保留它们，只做小幅调整。也可以用本图“图表操作 → 关闭图表”精确关闭一张。
5. **自适应与持久化**：图表以平铺方式利用空间，布局自动保存；没有手动保存、撤销/重做按钮。上下插入会保留图表的可读高度，内容变长后纵向滚动，不强制把所有图压成一屏。

“收起”保留图表，在收起条点“展开图表”可回来；“关闭”移除这张图。锁定、收起或最大化时无法按普通方式拖动排布。先解锁、展开或恢复，再调整。

## 滚轮：先看指针在哪

- **在图表绘图区内**：上下滚轮缩放时间轴，优先交给当前图表，不带着整页上下走；水平触控板滚动用于平移这张图的时间轴。
- **在图表缝隙、空白边缘或图表外**：滚轮滚动对应区域；图表内容过长时在缝隙或边缘纵向滚动，也能拖滚动条。
- 想看更早行情：在图内按住拖动时间轴，历史按需补充；“回到最新”回到最近行情。不要把“缩小图表”和“把窗口高度变矮”混为一谈。

## 每张图自己的组件栏

指针移入图表，靠下方会出现组件栏；键盘聚焦时也会显示。所有操作只针对这一张图，除非主动开启时间轴联动。

品种、周期和 OHLC 信息在图表底部。没有行情时点“让 Sesame 配置连接”，会直接向主 Agent 发送配置请求并切到对话栏；已有任务运行时请求进入队列，不打断当前任务。

安装并绑定支持订阅的提供方后，可见图表按该提供方实际机制更新，K 线、成交量和在线指标随真实数据变化。不同后端可能采用不同轮询间隔或流式能力，不能统一宣称每秒行情。实际速度取决于提供方响应，价格没变化不会伪造变动。屏幕外图表暂停绘制，回到视野后补齐；休市或断线时保留最后行情，恢复连接后续接。一次性发布的研究数据曲线是静态结果，不会自动重算。

| 控件 | 怎么用、会得到什么 |
| --- | --- |
| 拖动把手 | 按住拖动，改变该图在图表区的位置。 |
| 图表设置 | 搜索当前绑定提供方的真实品种（匹配并分页加载）、选周期、切换 K 线／美国线／折线／面积图。 |
| 成交量 | 新图默认显示，可在本图设置关闭。显示当前来源的量，不假定所有市场都是真实成交量，外汇可能是 tick volume。 |
| 均线 | 开关内置 SMA20 与 EMA50；其他指标可让 Agent 编写。 |
| 交易标注 | 当前通用图表未渲染成交标注。查看成交时，让 Agent 按所选账户提供方的实际能力读取并引用结果。 |
| 对数坐标 | 按相对比例观察价格变化，适合比较跨度较大的涨跌。 |
| 时间轴联动 | 默认独立；可选 A/B/C 或已有自定义组，面板显示当前实际分组。同组图会同步拖动和缩放的时间范围，不统一价格轴。想只调整当前图，选择“独立”；也可让 Sesame 取消指定图表的联动。 |
| 代码曲线 | 选择已绑定的指标成果修订，编辑 JSON 参数后应用到图表，或移除该曲线；指标源码由 Agent 编写、发布并绑定。 |
| ＋ / － | 放大、缩小这张图的时间范围。 |
| 显示全部 | 适配当前已加载的数据范围，不表示下载所有历史。 |
| 回到最新 | 回到最近一段行情。 |
| 图表操作（…） | 锁定/解锁、收起、最大化/恢复、保存图表图片、全屏、关闭。最大化填满图表窗口；全屏是浏览器全屏。 |

可直接说：“把 EURUSD 的 H1 和 M15 放在一起，联动时间轴，并在 H1 上画 20 周期均线。”Agent 应使用实际券商品种名称，显示成功后再确认。
