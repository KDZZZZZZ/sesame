# 官网说明与历史演示

[插件库](https://sesame.bot/zh/plugins/) 的新 API 1 区域面向正式目标 0.2.0 与匹配开发预览。应用发行与下载状态以官网实际标识为准；插件 development 归档不等于应用安装包。0.1.4 保留独立历史目录。核对页面标识和实际安装版本，不把旧演示的按钮、默认后端或安装话术套用到新版。

本插件的 installation/settings/dashboard 参考页说明当前目标。官网历史演示用于解释交互与表达，不证明用户当前账户、行情或原生策略结果：

- [工作台](https://sesame.bot/demos/?view=dashboard&lang=zh)：布局、拖动和缩放。
- [代码指标](https://sesame.bot/demos/?view=indicator&lang=zh)：修改参数并查看曲线。
- [走势报告](https://sesame.bot/demos/?view=technical&lang=zh)、[相关性](https://sesame.bot/demos/?view=correlation&lang=zh)：查看来源、筛选和比较。
- [策略结果](https://sesame.bot/demos/?view=strategy&lang=zh)：学习参数、曲线与明细联动，不等于 MT5 或 QMT 真实执行。

报告插件的 examples/editorial-demo.html 是明确虚构的离线设计样本。真实任务用自己的固定 DataRef，发布后以实际 report_check 回执判断渲染是否通过。
