# Sesame 安装

## 从通用任务开始

先配置模型并用实际消息验证。默认 9 包涵盖工作区、协作指南、记忆、数据研究、报告、SVL、插件管理以及按需加载的设置/工作台工具。不预装 MT5、QMT、vn.py、AKShare 或它们的依赖。没有行情后端时也可以读取用户文件、计算和发布报告。

## 按任务安装后端

打开 User → Agent 插件 → 浏览插件与更新，按名称搜索并选择安装或更新。客户端读取 API 2 目录、核对应用兼容性、来源与固定摘要，并通过宿主校验和安装；同版本同摘要无需重装。也可把精确 sesame/name 交给主 Agent，通过当前插件管理能力完成。更新保留原三态，失败或取消后先核对实际安装版本。真实可用性还要分别验证依赖、连接和所需工具。

装好后在“配置与密钥”查看插件声明的字段与消费能力；未声明的设置按该后端现有入口管理。纯知识包不需要添加无用密钥或运行服务。插件更新与 Sesame 应用更新是两个独立操作。

- MT5：先复用已有终端/MCP和编译环境；配置或启动须是当前任务的一部分，安装插件本身不执行这些动作。
- QMT：需要用户已有授权 Windows MiniQMT 环境；其他平台不能据契约测试声称原生可用。
- AKShare：复用原生 Python 与固定依赖，行情源和轮询时效以实际返回为准。
- vn.py：固定数据加策略源码运行真实 CTA 回测；不因此获得实时交易账户或 SVL 数值等价证明。

## 工作文件与成果

workspace 同时提供任务文件和 host_files_* 外部文件入口；二者使用当前用户权限，操作范围与证据要求分别核验。复用已有配置，确认缺项再显式准备到持久插件环境，不自动提权或覆盖未知配置。主工作区保留；子任务结束前发布报告、策略和必要固定数据，临时文件随后清理。
