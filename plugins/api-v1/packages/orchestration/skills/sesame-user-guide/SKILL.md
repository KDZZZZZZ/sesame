# Sesame 用户使用指南

这是官方产品说明，供主 Agent 按需教学。目标是让用户完成自己的任务，而非介绍 Agent 的工具清单。它不增加执行权限，不替代配置、图表、研究、记忆或策略插件。

## 如何回答

1. 先判断用户是在问“怎么做”，还是要求你代做。前者简洁教学；后者直接使用已允许的业务能力完成。没有必要先询问是否开始。
2. 按下表读取相关参考页。用 `plugin_read` 读取本插件已声明资源，或按本 skill 所在目录读取相对路径；不要把本机文件路径抛给普通用户。
3. 用“你能得到什么 → 入口与 2–5 个步骤 → 做完会看到什么 → 一句可复制的请求”组织回答。很小的问题直接给答案。用户要完整指南时才展开全部章节。
4. 涉及“你现在能不能做”“为什么没显示”时，读取当前工作台、配置或插件状态。区分功能存在、已配置、请求已保存和实际成功。看不到用户指针或焦点时不要猜；只在答案确实依赖它时问一个具体问题。
5. 初次上手可先分析用户文件并发布图文报告，不需要行情后端。用户要行情时再发现/安装目标后端，读取实际品种和能力；不猜券商名称或后缀。

## 教学约束

- 三个外层窗口固定按图表、Agents、研究从左到右排列；不要描述为自由拖动的无限画布。
- 不推荐已移除的导航页、顶部栏、Import CSV 按钮、布局保存/回退按钮或手动自动连接按钮。
- 帮助用户提供本机普通文件路径、数据来源网址或已有报告；不要凭空建议当前不存在的上传控件。
- 仅浏览和绘图无需开启交易权限。对交易、部署和宿主访问，只解释当前权限与真实操作前提，不因用户在学习就改变它们。
- 默认只安装通用骨架与规范包；MT5/QMT/vn.py/AKShare 等后端按需安装。已有程序、账号和平台授权不由插件安装提供。模型错误读取实际状态，不承诺固定重试次数或所有供应商行为相同。
- 不声称研究结论必然盈利，不把代码编译或参数拟合当成真实回测成功。使用可选判断复盘插件时，未来判断必须按其真实事前登记与证据规则处理。
- 判断复盘是主 Agent 可见的按需 skill：由它根据当前任务与新证据决定何时查看待办，用户也可直接要求复盘。不会定时发送用户消息或在后台唤醒模型。
- 没有新工具的说明型插件可以正常工作；不要把其“未运行”当成故障。

## 维护入口

说明以当前仓库前端及宿主实现为准。组件或交互变更时同步对应参考页；`/skill:` 清单来自已挂载插件的 Skills，外部安装会改变实际列表。不要复制其他产品的斜杠命令。
