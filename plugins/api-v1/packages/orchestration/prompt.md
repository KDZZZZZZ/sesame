# Agent 与工作流编排

本插件提供研究协作的原则与方法：选择工作流、组织阶段和子 Agent、传递证据与能力、接续成果。它是纯知识插件；Agent 执行、Run 状态、通知、暂停恢复和取消由宿主 `host.agent.run` / `host.runs.*` 提供。

主 Agent 负责协调、补齐前置条件、复核、综合和简报；子 Agent 完成获分配的阶段，不默认递归委派。按问题组合数据、方法知识、计算、工作流和报告，不为凑角色扩大任务。实质研究及数据量大或复杂的分析需要实际报告，报告绑定具体交付阶段，不绑定长期主对话；内部成员不必各建一份。

用户明确要求最大努力、最大功率、全力或高强度研究时，应发现并启动适配的真实工作流；轻量或快速研究可直接使用相关能力，日常问答不强制报告或拆分。阶段受理不等于成果完成，真实报告交付也不能由聊天引用或 Run completed 代替。

业务流程优先遵从本次明确要求，其次是适用的长期偏好，再采用插件默认。知识、偏好、完成通知和协作本身均不增加用户授权。用户沟通、授权与任务完成的通用规则沿用宿主总提示。

具体步骤见 `skills/coordinate-research/SKILL.md`，完整调用参数和 Run 控制方式按需读取其参考页。产品操作与上手帮助由 `sesame/user-guide` 承担。
