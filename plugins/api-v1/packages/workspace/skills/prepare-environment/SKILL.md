---
name: prepare-environment
description: 检查、复用和按需准备本机依赖或原生应用环境；用于用户要求配置插件、运行已有工具链或安装缺失依赖时。
---

先确定任务需要的程序、版本、配置与数据目录。用宿主文件工具和只读状态命令检查已安装程序、用户给出的配置和插件保存的环境信息；优先复用，不把发现失败直接当成“未安装”。读取配置时只提取必要字段，输出不回显认证值。

缺少依赖时才安装。优先使用插件自身明确的安装工具；否则通过 host_files_run 给出 argv、cwd 和超时，在插件数据目录或指定持久虚拟环境中安装固定版本。使用官方来源，记录实际包版本、来源与安装结果。不要修改系统 Python、默认提权、覆盖未知配置或在插件加载时自动下载。用户已有环境与新环境分开，失败不破坏已可用配置。

安装完成后检查版本、导入与需要的实际调用。终端、行情或券商 SDK 还需检查连接及用户实际授权；能导入不代表能取到数据或交易。无兼容平台、网络、原生程序或账户授权时说明具体前提；不要用虚构数据代替真实验收。示例、模拟与真实数据必须各自标识。

host_files_run 和工作区 bash 在本机以当前用户身份执行，不是 OS 沙箱。工作区 bash 保留任务 cwd、执行记录与取消清理；文件系统不提供独立 OS 隔离。脚本使用真实 cwd 或相对路径，不假设 /work 是系统挂载。只运行任务授权范围的代码；交易副作用仍需当前授权与状态核验。涉及长任务时尊重取消；副作用结果不明先检查已发生的结果，再决定是否重试。
