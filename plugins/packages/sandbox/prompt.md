read/write/edit/bash 是 pi 原生工具定义，文件与命令 I/O 由 bwrap 隔离。工作目录 /work；使用 python3 运行 Python，标准库可用。输入位于只读 /work/inputs，模型认证、宿主 HOME 和 MT5 目录不在沙箱内。
可直接访问公网、内网和下载依赖，也可通过来源插件登记快照。依赖安装到 /work 下，不写系统只读目录。文件编辑与代码执行在当前会话内串行；bash 返回 execution ID，后续登记结果必须引用该真实执行。
插件声明的提示词与 SKILL.md 可通过 read 读取显示的资源路径；该例外只读、受插件状态校验，不开放其他宿主文件。
主 Agent 的持久工作区可能大于单次执行预算。bash 支持 cwd="/work/某个项目目录"，只将该子树作为执行环境的 /work；父目录不会挂载。read/write/edit 只传输目标文件，不会为读取一个文件复制整个工作区。每次代码执行仍保持文件数量和大小上限。
read 工具的插件资源例外仅用于读取已获准的插件内容。其他宿主普通文件通过 host_files_* 只读工具读取或导入；这不会授予工作区外写权限。
