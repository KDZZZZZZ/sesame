# Sesame 官网文档：产品用法与可交互演示

依据用户编写的 [sesame.bot 文档](https://sesame.bot/zh/docs/)，于 2026-10-08 读取线上版本，随此插件离线提供。涵盖快速开始、专属顾问、研究报告、魔术仪表盘和量化策略五章。按用户当前问题读取相关部分，优先给出能直接执行的请求和对应演示，不一次发送整页。

操作说明已按当前应用校对：图表信息在底部；连接入口直接请求 Sesame 配置；模型失败每隔 5 秒重试；生成中支持消息排队与抢占；判断复盘由主 Agent 在任务中按需执行，不定时发送用户消息。官网演示使用已发布报告或历史数据，不代表用户当前账户、实时行情或已完成的原生 MT5 回测。

## 快速开始

来源：[开始使用](https://sesame.bot/zh/docs/quickstart/)。

1. 从 [下载页](https://sesame.bot/#get) 选择对应安装包：Windows 10/11 使用 `.exe`；macOS 13+ Apple Silicon 打开 `.dmg`，把 Sesame 拖进 Applications；Ubuntu/Debian 桌面安装 `.deb`，也有 AppImage。首次启动与额外运行环境见本插件的 installation.md，不把安装成功当成所有执行环境已就绪。
2. 在右上 User → **模型与运行状态** 选择供应商、认证方式和模型。使用该供应商支持的 API Key 或浏览器登录，保存后发一句消息确认可以回复。模型账号和额度由用户准备；普通模型密钥在设置中输入。
3. 打开已经安装的 MT5，登录券商账户。在 **工具 → 选项 → MCP** 启用本机服务，提供相应原生授权。把 MT5 导出的 Claude Code / Codex 配置复制给 Sesame，它会保存并检查；也可在 MT5 连接设置填写。在空白行情图点击 **让 Sesame 连接 MT5** 会直接向主 Agent 发送配置请求。
4. 直接开始：说“分析这份 CSV 并画图”“研究一下当前的品种”或“创建并编译一个 MQL5 策略”。遇到问题，说“检查模型、MT5 连接和运行环境”；系统学习可说“教我使用 Sesame”。Sesame 不附带 MT5 或券商账户。

新安装默认开放网络、MT5 交易和原生网络/shell 权限；交易、宿主访问和 Python 插件默认可发现，Agent 按需加载。用户可以要求主 Agent 调整应用权限。MT5 自身的 MCP、账户和程序授权仍以终端实际状态为准。已有用户保存的关闭选项不会因升级而被抹掉。

| 聊天操作 | 结果 |
| --- | --- |
| `@` | 选择并引用 Research / Strategy 报告；不是文件或 Agent 选择器。↑ / ↓ 选择，Enter 或 Tab 插入，Esc 关闭，可同时引用多份。 |
| `/clear` | 清空可见对话并回到 Open Sesame，保留实际聊天、上下文与长期记忆；生成中不可使用。 |
| `/skill:名称` | 调用本会话已加载的 skill，例如 `/skill:sesame-user-guide 教我拖动图表`。 |
| Enter / Shift+Enter | 发送 / 换行。运行时有文字则发送并排队；⌘/Ctrl+Enter 或抢占按钮立即介入；输入框为空时显示停止按钮。 |

| User 设置 | 解决什么问题 |
| --- | --- |
| 语言、主题 | 更换界面语言与明暗；Open Sesame、Whisper your wish… 保持英文。 |
| 模型与运行状态 | 设置供应商、认证、模型、思考级别，查看研究环境状态。 |
| MT5 连接与能力 | 查看服务状态、认证和原生权限；配置完成后自动连接与恢复。 |
| Agent 插件 | 管理默认挂载、可发现、不可使用和远程 MCP 连接。网络已默认开放，没有网络模式开关。 |
| MT5 策略工程 | 查看源码、版本、可视化逻辑、编译与真实回测，设置 Tester 风险限额。 |
| 记忆与工作区 | 搜索、固定、归档或忘记长期记忆，查看最终成果和临时文件清理状态。 |

## 专属量化顾问：把一个问题交给几个研究方向

来源：[专属顾问](https://sesame.bot/zh/docs/advisor/)。

主 Agent 可以并行安排 subagent，分别查资料、处理数据、寻找反例，再汇总一致之处与分歧。最终报告和策略保留，子任务结束后清理临时研究文件。

可直接说：

> 安排三个 subagent 分别研究趋势、均值回归和失效场景，用同一段数据比较，给我一份结论和分歧都清楚的报告。

需要什么方法，就加载什么插件。在 User → **Agent 插件** 管理常用能力，也可以让 Sesame 查找 QuantSkills 的量化方法，或把反复使用的流程整理成插件。

| 加载方式 | 适合什么情况 |
| --- | --- |
| 默认挂载 | 符合范围的会话自动加载，适合经常使用的方法。 |
| 可发现 | 任务需要时查找和加载，减少日常上下文占用。 |
| 不可使用 | 不向 Agent 提供查找和调用，需要时由用户重新启用。 |

> 把“读取公告、去重、抽取日期与事件、生成时间线报告”做成插件，先用两份公开资料测试。

让判断接受后来的检验：先记录对象、期限、判定标准与概率，证据到齐后复盘。主 Agent 在自己的持久工作区整理偏差和适用条件，提醒相关 subagent 读取。证据不足继续标记待核实；候选方法接受新样本检验。复盘由主 Agent 根据任务和新证据决定何时进行，用户也可以直接要求检查到期判断。

[判断复盘演示](https://sesame.bot/demos/?view=review&lang=zh)：用 2024 年历史数据校准均线判断，再看 2025 年逐条结果；切换均线周期和命中/失效筛选，检查反例。它是历史重放，不是当前账户正在运行的预测。

记忆设置可以搜索、固定、归档或忘记经验；长期不用的记忆逐步退出自动加载。模型供应商支持何种订阅或认证，以实时目录和该供应商说明为准；自定义供应商需要协议、Base URL、模型 ID 和认证，保存后用实际回复确认。

## 产出精美可靠的市场研究报告

来源：[研究报告](https://sesame.bot/zh/docs/reports/)。

从一个问题开始：告诉 Sesame 市场、时间范围和比较对象，它会取数据、计算、作图，在右侧 Research 交付报告。讨论到合适阶段可主动总结交付，用户也可直接说“把这次研究整理成报告”。

报告以图表传达信息，文字简洁、结构清楚；数值来自实际数据源和可检查的计算，Agent 决定怎样引用和呈现。交互可用于切换窗口、筛选条件、比较参数和检验假设；统一风格不应掩盖数据口径或证据不足。

> 并行研究价格结构、成交量和反对观点，最后合成一份带数据来源的报告。

| 可交互示例 | 可以实际操作什么 |
| --- | --- |
| [走势与关键价位](https://sesame.bot/demos/?view=technical&lang=zh) | 已完成的中天科技研究，66 个交易日至 2026-09-30。点图例开关均线、移到曲线上读数、展开方法查看口径。 |
| [板块热度与候选比较](https://sesame.bot/demos/?view=sectors&lang=zh) | 已发布的 14 个板块 ETF、10 只个股研究；比较涨幅、量比和排名，展开表格查看其余行，检查新闻统计。 |
| [相关性会随窗口改变吗](https://sesame.bot/demos/?view=correlation&lang=zh) | 选 30、90、180 或 365 天，点一对资产，观察归一化曲线如何变化。 |
| [换一种仓位，回撤差多少](https://sesame.bot/demos/?view=allocation&lang=zh) | 切换资产并拨动仓位滑杆，比较持有与现金的收益、最大回撤。 |
| [如果错过涨幅最大的几天](https://sesame.bot/demos/?view=timing&lang=zh) | 移除历史中最好或最差的若干天，重新计算净值；这是事后情景重算。 |

引用已有报告继续工作：聊天框输入 `@` 选择报告，也可在报告中点“继续对话”。Sesame 读取所引用的具体版本，再补数据、改图或发布新版本。

> @中天科技走势研究 把关键价位画到行情图上，再把均线周期换成 10 和 30，解释有什么变化。

## 魔术仪表盘：你看行情，Sesame 安排视图

来源：[仪表盘](https://sesame.bot/zh/docs/dashboard/)。

图表、Agents、研究从左到右排列。图表区最多放 32 张图，每张拥有独立的品种、周期与组件栏，布局自动保存。品种、周期和价格信息在图表底部，不占顶部空间。

> 把 BTC 的 H1、H4、D1 放在一起，联动时间轴，并给 H1 加一条 20 周期均线。

[工作台演示](https://sesame.bot/demos/?view=dashboard&lang=zh) 可实际尝试拖动、双击与缩放。使用券商数据时先查实际品种名称，不假定券商就叫 BTC。

| 操作 | 发生什么 |
| --- | --- |
| 新增 | 双击图表之间或外缘的缝隙，新图插在此处，沿用相邻图的品种、周期。 |
| 移动 | 图上双击，第二下按住拖动，或使用组件栏把手。靠近另一张图四边，看到灰色玻璃预览后松手；Esc 取消。 |
| 调宽、调高 | 拖竖缝改宽、横缝改高；连续缝隙调整两侧整组区域。 |
| 关闭 | 本图“⋯ → 关闭图表”，或把一侧宽/高压到零再松手；整组压到零会关闭该侧多张图。 |
| 缩放行情 | 指针在图内时上下滚轮缩放时间轴，不滚动整页；也可点 ＋ / −。 |
| 平移、历史 | 图内按住拖动或横向触控板滚动，历史按需补充；“回到最新”返回末端。 |
| 上下滚动图表区 | 指针放在缝隙、边缘再滚动；上下插图保留可读高度，超出一屏后纵向滚动。 |
| 看 Agents / 研究 | 焦点在控件外时，← / → 平移整排窗口；输入框内移动光标。 |
| 调三个窗口宽度 | 拖外层竖线，只改变左侧相邻窗口宽度，右边整体让位。 |
| 暂时收起、放大 | “⋯”中收起、最大化、全屏；恢复后再重新排布。 |
| 键盘操作 | Tab 聚焦缝隙后用对应方向键调宽高；聚焦插入缝隙后 Enter 新增。 |

指针移入图表，下方出现本图组件栏。设置里可搜索并分页加载所有券商品种、改周期、切换 K 线/美国线/折线/面积图，开关成交量、均线、交易标注和对数坐标；时间轴默认独立，也可主动选择同一 A/B/C 组联动。

连接 MT5 后，可见图表每秒检查一次新行情；价格未变化时不伪造跳动。历史按需获取，离开视野暂停，恢复时补齐。一次性研究曲线保持发布时的结果；在线代码指标随行情数据变化重新计算。

> 画一条 20 周期均线和最近 20 根 K 线的最高、最低价通道，周期保留为可修改参数。

[代码指标演示](https://sesame.bot/demos/?view=indicator&lang=zh)：改周期重新执行曲线代码，图内能打开编辑器。不需要用户自己写代码，描述公式、数据和主图/副图即可；愿意手动修改时，打开“代码曲线”，编辑 JavaScript/TypeScript 或参数，点“应用到图表”。

## 量化策略开发：从规则到可检查的结果

来源：[策略开发](https://sesame.bot/zh/docs/strategy/)。

说清入场、退出、仓位与风险限制，Sesame 编写代码、生成可视化逻辑、完成编译与回测，在 Strategy 交付结果。用户把注意力放在规则、证据和比较上，不必逐行读代码或亲自整理回测数字。

> 开发一套快慢均线策略。先解释规则，再回测不同参数，比较收益与回撤，让我能查看每笔交易为什么发生。

流程：规则（入场、退出、仓位、限制）→ 工程（源码、参数、编译、逻辑图）→ 回测（净值、回撤、参数、交易）→ 挂载（通过验收后进入策略挂载）。

[策略结果演示](https://sesame.bot/demos/?view=strategy&lang=zh)：点选 16 组参数，净值、回撤与交易列表一起变化；切换价格与交易/净值曲线，点交易或“信号与成交”查看实际输入与执行时间。该示例在真实 BTC 日线上执行研究回测，应用内的 MT5 策略还需要原生 Tester 验证，不能混称为同一种证据。

在策略工程看源码、状态图和规则依赖。点节点看表达式与输入，再核对哪一天满足条件、哪根 K 线执行、何事触发退出。直接要求“解释这笔交易”“把退出条件改成……”或“用另一段时间重测”，继续修改与验证。

明确要求 Sesame 挂载已回测策略，或右上账户面板 → **策略挂载**，选版本并点 **一键挂载**。应用自动准备并核验账户、构建和风险限制，通过后挂载；需要重启终端而存在持仓、挂单或其他 EA 时会暂停。停止挂载停止 EA，不自动平仓。

图表开启“交易标注”可点击成交看记录；由可追溯策略产生的交易能继续查看关联规则证据。没有完成的编译、真实回测或交易证据，就如实说明缺项，不以演示数字替代用户自己的结果。
