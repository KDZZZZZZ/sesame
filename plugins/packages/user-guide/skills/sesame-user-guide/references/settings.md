# User 设置：按想解决的问题选择

入口在右上角人像 **User → 用户设置**。输入框下方的模型名称也能打开“模型与运行状态”。通常只需要设置可用模型、连接 MT5，其他选项按任务需要再看。

## 语言与主题

- 语言：中文 / English，改变应用界面与默认回复语言；Open Sesame 和 Whisper your wish… 保持英文。
- 主题：浅色 / 深色，按观看习惯选择，图表同步更新。

## 模型与运行状态

| 项目 | 对用户意味着什么 |
| --- | --- |
| 供应商、模型 ID | 选择由谁来处理你的对话和任务。使用实际已开通、可调用的模型。 |
| API Key / 浏览器登录（OAuth） | 给 Sesame 连接该供应商的认证方式；按当前供应商支持的方式填写。编辑已配置模型时，密钥框留空表示保留原认证，填入新 Key 表示更换认证；已保存的密钥不回显。 |
| 自定义 Base URL、接口协议 | 接入兼容服务时填写对方提供的地址与协议，和“模型 ID”分开，不需要普通用户自行猜。 |
| 思考级别 | 调整模型推理投入，支持程度依模型而定；更高可能耗时、耗费更多，不等于保证正确。 |
| 上下文窗口 / 最大输出 | 只在自定义模型配置中需要：前者是可处理上下文量，后者是单次输出限制，应按供应商实际值填写。 |
| 模型支持推理 | 对自定义模型声明它是否支持推理，不会给不支持的模型增加能力。 |
| 保存并使用 | 保存配置并选用；仍要以实际回复验证余额、权限、网络和模型是否可用。 |
| Research 沙箱、MT5 状态 | 当前研究执行环境与终端检测信息。缺失时影响相应工作流，不表示所有聊天功能都失效。 |

上下文可自动压缩，但这不是永久记忆。要长期记住的偏好应明确说“记住”，或在记忆设置中查看。密钥和验证码只在对应设置/授权窗口输入，不贴到聊天或报告。

## MT5 连接与能力

已配置设备默认自动连接，断线后尝试恢复；没有需要反复点击的“自动连接”按钮。自动连接复用终端保存的登录，核验券商在线与账户匹配，不自动切换账户或下单。

| 服务或选项 | 用途与含义 |
| --- | --- |
| 交易终端 | 查看券商行情、账户和已允许的终端功能，是看 Dashboard 实时行情的主要连接。 |
| MetaEditor | 编辑、编译 MQL5 时按需自动启动；未启动不影响看盘。 |
| MetaTrader.com 市场数据 | 独立数据服务；未启用不等于券商行情离线。 |
| 官方 Python API | 供需要它的量化任务使用；“已安装”只表示环境存在，实际连接另行核验。 |
| 终端启动器 | 原生程序/代理服务相关功能；环境存在不代表任务已执行。 |
| 高级设置 → 启用连接、地址、API Key | 指定服务地址与认证。首次原生 MCP 需在 MT5 自身设置启用并填入正式导出的当前 Key。 |
| 读取本机配置 | 尝试导入能识别的本机设置；受保护的密钥存储值未必能直接当 API Key。 |
| 保存连接设置 / 检测官方能力 | 前者保存并唤醒自动连接；后者读取实际工具目录。已保存密钥不等于认证或券商登录成功。 |
| Python 账户连接 | 填写明确的 Login、券商服务器与需要的密码；看盘优先复用终端已保存登录，不猜券商服务器名。 |
| 原生启动配置（INI） | 高级用户配置新启动终端的行为，可能含秘密，因此不回显；普通看盘不必填写。连接恢复使用自己的固定配置。 |
| MetaTester 代理服务 | 配置官方代理服务的地址、端口、密码；保存不等于安装或启动服务。 |
| 允许原生网络与 shell 工具 | 新安装默认开启，可要求主 Agent 调整；控制 MT5 原生宿主工具，还受 MT5 自身授权约束。 |

“未启用、待配置、未启动、未安装、已安装”是不同状态，按需求处理；“连接异常”才需要根据真实错误排查。用户无需为暂时不用的服务把所有状态都变成已连接。

应用交易权限默认开启；要调整可以直接说“关闭 MT5 交易权限”或“启用 MT5 交易和宿主权限”。主 Agent 会读取现值、按版本保存并核验结果。此操作不产生订单，不代替终端原生授权。设置开关的滑块、轨道和文字都可点击，键盘聚焦后可用空格切换。

## Agent 插件

| 项目 | 用途与含义 |
| --- | --- |
| 默认挂载 | 在符合范围的会话中自动加载提示词、工具和 skill。 |
| 可发现 | Agent 需要时可以查找并加载；本次加载只属于当前会话。 |
| 不可使用 | 不向 Agent 提供发现、调用与读取，不能靠其他工具绕过。 |
| 内置 / 外部、版本、诊断 | 知道能力从何而来、当前版本是否正常。内置随应用更新；外部安装可按页面选项回滚或卸载。 |
| 未运行 / 已就绪 | 插件运行进程的状态；纯说明型插件不需要启动进程，并不因此失效。 |
| 远程 MCP 连接 | 为某插件的某个服务设置地址与可选认证。凭据只用于保存的精确地址，不写进插件包；更换地址不会沿用旧凭据。清除连接凭据后，免认证服务仍可访问。 |
| 连接 Claude / Codex | 让外部客户端通过 Sesame 的 MCP 地址访问开放的工具；此处凭据与 MT5 的 API Key、模型 Key 是三种不同的凭据。更换凭据会断开旧授权。 |

主 Agent、subagent 和 MCP 可访问公网、内网并下载依赖。需要认证的服务仍使用单独配置的凭据。插件策略共用，但有主 Agent 专用范围；正在运行任务时设置可能需要等任务完成。仅介绍这些选项不代表用户已经授权改变它们。

## MT5 策略工程

用来把一句策略设想变成可以检查的源码版本、编译产物、回测记录、状态图和交易证据。可查看/创建工程、读模块和源码、设置平台 Tester 限额、编译某个版本、选择品种/周期/时间/参数进行真实回测。

平台 Tester 限额包括单次风险、每日亏损、持仓与挂单数量、总手数等，由用户设置，策略参数不能覆盖。草稿能编译并不代表逻辑已完成；编译成功也不代表回测完成或可以部署。实际挂载在账户面板的“策略挂载”中查看准备与验收结果。普通分析、看图和画指标不需要走部署流程。

## 记忆与工作区

- **长期记忆**：按用户偏好、项目事实、策略、纠错经验、参考资料分类；可搜索、查看来源、修改、固定、归档、恢复或忘记。
- **常用 / 较少使用 / 已归档**：按真正采用的情况管理，长时间不用会逐步退出自动加载，归档仍可查回。固定的重要记忆保留。具体天数以页面当前策略为准。
- **已过期 / 待核实**：需要重新检查来源或冲突后再用；不是可靠的当前事实。
- **待整理候选**：还没进入正式长期记忆，审阅后才能保留；不要把候选当成已经记住。
- **归档与忘记**：归档可恢复；忘记删除正文与索引，不能从归档恢复。`/clear` 不做这件事。
- **工作区与清理**：主 Agent 工作区持久保留；subagent 结束后封存最终报告、策略与必要依赖，再销毁本次会话、工具结果和临时文件。清理失败可查看状态并重试。
- 工作区外普通文件可读，处理时导入副本；凭据、应用控制数据与其他子任务私有内容受保护。普通研究不修改用户原文件。
