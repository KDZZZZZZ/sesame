# canvas-control: publication provenance

Publisher: Sesame (https://github.com/KDZZZZZZ). Package version: 1.4.1.

This directory is a deliberately bounded export of the official Sesame 0.1.4
plugin files. It contains the plugin source, prompts, schemas and skills only.
The MIT license in this directory covers the files authored by Sesame here;
it does not license the private Sesame host application or any code referenced
by imports outside this directory. Third-party content retains its own rights.

This is a bundled Sesame plugin. Its native factory or guide depends on the installed application. Publishing its source does not make it a standalone package, and the catalog client must load the installed plugin rather than download and import its factory.

This export describes the 0.1.4 runtime, not the separate plugin API v1
refactor. Public source integrity is recorded by the immutable Git commit,
file hashes and tree digest in ../../catalog.json.
