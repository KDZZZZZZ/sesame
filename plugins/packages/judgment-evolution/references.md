# 研究依据与采用范围

调研日期：2026-10-04。以下是独立实现的设计依据，没有复制任何闭源系统内部算法。

- [PandaAI EVO 官方说明](https://www.pandaaiquant.com/docs/evo)：公开内容描述账号持久工作区、量化对象、任务编排及官方 Skills；并未完整公开内部自进化算法。本插件借鉴持续研究资产的组织方式。
- [QuantEvolve](https://arxiv.org/abs/2510.18569)：用假设驱动的多 Agent 演化及质量与多样性组织候选。本插件按主题和适用环境保留多个候选，避免只留下历史最优的一条。
- [EVOQUANT](https://arxiv.org/abs/2607.12455)：强调受控候选修改、验证和经验积累。本插件采用冻结判断口径、候选版本与独立核验，不复现论文的策略优化系统或其收益结果。
- [FinCon](https://arxiv.org/abs/2407.06567)：经理与分析员协作，并将经反思更新的观念选择性传给相关 Agent。本插件由主 Agent 维护准则，在委派提示词中指向相关文件。
- [FinMem](https://arxiv.org/abs/2311.13743)：分层组织不同记忆。本项目普通记忆可降温、归档；判断与证据台账作为最终业务成果独立保存。
- [Gneiting 与 Raftery，严格适当评分规则](https://sites.stat.washington.edu/people/raftery/Research/PDF/Gneiting2007jasa.pdf)：概率判断使用二元 Brier 损失 `(p-y)^2`，不只统计命中率。低损失不代表高交易收益。
- [Bailey 与 López de Prado，Deflated Sharpe Ratio](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=2460551)：反复选择候选会造成选择偏差。本插件记录全部候选数量、分离形成规则的历史证据与前瞻样本；没有宣称实现 DSR 或证明市场样本独立。

## 实际验证约束

规则采用前瞻影子概率，同时比较相同判断的主概率、事前基准与候选概率的 Brier 损失差。同主题和环境的全部未退休规则必须事前提交影子概率，防止选择性测试；每主题同时最多 10 个在试规则。相同事件去重，时间区间重叠样本合为一个块。默认至少 30 个样本块、3 个日历窗口，全部到期样本已核验，且对两种比较各自的 Hoeffding 改善下界都大于零，才能进入 active。错误预算按全局候选序号 k 和证据集合实质变化的检查序号 t 分配为 alpha/[2k(k+1)t(t+1)]，其中 2 为两个比较分配预算，同时约束多候选选择和持续窥看；重复读取不增加检查序号，重叠块合并也不会重复使用旧预算。实际市场仍可能存在跨时间相关性和分布漂移，active 只表示通过这套保守运行门槛。登记、核验及主 Agent 读取准则时重评，门槛失效进入 probation。

截止前冻结来源和 selector、指标、运算符、目标、观察窗口及概率。截止后仅从真实已登记数据集读取数值；观察时间必须带时区并处于冻结窗口，采用窗口内最后观察。多条同时间冲突数据拒绝核验。派生数据保留来源链、证据哈希和必要字段，而非完整临时执行日志。

主工作区 `work/judgment/` 保存可读准则、索引、指标和最近判断摘要；同一主工作区的 `judgment-state/` 保存宿主管理的权威台账。subagent 根据主 Agent 的委派提醒读取准则，不拥有修改台账的工具。

判断复盘以主 Agent 可见的 judgment-review skill 提供。主 Agent 根据任务与证据决定何时查看 judgment_review_queue；宿主不定时检查、不创建自动用户消息、不唤醒模型。普通回复进入持久语义核对队列，读取原文后再确认，关键词仅作线索。主 Agent 可用 judgment_review_due 核验已有证据，再用 judgment_reflect 完成归因；缺失证据明确保留待办。队列与权威台账在重启后保留，不因未处理而自动丢弃。历史版本的 automation 消息仍不能作为用户明确偏好的证据。
