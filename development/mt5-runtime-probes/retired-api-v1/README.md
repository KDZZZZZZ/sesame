# Retired MT5 VM compiler implementation

Historical source and tests retained when MT5 switched to native MetaEditor execution in 1.1.0. Not a plugin package, not in any official archive, and not part of current verification or prerequisites. The old guest transport SDK entrypoints no longer exist. Running this historical work requires its matching historical SDK and prepared runtime assets; no binaries, terminals, accounts, or VM images are included here. Current snapshot validation, native process receipts, EX5/diagnostic verification and dependency tests remain in plugins/api-v1/tests.
