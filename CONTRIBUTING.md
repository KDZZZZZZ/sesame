# Contributing to Sesame

Start from current `dev`. Contributors open a pull request from a fork into `dev`. The repository owner can use a same-repository work branch. Only the owner merges. Use a merge commit so release plans retain a reachable source commit.

`main` accepts release pull requests from this repository’s `dev` branch. Required checks and review discussions must be resolved before merge. Keep attribution, licenses and immutable release history intact.

For creating a package, running the checks and submitting a plugin PR, follow the [plugin contributor quick start](plugins/CONTRIBUTING.md). Maintainers promoting a version can use the [plugin publication guide](plugins/api-v1/PUBLISHING.md) or the [application release guide](RELEASING.md).
