# Research：按金融问题区分的内容结构

2026-11-16 · 设计稿，尚未实施

配套：[Research 插件设计](2026-11-16-research-plugin-design.md)。本稿重新设计其中的回答结构，不增加宿主接口、主题单元或报告业务模板。

## 1. 预设负责提供专业起点

共用的是调查过程、证据记录和成果交接；不同问题保留各自的分析关系与答案组织。不能把所有问题都压成“判断、依据、风险、下一步”，再仅替换标题或标的。

下表是依据公开报告、官方说明和分析工具示例提炼的 Sesame 设计，不是逐字复制机构报告，也不是这些机构共同采用的标准。来源表区分实际报告、官方样例、产品说明和软件文档；它们提供的证据强度不同。

每份预设保存：适用问题、独有的调查重点、完成该判断所需的证据、推荐回答结构、按条件展开的分支，以及可参考的样例。结构提供起点，用户的具体问题决定最终保留哪些内容。

## 2. 常见问题应有不同的答案组织

以下顺序用于指导内容，不规定页面布局、组件、字数或图数。分支只有与本次问题有关时才展开。预设中的数值必须来自本次证据，不能沿用示例报告的数据。

| 问题类型 | 本次研究特有的关系 | 推荐回答结构 | 裁剪与扩展 |
| --- | --- | --- | --- |
| 当前行情发生了什么 | 当前与前期、同类资产的变化；变化发生的时点 | 主要变动、涉及范围、相对强弱、相关的新信息 | 事实快照不自动变成预测或交易方案；参考 R5 的简报组织 |
| 当前技术结构怎样交易或观察 | 价格结构与观察期限、关键价位、触发与目标的关系 | 当前结构与期限；关键分界；满足条件后的路径和目标；相反条件对应的路径 | 用户只问走势时不加入仓位与执行安排；不强制固定目标数量。参考 R6 |
| 一天中何时更活跃，可能波动多大 | 不同时段、星期、期限的波幅分布 | 时段差异、不同期限的预期范围、与用户持有时间的对应关系 | 波动范围不等于方向预测；不照搬厂商样本的覆盖概率。参考 R7 |
| 现在有哪些机会或事件值得关注 | 候选之间的区别、事件时点、与用户条件的匹配 | 扫描：匹配条件与候选差异，再解释优先关注对象；日历：时点、事件、已知预期和相关资产 | 日历和机会筛选是不同分支；只问日历不添加整篇市场观点。参考 R5，筛选部分为 Sesame 扩展 |
| 公司怎样赚钱，增长质量如何 | 业务、客户、竞争条件如何形成利润与现金 | 收入和利润来自哪里；增长由量、价、业务组合还是投入驱动；现金转化与竞争持续性 | 不因研究公司就必须给目标价；首次研究与增量更新采用不同篇幅。参考 R1 |
| 现在的价格贵不贵 | 价格隐含要求与经营能力、可比对象的差异 | 估值对象与口径；价格隐含的经营要求；可支持的假设与价值区间；最敏感的变量 | 先选适合资产的估值方法，不给所有资产套公司现金流估值。参考 R1；价格隐含要求是 Sesame 的问题化扩展 |
| 财报发布前看什么 | 尚未公布的信息与现有预期之间的关系 | 事件与预期基准；最能区分结果的经营指标；驱动如何影响收入、利润或指引；公布后如何解读 | 必要时再看已计价程度、期权隐含波动；没有共识数据时寻找其他明确的比较基准。参考 R2 |
| 财报发布后改变了什么 | 实际相对事前预期的差异、持续经营与一次性因素 | 实际与预期的关键差异；业务或成本贡献；核心与报告口径；新旧经营判断及预测修订 | 不重写整份公司背景；用户问股价反应时再接入事件解释。参考 R3 |
| 为什么发生这次涨跌 | 信息到达、预期差、跨市场反应及竞争解释 | 信息和价格的时间顺序；最能解释变化的渠道；同期因素与替代解释；能够区分解释的后续事实 | 不从新闻和价格同时发生直接断言因果；央行、财报、政策事件替换各自字段。由 R3、R5 提炼 |
| 经济与政策路径会怎样变化 | 基准假设如何连接增长、通胀和政策反应 | 形势变化与基准假设；增长、通胀、政策路径；地区差异；相比上次预测的修订；相关冲击情景 | 只分析用户关心的经济体和期限；不固定三情景，不把宏观展望直接等同某资产涨跌。参考 R4 |
| 一个宏观主题怎样影响某类资产 | 冲击经由哪些渠道传递、时滞多久、谁受影响 | 核心变化；传导路径及受影响对象；相反力量与时间差；价格已反映的部分；下一项关键观察 | 例如降息、油价、AI 投资分别需要不同传导关系；不先写完整全球综述。参考 R5，结合 R4 |
| 两个资产或方案怎样选择 | 用户目标下的共同口径、差异与取舍 | 先确定选择目标；比较真正决定选择的差异；解释不同条件下的取舍 | 比较基金、公司和期权结构时使用不同指标；不默认生成综合评分。借用对应专业方法 |
| 我的组合主要承担什么风险 | 权重、共同暴露、风险贡献和压力损失的差别 | 实际持有的暴露；风险集中在哪里；相关冲击影响哪些持仓；能改变风险结构的调整方式 | 大权重不自动等于最大风险贡献；只计算与持仓有关的风险类型。参考 R9 |
| 这次组合亏损主要从哪里来 | 实际损益与持仓、市场、配置及交易变化的关系 | 损益来源；时间和资产贡献；适用时与基准比较；哪些变化值得处理 | 与前瞻风险诊断分开；不将风险敞口当作已实现亏损归因。Sesame 扩展，参考 R12 的绩效分解入口 |
| 怎样配置或再平衡 | 目标、约束、现有持仓与调整成本之间的关系 | 现状与目标偏差；候选配置的取舍；调整前后的暴露和成本；实施顺序与触发条件 | 根据问题选比较或优化，不强制运行优化器；研究结论不自动执行交易。由组合方法扩展 |
| 怎样选择期权结构 | 方向、期限、波动和资金约束如何改变条件损益 | 候选结构的合约组成与成本；盈亏平衡和条件损益；时间、波动变化的影响；相关的到期与行权影响 | 区分到期损益与持有期间估值；不拿单一希腊字母代替全部取舍。参考 R10 |
| 因子提供了什么信息 | 因子值与目标、期限及样本之间的关系 | 含义与计算口径；与目标的关系；分组或分状态表现；稳定性、冗余与互补；因子库记录 | 横截面与单品种时序采用适合的方法；策略选用与应用收益另行评价。参考 R11，保留既有因子体系边界 |
| 策略是否值得进一步研究 | 规则、样本划分、成本与收益风险的关系 | 真实规则和评价口径；样本内外表现及基准；主要回撤与收益来源；相关成本和稳健性结果 | 检验按待支持的结论选择，不把所有评估变成必做项。参考 R12；它的单资产示例不等同完整策略验证 |
| 策略最近为什么失效 | 原来与当前表现之间的变化及原因 | 变化从何时开始；哪些交易、市场状态或执行环节贡献了变化；竞争原因的检验；值得修改的部分 | 优先复用已有回测和交易记录；不直接把所有亏损归因于因子失效。由策略评价方法扩展 |
| 之前的预测为什么不准 | 当时可知的判断与实际结果、条件变化之间的关系 | 原始判断和期限；实际偏差；条件、数据或推断的偏差来源；对下一次判断的具体修正 | 只有当时真实给过概率且样本适合时才做概率校准；不事后补写原预测。参考 R8 的分组统计思想，并保留既有复盘原则 |
| 一个概念、机制或数字是什么意思 | 用户的理解缺口与具体市场例子 | 直接回答所问关系，给一个必要例子或计算；仅在有价值时解释相近概念的区别 | 可以只用一段回复；不为了使用预设启动完整研究。Sesame 的轻量问答分支 |

这些类型不是互斥标签，也不是能力上限。公司价值、宏观、组合、因子等方法提供不同分析起点；用户提出新品种或新问题时仍要继续寻找专业知识与数据能力。

## 3. 泛用性来自任务适配

方法选择先看用户想完成什么，再看对象、期限、问题处于事前还是事后、已有证据及是否存在既有判断。不能只因为提到了股票就选择公司研究，也不能因为提到了未来就统一生成交易计划。

一次任务可以采用零个、一个或多个专业方法。纯事实查询可以直接回答；复杂问题先确定一条主回答线，再借入其他方法需要的调查动作和证据。多个方法共享数据，不共享一套必须填完的正文。

例如“利润增长为什么股价跌了”以价格变化解释为主线：借用财报点评中的预期差和盈利质量，检查指引及同期市场因素；只有估值预期可能解释差异时才深入估值。最终内容围绕解释及证据组织，不拼接公司介绍、财报报告、估值报告三套正文。

“AI 投资能否带动电力公司长期价值”则以价值形成和估值为主线：从宏观主题方法借用需求传导，再调查资本开支、融资、监管回报和现金流。与前一个问题即使研究同一家公司，也应形成不同的内容。

未命中预设时：从问题需要的分析关系出发选择相近方法，补充本次独有的调查，再形成临时回答结构。必要时继续查找专业插件及外部一手报告；目录没有同名方法不是停止条件。获得新证据后可以修订结构，但不能悄悄丢掉用户明确提出的问题。

## 4. 如何检验有没有重新同质化

不靠要求每份报告标题不同来验收。比较它们实际调查了什么、用了哪些关键证据、解释了什么关系，以及是否回答用户的问题。

| 对照任务 | 应出现的实质差异 |
| --- | --- |
| 同一公司：财报前看什么／财报后哪里超预期／现在贵不贵 | 分别以待揭晓变量、实际预期差、价格隐含要求为重点 |
| 同一事件：发生了什么／为什么影响债券／我持仓受多大影响 | 分别交付事实、传导解释、结合实际持仓的影响 |
| 同一策略：整体评价／近期退化原因／仅修改报告视觉 | 分别评价结果、定位变化、复用成果并交 Reports |
| 同一标的：一句话概念问答／详细研究／明确只要事件日历 | 工作量和内容随需求变化，不出现同一套必填章节 |
| 没有预设的新问题／含多个研究方向的问题 | 有任务专属调查与主回答线，既不拒绝也不拼接所有模板 |
| 数据不足或证据推翻了最初猜想 | 调整取证与解释，交付已有证据能支持的内容，不为填栏目伪造结果 |

完成检查关注问题覆盖、关键依据、重要分歧、无关内容和重复取证；各项按实际任务适用。短答案不因章节少而不合格，长报告也不因栏目齐全而自动充分。
