# Agent 手工交易与研究插件

本次直接在插件仓库 dev 实现，复用 Sesame 0.2.2 的 Agent、已配置模型、工具组合、数据集和研究文件树接口，不改宿主工作区中的其他功能。

## 产品约定

- `manual-trading` 保留原有一次性交易工具，新增持久计划、周期/事件触发、单 Agent 与 team 两种运行方式。
- 计划指定默认供应商/模型，team 中每个角色可独立覆盖，保存配置摘要与实际运行模型；配置漂移报错，不静默换模型。
- TradingAgents 的分析报告共享、有限轮次多空辩论、风控和组合经理流程作为调度参考。只共享显式报告与证据，不提取模型私有推理。
- 最终决策是目标仓位；允许整体不变，未指定的品种保持不变，显式零仓位表示平仓。账户持仓不区分手工或量化来源。
- 不新增暂停权限开关。提示词要求继续运行会造成极大风险时停止该账户上的挂载策略；MT5 使用实际停止 EA 的能力，回执不声称保留可恢复的运行状态。停止 EA 不等于已平仓。
- 执行仍使用报价时效、账户版本、稳定操作 ID、原生最终核验和未知回执阻断；重启/取消不自动重放订单。
- 独立 `financial-research` 提供价格、财务、新闻、SEC 文件、分析师、内幕交易、宏观和情绪资料。Agent 与用户读取同一数据集，缺源明确返回不可用。
- 合入 judgment-evolution 的判断/证据/规则功能，并增加按账户和已知时间检索的交易案例与证据复盘；旧插件与数据不删除。
- 每次运行的日报写入研究树 `手工交易日报/<计划名称-ID>/`，文件名含时间与运行 ID。保留输入、团队报告、目标、暂停回执、交易回执、证据和复盘。决策不冒充成交，目标不冒充收益。

## 实现与验证

1. 独立实现研究插件、判断/记忆、后端窄控制工具；主线负责计划调度、目标执行、归档和整合。
2. 单账户运行串行，重复事件去重，运行期间的新事件合并；周期错过时只执行当前一轮。
3. 任务通过 `host.agents.current()` 与冻结计划/运行身份关联，后台执行工具不接受模型自报权限。
4. 用虚构模型/后端验证周期、事件、每角色模型、共享报告、持仓减仓/平仓、未知回执、取消、重启、研究证据、归档和原工具回归。
5. 运行源码锁、清单一致性与宿主 SDK 安装/调度检查；不接入实际券商发送测试订单。

参考：TradingAgents（MIT，1394a3f72aa4393e1a98f51b382434c4b4c2d972）、META（2609.28771）的案例记忆思路、Rallies 官方工具介绍。这里是适配 Sesame 的实现，不声称复刻未公开的 Rallies 内部系统。

- 可选插件全量套件在本机仍有其他插件的原生运行环境、平台路径及 MCP/Python 依赖失败；本次相关测试单独通过。未连接真实券商、未验证实盘收益或券商端原子性。调度要求应用持续运行，研究源需要实际可用的密钥/访问权限。
