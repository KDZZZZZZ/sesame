## 执行分工与顺序

1. 分类与脚手架：保持原 category，扩展 functionalCategory / implementationKinds；覆盖当前全部插件并修正生成；先失败回归，再实现。
2. 宿主配置：新增配置声明校验、脱敏目录、统一保存路由与能力级预检；保持旧 configuration.read/update 可用。
3. MT5：先定位当前订阅错误，再保护现有行为做入口整理及配置元数据接入。
4. 根 Agent：整合配置插件、金融信源配置、设置 UI、ICT 与 Investment Research 试点；最后统一生成锁与 inventory，集成回归。
5. 通过代表性试点后，推广九类标签/作者规范及适合已有结构的模板。剩余复杂包的物理重排按相同验收逐批进行，不为统一形式搬动已经清晰的模块。

## 新增配置契约

capabilities.json 增加可选 configuration.fields，每项含 id/title/schema/binding。密钥 schema.writeOnly 为 true。binding 明确指向环境变量或本包既有 read/update 能力及 JSON Pointer，不根据字段名猜存储去向。

能力增加可选 configurationRequirements，引用同包 field，可附输入 JSON Schema 条件 when。预检只检查本次能力实际所需字段；FMP 与 FRED 分别依赖各自来源密钥，公开来源继续可用。配置目录展示字段状态和关联能力，秘密只返回 configured 状态。

统一 host.configuration.catalog/check/apply 与 /api/v1/settings/integrations 使用相同服务。普通调用可只读检查；写入仅主会话。环境字段复用应用 secret 存储，插件字段转发原有领域入口，保留命令幂等、版本冲突和配置钩子。新的 values 载荷必须在会话、能力回执、审计和事件中脱敏。

## 已实现内容

- 当前 56 包全部进入九类主功能组，另以可复合的五种 implementationKinds 描述实现；旧 category 与平铺发行路径保留。inventory 从当前声明生成，修复 Investment Research 问答能力和版本漂移。
- 复用现有生成器支持 native／skill／knowledge／function／adapter／workflow／service 七个模板；没有第二套生成器或新依赖。
- ICT 保持知识、脚本和样例字节及路径；Investment Research 六个私有模块移入 src，入口与公开契约保持；MT5 入口仅注册，生命周期与分派移入 backend/plugin-runtime.js。
- 新增“用户设置 → 配置与密钥”，插件页也可进入，且能转到原模型设置。密钥不回显，支持最小修改、明确清除、放弃编辑、原始版本冲突检测。
- 配置目录、检查与保存共用 host.configuration.catalog/check/apply。声明字段引用环境存储或本包原有配置能力；新加四个配置助手包装，保留旧入口。
- MT5 的 17 个字段复用原有版本化设置；新增 host-only configuration.read 提供只读投影，原 mt5_settings／更新能力仍需主会话。金融研究五个来源字段沿用自定义环境变量映射，按 provider、kind 和 as_of 选择真正需要的凭据；历史快照与 CFTC 不受无关密钥阻塞。
- 新配置写入不能进入持久化 Run；显式 graph 在创建父 Run 前扫描全部已安装声明，包括禁用／失败插件。缺配置的普通工作流保留原中断／恢复路径。
- 发布校验复用可信分类规则；GitHub／R2 生成器只读取固定 sourceCommit 中的可选分类字段，缺少新字段的历史发布保持原字节，不执行候选分类代码。
- 网站预览支持中英文九类筛选、复合实现标签与搜索，兼容旧目录。同步只消费已验证的公开 catalog；当前公开预览仍为 54 包，没有用本地 56 包清单替换。

## 当前 MT5 图表

运行中图表的原始回执为 stale／error、0 bars，错误被包装为 INTERNAL。同一品种只读行情可用；旧插件将临时原生读取错误直接送出，宿主无法识别为可重试来源错误。新增边界归类把已知暂时失败保留为 SOURCE_UNAVAILABLE／TIMEOUT，认证失败单独保留 AUTH_REQUIRED；最初触发断连的底层原因已被旧代码丢失，不作推断。

通过当前应用的 canvas API 在 CAS 保护下重建同一绑定，图表 version 13 → 15，回执恢复 rendered／live／346 bars；品种、周期、其它图表字段和布局逐项保持。没有重新安装、重启或修改账户／交易配置。

## 发布与推广边界

本轮是未发布源码改动。统一分类与作者规范覆盖全部 56 包，物理重构限三个代表性试点；其他复杂包后续按同一基线、契约、回归门槛逐批整理。配置与自动重连的新代码尚未替换当前安装版。正式发布时须为变化的插件／宿主递增版本、核对新的宿主兼容门槛，再生成新的发布计划与固定摘要；不得覆盖历史发布字节或用本地描述清单冒充已发布安装目录。
