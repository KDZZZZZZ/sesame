# 初稿后的图文编辑

## 目标与边界

用户要求将视觉设计与文字润色合为初稿之后的一个步骤。当前图覆盖度已基本满足需要，本次重点是内容组织、自然叙述及图的意义设计。沿用 visual-compose 和现有组件协议，不增加工作流、宿主接口、研究模板、图数指标或排版规则。

## 对照依据

- 分享对话后半在检查 PDF 后撤回了字号、留白、双栏和整体结构方面的批评。保留的表达问题是关键判断没有充分落图、研究过程语言进入正文、反复防御性说明，以及标题强度超出证据时点。
- 当前视觉设计测试已将原稿多组数值转成图形，仍有精确抓取时间、冻结记录和方法缩写等过程语言；价格图未标全正文讨论的关口。不能再把主要目标设成增加图数。
- Claude Scientific Writer 可借鉴主题句—证据—衔接、按发现组织、图文分工和正反例。其官方 122 页市场报告也存在列表过多等不足；不照搬固定图数、学术章节、LaTeX 或强制披露。

## 实现与验证

Reports 的 prompt 只保留职责和入口，visual-compose 执行统一图文编辑，text/composing 提供叙述、构图与少量改写示例。Research 负责事实、解释、预测和时点的判断校准，交付初稿时不把内部记录或原措辞锁成读者必须阅读的内容。

图文编辑先确定整篇主回答与推进顺序，再共同重写段落、重设计图中的参照和重点；首屏概括完成后的正文。保留实质判断、反例、数字和必要条件，不将重复免责声明与内部过程一并搬到成品。复核读者是否能理解结论及其依据，不以图数或禁词数量验收。

验证使用现有目录、组件与研究资源测试及包锁/inventory 检查；不增加镜像提示词句子的测试，不操作 GUI。真实模型的表达效果需与规则测试区分记录，PDF 清晰度和附件跳转问题不在本次表达修改中宣称已修复。
