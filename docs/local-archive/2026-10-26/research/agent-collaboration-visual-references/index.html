优先参考 · 官方功能演示 / 2026.07

Langfuse · 概览与实际执行路径

聚合视图压缩重复调用；展开视图展示每一次实际发生的调用。

值得借鉴

概览里重复步骤合并并显示次数；展开后循环成为逐次调用构成的路径，能解释一次运行究竟如何推进。

用于 SESAME

「协作概览」看角色关系，「本轮过程」看真实交接。研究 → 实现 → 评审 → 修改可以逐轮展开，保留失败分支。

04
近期更新 · 官方功能演示 / 2026.08.28

Langfuse · 可缩放并行时间线

先把整轮执行压进视野，再放大某一段，观察并发、等待与长任务。

值得借鉴

时间与行一起缩放；缩小时保留结构，放大后显示名称和耗时。可快速定位长耗时调用。

用于 SESAME

作为「执行效率」的可折叠视图，查看哪些研究方向并行、哪一步等待最长。正文继续按研究逻辑纵向阅读。

05
设计概念 · 非已发布组件证明

AgentPrism · 执行树回放

用路径高亮、节点淡化与播放控制，表达研究如何走到当前结果。

值得借鉴

将注意力集中在当前路径，其他分支弱化。图中是自上而下的执行树 / DAG，官方将它标为概念稿。

用于 SESAME

回放因子提出、否决与修改过程；点选某个版本，显示它继承自哪个候选、依据什么证据改变。

06
团队配置参考 · 官方文档截图

AutoGen Studio · 角色、模型与工具

把团队成员及其模型、工具展示在同一张关系图里。

值得借鉴

角色、使用的模型、可调用的工具有清楚的归属关系，便于理解团队由谁组成。

用于 SESAME

页面上方做简洁的团队名册：研究总管、研究员、实现者、评审者与复盘者，各自显示模型。主报告另按执行过程展开。

PROPOSED DIRECTION / SESAME 的组合建议

纵向叙事，按需深入。

  1. 团队与本轮目标谁负责什么、各自使用哪个模型、这一轮准备验证什么。
  2. 阶段执行树以 AgentPrism 的树结构为主，按研究轮次展开；同轮的并行任务放在一起。
  3. 可展开的证据借鉴 Sim：点击步骤，在下方查看输入、工具结果、公式、指标与评审依据。
  4. 迭代与回放借鉴 Langfuse 的聚合 / 展开切换；显示真实发生的交接、修改与失败分支。

视觉上保留 Sesame 的纸色背景、深色文字与少量橙色强调；用细连接线、缩进和排版表达结构。上方参考图保留原产品配色。
