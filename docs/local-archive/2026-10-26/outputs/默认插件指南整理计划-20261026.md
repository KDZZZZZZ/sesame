# 默认插件指南整理计划

范围：`sesame/orchestration`、`sesame/plugin-manager`、`sesame/data-access`；按用户后续要求补充 `sesame/reports` 的统一视觉验收及说明精简。整理提示词、技能和接口参考；核对中发现的接口声明和错误提示按实际实现修正，不更改宿主执行逻辑、不操作用户当前任务、不安装或重启运行中的应用。

1. 核对已声明能力、宿主实现与现有指南，列出真实差异。
2. 保持分工：`prompt.md` 写职责、原则和选择依据；`SKILL.md` 写适用场景与执行步骤；参考文件写完整参数、限制和示例。保留授权、证据、报告交付、失败恢复等已有原则。
3. 先运行相关接口/行为测试。对新增的可调用示例，用真实 schema 和计划解析器验证；不凭文案另造接口。
4. 编排补充工具用法、自定义触发条件和三类业务工作流的定制边界；插件管理核对发现、读取、创建、安装、更新、启用和配置；数据访问按来源发现、读取固定输入、行情与计算证据组织。
5. 更新版本、资源声明、锁文件、库存和逐文件摘要；检查路径、声明与引用完整性。
6. 运行最小相关测试及库存检查，独立复核原则保留情况，按职责提交本地 commit。

验收：描述与当前代码一致；示例通过实际接口校验；prompt 与 skill 不重复堆砌；没有删除有效原则或引入运行时行为变化。
