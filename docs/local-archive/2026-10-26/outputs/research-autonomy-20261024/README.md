# 研究自主推进与插件组合修正

本次针对主 Agent 把单个评估器限制扩大为工作流限制、未带知识包、过早要求用户提供数据或选择下一步的问题。只修改产品提示、插件说明及对应测试，没有代写研究、获取行情或执行交易。

## 已确认的原因

- 原提示的安装、配置与恢复要求主要由“用户要求配置”触发，未明确覆盖普通研究任务的前置准备。
- 主 Agent 的两次研究子任务未传知识 plugins；auto_factor_start 未传 config.research，导致知识与研究工具集合为空。现有组合链路实际支持知识包。
- 工作流不限制品种数量；当前内置 factor-evaluator 的指标是多品种横截面 Rank IC，其每时点至少四品种要求属于计算实现。
- 既有工作区有 XAUUSD M15 数据；主 Agent 没有实际尝试 XAUUSD M1/M5 获取。已有原生数据快照、工作区转换、research_register 路线，不能把该路线误报为产品没有数据入口。
- 插件发现按简介等元数据作关键词匹配，一次无匹配不证明没有方法。应换相关概念或浏览可发现目录。

## 修改

- 宿主总提示：普通数据获取、相关插件准备和可逆本地处理属于完成任务的责任；先尝试适合的路径，再针对真实缺项询问。
- 明确自身知识不足、工具失败不是否定用户想法的依据，应查知识、找证据、组合能力并继续验证。
- 主动组合工作流、技术知识、数据来源、计算/回测和报告；知识必须实际阅读并传入执行成员。
- 区分数据、方法与评估实现缺口；某个阶段不具备实现时继续可独立执行的阶段，不冒称数值试验已完成。
- orchestration 3.1.6、auto-factor-mining 1.1.6 同步提示和发现说明；公开接口与数值评估算法未改。

- 插件知识组合、分类与独立包边界检查：21/21 通过（plugin-green.log）。
- 语法、定向 lint、diff 空白检查通过；锁文件和 inventory 已重新生成。
