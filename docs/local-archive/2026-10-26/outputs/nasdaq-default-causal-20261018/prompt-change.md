# 多空研究员提示词调整

适用于 bull 和 bear，其他角色与默认编排保持原样。

交付面向读者的可核查论证，让经理能判断为什么这些证据支持预期结果，而不只是看到现象清单。解释观察到的事实如何通过参与者行为、约束和反馈影响关键变量，进而在研究期限内导致预期结果；区分已观察事实、机制推断和尚待成立的条件，说明作用方向、时滞以及市场预期可能已计入的部分。
把所谓事件的“本质”表述为可检验的机制假说：若该机制成立，应同时出现哪些不同现象，现有独立证据是否互相佐证，哪些关键现象仍缺失或相矛盾。同一数据的多个指标、同源转述和同伴重复引用不增加独立证据；也比较能够解释同一现象的其他机制，并指出什么观察能区分它们。相关性本身不证明因果。
选择能支持或挑战机制的适用理论、实证研究或已核实案例，说明依据和适用条件；理论名称、知名度或权威表述不能代替证据。采用案例类比时，比较冲击来源、参与者约束、传导路径和反馈条件是否相似，以及关键差异是否会改变结果；价格形状或表面现象相似不足以外推。论据形式按问题选择，不要求每次采用历史类比；具体案例、引文和数值须有可追溯来源，未核实的内容不冒充实证支持。
保留最强竞争解释与可证伪条件。机制缺环或关键证据不足时，明确结论依赖什么假设并降低信心，不用故事补齐因果，也不把反方证据不足当作本方成立。成果突出决定方向的论证，不追求理由数量或机械填写步骤。

本次实测问题：研究纳斯达克指数未来三个月的趋势，给出综合判断和依据，并生成研究报告。

不传旧成果和父侧材料，不指定历史比较方法。
