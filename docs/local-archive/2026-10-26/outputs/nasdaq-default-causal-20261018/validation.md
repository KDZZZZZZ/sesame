# 多空因果论证提示词与默认研究实测

## 本次修改

只修改投资研究工作流的多头、空头职责和两者共享的论证要求，并同步 README 与包校验锁。其他角色、协作顺序和报告生成逻辑未改动。

- 说明观察事实如何通过参与者行为、约束、传导和反馈，在研究期限内影响预期结果。
- 区分事实、机制推断、成立条件与已被市场预期计入的部分。
- 将事件的“本质”写成可检验的机制假说，用不同来源、不同现象交叉检验；同一数据的多个指标不算独立佐证。
- 理论须解释适用条件，案例须核实底层机制与关键差异；不强制历史类比。
- 保留竞争解释、最强反证和可证伪条件。证据不足时降低信心，不为多空角色强行站队。

## 实测输入与人工介入边界

问题只有：“研究纳斯达克指数未来三个月的趋势，给出综合判断和依据，并生成研究报告。”

研究对象为 NASDAQ100、NASDAQCOM，期限为 2026-10-18 至 2027-01-18。使用默认研究能力；父侧没有提供旧报告、行情、来源网址、历史样本、计算结果或方向结论，没有代成员检索。

本次不能记为完全无人干预的默认成功运行。原工作流发生两次运行介入：

1. 成员将 Reddit 当成必需来源，并把启动时间理解为历史回测的采集截止点。澄清这是当前研究、原问题没有指定 Reddit，继续由成员自行选取已授予能力。
2. 单个网页 HTTP 403 引发整队暂停。恢复原成员，失败请求保留为访问限制；没有提供替代网址或研究材料。

两次干预均记录于 `run-1/controls.json`。测试驱动首次恢复因缺少 interruptIds 出错，补齐运行控制参数后继续同一工作流；没有重复新建研究任务。主 Agent 未能自行解决这些暂停，默认恢复能力仍有缺口。

## 多空论证的实际变化

多头给出“需求与收入兑现 → 利润、经营现金流保持 → 盈利预期维持或上修 → 折现率和风险溢价不过度上升时支持价格修复”的链条。它区分了已经观察到的财务表现与尚未测量的预期变化，并解释三个月内起作用的是新信息对长期现金流预期的更新，而非资本开支在三个月内全部收回。

空头解释了“历史盈利增长”与“股价下跌”可以并存：增长可能不足以超过市场原有要求，或不足以抵消估值与折现压力。同时承认现金流改善、实际利率下降是重要反证，不能声称现金流危机已经发生，也不能将下跌全部归因于利率上升。

两者均比较竞争机制和后续区分条件，没有强套历史案例，也没有为了角色身份给出确定的多空立场。多头将修复保留为待确认情景。

仍未达到的部分：多空都识别出指数估值、盈利预期与修订、资本开支购买方变现等关键缺口，但两者没有新增检索或计算调用；主要依赖上游完整成果进行条件推演。理论提供解释框架，本轮没有新增独立实证研究或历史案例来估计效应大小。论证结构改善，不等于机制已经被充分验证。

## 经理结论与产物

本轮经理将“震荡偏弱、反弹修复可能受阻”作为条件性基准，保留盈利和现金流支持修复的竞争情景，不将其升级为高置信度下跌预测或长期熊市判断。
