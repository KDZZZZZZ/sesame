# 基本面成员交接：纳斯达克未来三个月

## 角色问题与结论

**研究区间：2026-10-18 至 2027-01-18。**本角色检验企业盈利、现金流及利率是否支持纳斯达克上涨解释，不制定交易计划。

**局部判断：企业经营数据支持“大型科技盈利仍在扩张”，但不支持直接推导“指数未来三个月必然上涨”。基本面呈现盈利支持与利率约束并存，偏积极判断必须附加现金流延续、盈利预期不恶化及估值不过度扩张等条件。**

目前证据更适合解释大型科技与半导体经营状态，**不能代表 NASDAQ100 全体成分，更不能代表 NASDAQCOM 全市场盈利**。没有指数估值与一致预期证据，无法判断这些经营改善是否已经充分计价，也不提供指数目标点位或方向概率。

## 方法与时间口径

采用实际财务对照与折现率传导分析，分别检验：

1. 收入增长是否伴随营业利润增长；
2. 利润是否有经营现金流支持，资本支出是否挤压剩余现金；
3. 实际长端利率与短端资金价格是否支持估值扩张。

本次按主流程澄清作为**当前研究**处理。财务快照采集于 **2026-10-18 14:13:21—14:13:37 UTC**；财报期末、供应商 filingDate 和 acceptedDate 分别保留，不当作当前数据版本的首次可用时间。FMP 的 `available_at` 为未知，本次只能确认所列版本在采集时已取得；不是历史点时回测证据。

## 已取得的实际证据

### 1. 微软：收入、营业利润与现金流同步改善，但投资负担不轻

单位为**十亿美元，季度值，USD**，不是年化值或 TTM。

| 指标 | FY2026 Q3，2026-03-31 | FY2026 Q4，2026-06-30 |
|---|---:|---:|
| 收入 | 82.886 | 90.007 |
| 营业利润 | 38.398 | 40.603 |
| 净利润 | 31.778 | 35.766 |
| 经营现金流 | 46.679 | 55.441 |
| 资本支出现金流原值 | -30.876 | -35.802 |
| 自由现金流，供应商字段 | 15.803 | 19.639 |

**支持的解释：**收入增长并非只停留于账面净利润，营业利润、经营现金流和自由现金流均较前季上升，削弱“增长完全没有现金回收”的解释。

**约束与替代解释：**

- 资本开支的现金流出也在扩大；经营现金流强，不等于全部可以分配给股东。
- 季度对照可能受季节性和营运资金影响；本次未取得去年同期现金流，不能据此宣布可持续增速。
- 总表没有业务分部、项目投资回报或客户收入数据，不能把全部增长归因于 AI，也不能证明新增投资已经取得足够回报。

来源：  
[FMP 微软季度利润表](https://financialmodelingprep.com/stable/income-statement?symbol=MSFT&limit=4&period=quarter)  
[FMP 微软季度现金流量表](https://financialmodelingprep.com/stable/cash-flow-statement?symbol=MSFT&limit=2&period=quarter)

### 2. 英伟达：收入和营业利润连续扩大，但净利润不是纯主营业务代理

单位同为**十亿美元、季度值、USD**。

| 财季及期末 | 收入 | 营业利润 | 净利润 |
|---|---:|---:|---:|
| FY2026 Q3，2025-10-26 | 57.006 | 36.010 | 31.910 |
| FY2026 Q4，2026-01-25 | 68.127 | 44.299 | 42.960 |
| FY2027 Q1，2026-04-26 | 81.615 | 53.536 | 58.321 |
| FY2027 Q2，2026-07-26 | 96.221 | 63.734 | 59.688 |

**支持的解释：**样本内四季收入与营业利润连续上升，为半导体相关盈利扩张提供经营层证据。

**削弱简单外推之处：**最近两季净利润变化明显小于营业利润变化，且供应商列示的税前其他收支净额分别为 16.367 与 7.773 十亿美元。因此不应将净利润或 EPS 的全部变化解释为主营需求变化。缺少订单、库存、应收账款、客户集中度、出口约束和最新指引，无法确认未来三个月收入继续按既有速度扩张。

来源：[FMP 英伟达季度利润表](https://financialmodelingprep.com/stable/income-statement?symbol=NVDA&limit=4&period=quarter)

微软与英伟达虽是不同公司，但可能受共同投资周期影响，不能把两者当作完全独立的需求确认。

### 3. 利率：局部实际利率回落，但“持续宽松”尚无支持

- **FRED DFII10**：十年期通胀保值国债实际收益率，日频、百分比、非季调。2026-10-09 为 **2.91%**，10-13 为 **2.88%**，10-14 为 **2.84%**，10-15 为 **2.78%**。10-12 为来源缺值“.”，不是零。
- **FRED FEDFUNDS**：有效联邦基金利率，月频、百分比、非季调。2026 年 4 月 **3.64%**，5—8 月均 **3.63%**，9 月 **3.75%**。

**机制解释：**最近几个有效观察日实际长端利率回落，在其他条件相同下有利于远期现金流现值；但这个短窗口不足以宣布中期利率下行趋势。有效联邦基金利率月均值也没有呈现连续下降，因而不能用“持续降息已兑现”作为看多前提。

FEDFUNDS 是实际有效利率月均值，**不是政策目标区间、降息次数或未来利率定价**。

来源：[FRED DFII10](https://fred.stlouisfed.org/series/DFII10)、[FRED FEDFUNDS](https://fred.stlouisfed.org/series/FEDFUNDS)。

DFII10 复用已保存的 2026-10-17 vintage，采集于 2026-10-18 14:05:44 UTC；FEDFUNDS 为 14:13:37 UTC 取得的当前版本。元数据更新时间不等于逐条观测发布时间。

这些是研究更新条件，不是已部署的保护措施。

## 对综合工作流的影响与剩余缺口

经理可将本结果表述为：**盈利端有实际支撑，货币与估值端不足以支持无条件乐观。**若价格或叙事成员偏多，本结果提供的是有限经营支持，而不是第二份价格确认；若其他成员偏空，经营增长也不排除估值压缩导致的下跌。

仍影响结论的缺口：

- 指数成分及当前权重、加权盈利和当前估值；
- 一致预期、盈利预测修订与业绩相对预期的差异；
- 更广泛成分公司覆盖，尤其 NASDAQCOM 的非大型科技企业；
- 最新业务指引、分部收入、投资回报及订单质量。

这些缺口限制的是**指数方向及计价程度判断**，不否定上述已取得的局部财务观察。本成员完成局部交接，不声称已完成全指数基本面定价。
