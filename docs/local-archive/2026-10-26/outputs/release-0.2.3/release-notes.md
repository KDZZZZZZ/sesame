Sesame 0.2.3 统一了 Agent 与工作流的运行控制，并发布 Plugin API 2。插件显式声明能力、输入输出、依赖和调用方式；缺少依赖时暂停任务并说明需要补充的条件。

- Agent 与多智能体工作流共用运行状态、过程展示与 Markdown 成果；报告按主标题展示。
- 账户页接入后端声明的手动平仓能力，并改进平仓操作界面；修复直接启动应用时的配置绑定错误。
- 长期记忆区分交易风格、个人风险规则和策略知识。正式风险规则需用户明确确认；工作流在判断前读取共同记忆。
- 清理重复的编排入口和手动交易判断实现，修复相同操作 ID 并发调用可能重复执行的问题。
- 同步发布 54 个 API 2 插件（9 个基础插件、45 个可选插件）；本次不发布 Kurumi。

下载与升级请阅读 INSTALL.md，并使用 SHA256SUMS.txt 校验文件。新版插件要求 Sesame >=0.2.3；旧版 API 1 插件需要更新到配套版本。

提供 Windows x64 安装器、Linux x64 DEB / AppImage、macOS Apple Silicon DMG。macOS 包使用临时签名，尚未公证；Windows 包未签名。本次验证覆盖源码回归、三平台构建、安装包提取和打包后服务导入，未覆盖真实券商交易与所有可选插件的外部环境。
