2026-10-24。源码已完成、验证并构建；新版已用原有本地数据打开。

## 界面与使用方式

- 标签栏取消底部彩色线，选中态改为金属灰。参考 [Oops 碎念卡片](https://me.oopsbox.cn/essays/) 的鼠标跟随高光，浅色主题使用蓝光，深色使用蓝紫光，移开后淡出。键盘聚焦时高光居中，触屏与减少动态效果的设置分别处理。
- 输入框参考 Beautiful UI 的官方 Prompt Bar 源码，沿用 Sesame 字体和主题。输入 `/` 显示命令菜单，支持搜索、方向键、Enter、Tab、Escape 和中文输入法；原有 `@` 报告引用、草稿保留和消息队列继续有效。
- `/clear` 清理当前可见对话，保留历史与模型上下文；`/plugin publisher/name` 指定插件；`/ultra 目标` 启动持续推进；`/ultra status` 查看状态；`/ultra stop` 停止；`/ultra resume` 继续。
- 模型选择只展示已有认证配置的提供商项；回复增加复制按钮和短暂成功反馈；工具、公开思考过程、流式文字按真实状态展示。
- 无新增依赖。Beautiful UI 的 MIT 许可已随前端打包。

## Ultra 官方插件

新增 `sesame/ultra` 1.0.0，按既有插件架构承担任务组织和持续推进。主 Agent 根据目标缺口、已有结果和失败原因寻找新的方法、数据与验证路径，安排工作流或子 Agent，并在独立任务可并行时补充空闲位置。研究阶段要求产出报告，子任务结束后自动通知主 Agent，继续汇总和安排后续工作。

目标、分支与运行状态持久保存。完成目标或用户停止后结束；完全相同、没有新依据的停滞计划会被识别，避免重复消耗。涉及交易副作用的任务按执行边界处理，不把研究并行机制用于重复执行同一交易。

本轮同时修复了三类实际问题：

1. 插入消息指定新插件后，SDK 仍持有旧工具快照：现在知识、工具与当前轮提示词同步生效。
2. Ultra 停止和启动交错时，旧启动可能复活或旧停止误停新目标：现在按用户命令顺序处理，并补充真实宿主与插件的并发回归。
3. 生命周期回调正常结束时误取消已接受的持久 Run，造成自动续办中断：正常返回不再取消 Run；主 Agent 已有完成通知待处理时，也不会重复启动规划。
