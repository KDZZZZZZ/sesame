## 显示行为

| 情况 | 当前规则 |
| --- | --- |
| 普通（默认） | 隐藏思考后再分组，隐藏思考不会拆开连续工具；单工具直接是一行，多工具合并成折叠组。 |
| 思考 | 仅显示真实摘要，默认展开，记住用户手动收起/打开的选择。结束后不再强行改写该选择。 |
| 详细 | 展开思考、工具组和各工具；切回其它模式不会污染之前的手动选择。 |
| 视图入口 | 输入框加号 → 对话显示；支持本会话选择、设为默认及 Ctrl+O 按可用模式循环。 |
| 分组边界 | 保留正文、插入的用户消息、真实压缩记录和原回复的执行边界。显式重试仍是独立回复。 |
| 当前状态 | 仅一处显示当前工作状态；正在执行的工具或真实内容已经显示该状态时，不重复增加底部状态。 |
| 压缩与中断 | 一次压缩只留一个对应记录；已结束的回复不残留“正在压缩”；暂停/停止/错误原因只显示一次。 |
| 文件与图片 | 加号菜单的“添加图片和文件”；原有粘贴、拖放、上传、草稿、重试与下载保留。 |

Thinking 默认展开、手动打开的工具组完成后保留选择，是本次采用上游完整规则后对旧自动收起行为的明确替换。普通视图仍默认安静收起。工具错误保持中性显示。
