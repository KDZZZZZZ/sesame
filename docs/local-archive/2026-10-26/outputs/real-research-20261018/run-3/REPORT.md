**未通过项一：日期型真实行情无法直接组合数值插件**

本次 FMP 日线提供 `date`，历史 `available_at` 为 null。五个已授权的 ABU 能力要求 `time` 和 `available_at` 都是精确 UTC 瞬时，且满足时序关系。独立审阅直接调用纯分析函数，五个入口均拒绝诚实的日期型映射；不是工具没注册，也不只是提示词漏写。

市场成员正确地没有伪造收盘时刻，但因此绕过了数值方法。**不能用“手算也做了分析”将这一项判为通过。** 最小修复方向是支持显式的日级时间精度，区分本次取得时点与未知的历史可用时点：允许当前快照的描述统计，输出历史可用性未知；回测和历史时点可见性继续要求真实证据。

**未通过项二：关键派生量没有得到复核，错误沿协作链传播**

10 月 14 日的真实数据：高 347.09、低 341.72、前收 341.27。按照成员自己列出的公式：

```text
TR = max(高−低, |高−前收|, |低−前收|)
   = max(5.37, 5.82, 0.45)
   = 5.82

10月12—16日 TR = 5.99, 7.41, 5.82, 6.25, 7.36
五日简单均值 = 32.83 / 5 = 6.566 美元
占最新收盘比例 = 6.566 / 343.46 = 1.9117%
```

原稿误用当日高低差 5.37，得到 **6.476 / 1.89%**。错误经 **market → bull / bear → risk → manager** 传播，五名成员都未纠正。上沿距离 4.69 小于近期波幅这一判断仍成立，但算术准确性和复核已经失败。审阅器没有向运行中的成员提供答案，因此这保留了真实测试表现。

派生数值应附可复算的输入和计算回执；当它支撑重要判断、多人复用同一手算结果时，复核应回到原数据和确定性计算。增加更多角色或重复一遍结论，并不会自动提高准确性。
