## Fundamentals 交接：AAPL 经营改善有实证，但利润率与现金流增幅不能全部外推

**观察日：2026-10-18；角色范围：经营、现金创造及其反证。**  
已取得并读取 Apple 2026 财年第三季度官方新闻稿及 SEC 10-Q 的财务报表、经营讨论、流动性和主要风险章节，并用 FMP 季报核对。以下是基本面条件判断，不是交易目标或执行指令。

### 一、决定性结论

1. **“经营改善只是股价或 AI 宣传的映射”不符合已取得财务证据。** 收入、产品销售和经营现金流均有实际增长；iPhone、Mac、Services 同时贡献，但增长来源并不平均。
2. **“50.1%毛利率与29% EPS增长可以直接持续”也缺乏依据。** 官方明确披露关税退款贡献约2个百分点毛利率、0.11美元稀释EPS。剔除此项的简单近似仍显示改善，但幅度明显较小。
3. **现金创造强，但现金流增速高于利润增速的一部分来自税款及营运资本时点变化。** 不能把全部增量视为持续性经营效率提升。
4. **6–12个月的主要分歧不是有没有增长，而是高端产品组合、Services增长能否抵消存储/芯片/算力成本和AI研发投入。** 公司已明确警告供应约束与成本压力可能加剧。

### 二、实际观察与可复核计算

除EPS外，以下金额统一为**十亿美元（USD bn）**；季度指截至2026-06-27的FY2026 Q3，同比截至2025-06-28。

| 项目 | 本期 | 同比基期 | 解释 |
|---|---:|---:|---|
| 总收入 | 109.417 | 94.036 | `109.417/94.036−1` ≈ **16.4%** |
| iPhone收入 | 54.252 | 44.582 | 官方取整同比 **22%**；公司归因于Pro机型 |
| Mac收入 | 10.352 | 8.046 | 官方同比 **29%**；主要来自笔记本 |
| Services收入 | 30.739 | 27.423 | 官方同比 **12%**；主要来自广告与云服务 |
| iPad收入 | 6.191 | 6.581 | 官方同比 **−6%**，构成“不全面繁荣”的反证 |
| 毛利率 | 50.1% | 46.5% | 本期含约2个百分点关税退款收益 |
| 稀释EPS，美元 | **2.02** | 1.57 | 官方值；约同比29% |
| R&D | 11.729 | 8.866 | 同比约32%，快于收入增速 |
| 净利润 | 29.789 | 23.434 | 同比约27.1% |

**增长集中度：**  
收入总增量为`109.417−94.036 = 15.381`；其中iPhone贡献`54.252−44.582 = 9.670`，约占增量 **62.9%**。因此，“多业务增长”成立，但不能据此说增长已摆脱iPhone依赖。

**利润质量调整：**

- 毛利率简单剔除退款近似：`50.1%−约2个百分点 ≈ 48.1%`，仍比上年46.5%高约1.6个百分点。  
- EPS简单剔除退款近似：`2.02−0.11 = 1.91美元`；`1.91/1.57−1 ≈ 21.7%`。

这只是基于公司披露的**单项调整近似**，不是完整经常性盈利重述，更不是未来预测。它支持“改善不全是退款”，同时否定把全部表观增幅视为可持续。

### 三、现金创造：强度与可持续性必须分开

以SEC 10-Q的**前九个月累计**作主要依据，避免混淆单季与累计口径：

| 前九个月项目 | FY2026 | FY2025 |
|---|---:|---:|
| 经营现金流 | 116.996 | 81.754 |
| 购建物业、厂房及设备现金支出 | 6.799 | 9.473 |
| 自定义FCF＝经营现金流−上述资本支出 | **110.197** | **72.281** |
| 净利润 | 101.464 | 84.544 |
| 实付所得税净额 | 26.555 | 37.332 |
| 回购普通股现金支出 | 62.094 | 70.579 |
| 股息及股息等价物现金支出 | 11.778 | 11.559 |

可复核推导：

- 经营现金流增长：`116.996/81.754−1 ≈ 43.1%`。
- 自定义FCF增长：`110.197/72.281−1 ≈ 52.5%`。
- 现金转化率：`116.996/101.464 ≈ 1.15倍`，上年约0.97倍。
- 回购加股息：`62.094+11.778 = 73.872`；低于上述FCF110.197，说明**本期现金创造能够覆盖这两项现金股东回报**，但不能保证未来回购规模或股价底部。

**为什么不把43.1%的经营现金流增长全部外推：**

- 实付所得税同比少`37.332−26.555 = 10.777`，数值约为经营现金流增量35.242的30.6%；这是贡献尺度比较，不是完整因果归因。
- “其他流动及非流动负债”现金流调整由上年−15.161变为+10.016，相差25.177，显示营运资本时点对增长很重要；各调整项目互相抵消，不能简单相加后认定可重复。
- 库存从2025-09-27的5.718升至2026-06-27的11.092，约增94%。这既可能反映备货，也可能增加需求或产品组合判断错误时的风险；仅凭库存增加不能判定滞销。
- 自定义FCF未扣除全部投资活动、并购或经济意义上的所有AI投入，也未把股票薪酬视为现金支出，不能直接等同于股东可无条件分配现金。

### 四、机制解释与反证

#### 支持经营改善的机制

- **高端组合改善：** SEC将iPhone增长主要归因于Pro机型，产品毛利率从34.5%升至40.1%；即使考虑关税退款，组合改善仍是合理解释之一。
- **Services的盈利贡献：** Services季度毛利率75.6%，与上年持平；收入增长带来毛利增加。它是利润缓冲，但“服务利润率持续扩大”并非本季度事实。
- **地域广度：** 各地域收入增长；大中华区季度收入18.816，同比约22%。不过公司明确表示人民币走强带来有利汇率影响，不能把美元收入增速全部当作销量或份额增长。
- **流动性并不支持迫切融资危机解释：** 6月末现金及流动/非流动可交易证券合计`39.544+22.855+84.118 = 146.517`。这些资产不等于无风险、完全可自由使用的现金，但提供了明显财务缓冲。

#### 削弱过度乐观解释的证据

- **退款不可机械年化。** 它来自特定关税退款，SEC说明收到的退款计为产品销售成本减少；并不意味着此后每季重复。
- **成本压力不是泛泛推测。** SEC经营讨论明确列出先进半导体、NAND、DRAM供应约束和成本上升，并称预计趋势加剧；提价可能无法完全抵消，并可能压低需求。
- **AI首先也是成本。** R&D同比约32%，公司将增加主要归因于基础设施相关成本，包括AI投资，以及人员费用。现有材料没有单列Siri AI收入、用户付费转化或投资回报。
- **Services并非无监管风险。** 10-Q列有DMA、DOJ和Epic相关事项。它们提供收费机制可能受约束的风险路径，但不能据此估计罚款、佣金损失或股价影响；7月文件也不能证明这些案件截至10月18日没有后续变化。
- **行业中性归因仍未解决。** 按主Agent恢复说明，XLK/QQQ权限限制未修复且不重试。本角色不把公司经营改善等同于已证明的行业超额增长，也不把单一公司当作行业篮子。

### 五、两个期限的条件判断

**未来4–8周：经营基本面提供支撑，但本角色证据不足以确定股价方向。**

较有解释力的检验是下一轮公司披露中：

- 剔除退款后毛利率是否维持改善；
- iPhone高端组合与Services收入是否延续；
- 存储、芯片、算力成本及R&D是否侵蚀利润；
- 库存增长是否获得销售与现金回收支持。

当前没有代表性一致预期样本，因此不能把财报增长自动称为“超预期”，也不能断言上述信息尚未计价。下一次财报具体日期应由事件角色的已核实官方资料确认，本角色不推定日期。

**未来6–12个月：经营性偏正面、估值回报未定。**

- **支持条件：** 收入增长不只依赖汇率；Services继续增长；退款消退后基础毛利率稳定；AI/研发投入产生可观察的留存、升级或现金回报。
- **削弱条件：** 高端组合转弱、存储和算力成本增速超过提价能力，或库存/现金转化恶化。
- **关键相反情景：** 营收仍增长，但退款消退与AI成本投入令盈利增速放缓；因此“销量/产品成功”与“股票回报良好”可能分离。需经理结合市场价格、宏观折现条件和其他角色证据判断，不能由基本面单独推出。

### 六、来源冲突与处理

**重要：不要直接沿用FMP的Q3 EPS 2.03美元。**

- FMP季度收入表返回稀释EPS **2.03**、季度稀释加权股数14.750302bn。
- Apple新闻稿与SEC 10-Q均为稀释EPS **2.02**；SEC季度稀释股数为14.714676bn，14.750302bn是**九个月**稀释股数。
- 因此本交接优先采用官方2.02美元及官方季度股数；FMP返回值保留为已观察的数据冲突，不静默修正原快照。

资产负债表也存在细项差异，例如FMP总债务84.307bn，而SEC表内商业票据及流动/非流动定期债务相加为84.344bn。本结论不依赖这项细小差异，不用FMP净债务字段替代官方口径。
