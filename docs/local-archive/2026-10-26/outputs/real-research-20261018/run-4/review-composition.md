## 暂停：真实 402 与过度阻断分开归因

真实失败是 FMP XLK/QQQ 在相同价格端点各返回一次 `SOURCE_HTTP_402`。market 没有循环重试，也没有伪造行业资料；这是正确边界。错误扩大在于把“尚不能排除行业共同因子”升级为整个 AAPL 多领域研究不得继续。

这一理解受到实际任务提示的直接影响：任务既要求“以合适的行业和大盘参照辨别公司特有变化”，又写“重要缺口影响研究结论时如实暂停并说明”。它没有区分：

1. 缺少输入会让当前承诺无法成立、必须先解决的核心阻塞。
2. 仅限制某一种强归因，但仍可交付更窄结论并继续其他独立问题的局部缺口。

因此将本次记为**任务/提示边界过严导致的过度阻断**，不简单归咎“Agent不听话”，也不将其误报为获取、解析或恢复接口坏了。市场研究员没有完成行业中性 alpha 的证明，可以如实保留未决；不必因此撤销经营、事件、观点的可独立成果。

暂停记录只有一个根因：`interrupt_92595043-def7-4f45-9adb-85eed679466d`，源自 market，10:45:47.693 UTC 建立，传播到四成员。不是四个独立依赖缺失。

真实 Runtime 的主 Agent 收到暂停通知后自行运行过。公开会话记录显示：10:46:00 调用 `host_runs_read` 检查原工作流；10:46:12 调用 `financial_research_status` 检查配置及已有快照；10:46:26 调用 `host_runs_message` 把检查结果发回同 Run。10:46:43 的最终回复要求用户授权其他行情来源，或者解决 FMP 套餐/提供匹配行业数据。它没有调用恢复，也没有在现有证据范围内自主收窄目标。这说明暂停通知和自动检查/上报链有效，但目标边界过严延续到了主 Agent，不能写成“主 Agent 没响应”。

随后测试操作者通过 `controls.json` 发出一次 resume，10:46:58.521 UTC 有回执。它澄清“可得证据的条件判断不要求证明行业中性 alpha”，没有修复 402、没有新来源授权、没有提供数值或多空答案。**准确记录为：主 Agent 自动检查并上报一次 + 测试操作者澄清范围并恢复一次；不能称主 Agent 自主恢复或无干预一次跑通。** market 恢复后没有新增工具调用，直接保留证据、收窄结论；fundamentals/news 也保留这一未决边界。
