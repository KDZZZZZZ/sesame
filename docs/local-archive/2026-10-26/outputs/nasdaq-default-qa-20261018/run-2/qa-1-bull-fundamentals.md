# bull → fundamentals

多头因果链的关键缺环是“已实现同比增长→未来三个月预期现金流上修”，但现有成绩可能早已计价。请在授权来源内定向核查MSFT/NVDA/AAPL最近已公开的公司指引或可比未来盈利预期修订（如可取得的官方业绩发布稿/指引）；优先一至两家，不重复抓取已有三表。能否证明未来经营而非历史EPS仍改善，特别是MSFT资本开支与现金回报如何影响该结论？区分公司自身指引、市场一致预期与实际修订；不能取得则明确覆盖/访问限制，不以维持买入评级代替。该答案将决定是否可把条件性盈利支撑升级为有催化的三个月看多。

# 定向核查答复：前瞻经营改善是否足以升级三个月看多判断？

## 结论：补上部分经营前瞻证据，但仍不能升级为“有新增催化的三个月看多”

本轮优先核查 **MSFT、NVDA**，没有重复请求已有三表。

**新增事实是：NVDA 的公司指引确实预期下一季度收入继续扩大，但毛利率下降、费用上升；MSFT 的官方披露补充了未来履约义务和业务变现规模，却未取得其量化前瞻指引。两者均不足以证明截至10月18日市场正在上调未来现金流预期。**

因此，原结论应保留为：

> 龙头经营仍提供条件性支撑，NVDA 的前瞻收入指引增强了经营延续性的解释；但“增长已被计价”的问题没有解决，MSFT 的资本开支—自由现金流约束仍然存在。暂不将其升级为具有已验证新增催化的三个月看多。

这不是证明市场预期没有上修，而是**尚未建立实际修订的证据链**。

## 一、新查得的事实：NVDA有前瞻增长，但不是全面改善

来源：[NVIDIA FY2027 Q2官方业绩发布稿](https://nvidianews.nvidia.com/news/nvidia-announces-financial-results-for-second-quarter-fiscal-2027)。

- **原稿发布日期：2026-08-26**
- 已实现季度截至2026-07-26；指引针对 **FY2027 Q3**
- **真实获取时间：2026-10-18 15:23:50 UTC**
- NVIDIA官方财务报告页面将其列为最新报告，并链接至该原稿。这里核实的是当前网页版本，并未声称完成历史逐版本验证。

| 指标 | 已实现FY2027 Q2 | 公司FY2027 Q3指引 |
|---|---:|---:|
| 收入 | 96.221十亿美元 | **108.0十亿美元，±2%** |
| GAAP毛利率 | 75.0% | **74.0%，±50基点** |
| 非GAAP毛利率 | 75.0% | **74.0%，±50基点** |
| GAAP经营费用 | 8.408十亿美元 | **约9.2十亿美元** |
| 非GAAP经营费用 | 8.232十亿美元 | **约9.0十亿美元** |

公司同时明确：**收入指引未假设来自中国的数据中心计算收入**。

### 它改变了什么？

**支持面：**下一季度收入指引高于已实现季度，说明正面经营解释不再只有历史同比增长。它支持管理层预计近期业务规模继续扩大，而非立即收缩。

**制约面：**指引同时包含毛利率下降和费用增加，不能概括为“收入、盈利能力与现金转化全面改善”。该发布稿的指引也没有给出下一季度经营现金流或自由现金流预测。

中国收入假设限定了基准情景，**不能自动被解释为未来必有的额外收入**；获得销售、交付与合规证据之前，只能视作未包含在基准中的不确定项。

### 它没有证明什么？

- 108.0十亿美元是否高于发布前市场一致预期；
- 分析师在8月26日至10月18日是否继续上调同一预测季度的收入、EPS或现金流；
- 该指引是否已被当前价格消化；
- FY2027 Q3之后、覆盖至2027年1月的经营预期是否继续改善。

**已公开指引可作为未来兑现的参照，但其公布发生在本研究窗口之前，不应直接称为未来三个月尚未计价的新催化。**

## 二、MSFT：前瞻需求线索增强，现金回报约束没有解除

来源：[Microsoft FY2026 Q4官方业绩发布稿](https://www.microsoft.com/en-us/Investor/earnings/FY-2026-Q4/press-release-webcast)。

- **原稿发布日期：2026-07-29**
- 报告季度截至2026-06-30
- **真实获取时间：2026-10-18 15:14:15 UTC**

### 新增核实的事实

官方披露：

- 商业剩余履约义务（commercial RPO）为 **678十亿美元，同比增长84%**；
- Azure全年收入首次超过 **100十亿美元**；
- Microsoft 365 Copilot付费席位超过 **3,000万**；
- 当季通过股息及回购向股东返还 **10.2十亿美元**。

这些事实使原研究中“没有业务拆分、不能确认具体增长来源”的缺口有所缩小：至少官方资料确认了云业务及Copilot的商业化规模。

但必须区分：

- **Azure收入、付费席位是已实现规模指标，不是未来增长指引。**
- **RPO是尚未履行的合同义务指标，不等于未来三个月收入，更不是已经收取的自由现金流。**本轮没有取得其期限分布、客户集中度及利润率，不能把84%的增长直接映射为近期现金回报增长。

### MSFT量化指引的覆盖限制

业绩稿明确表示，前瞻指引将在电话会议及网络直播中提供，而稿件本身没有列出量化指引。

本轮尝试访问的 `earnings-call-transcript` 地址返回 **HTTP 404**；该失败观察已保留，恢复后没有重放请求。因此：

> 本轮没有取得可引用的MSFT下一季度收入、Azure增长、资本开支或自由现金流量化指引。404只说明该地址失败，不能推断公司没有指引，或整个微软投资者关系网站不可访问。

### 资本开支与现金回报如何影响判断？

复用原研究已有季度现金流证据，单位均为十亿美元：

| 指标 | FY2025 Q4 | FY2026 Q4 |
|---|---:|---:|
| 经营现金流 | 42.647 | 55.441 |
| 资本开支现金流出绝对额 | 17.079 | 35.802 |
| 自由现金流 | 25.568 | 19.639 |

**经营现金流增长是真的，但自由现金流下降也是真的。**新增RPO证据提高了未来需求可见性，却不能单独证明基础设施投资已经获得足够现金回报。

资本投入可能先扩大可售产能，再形成收入和现金流；也可能因利用率、定价、运行成本及后续折旧而压低回报。**支出先发生、回报可能滞后的时间差，尤其限制三个月尺度的看多解释。**

股息和回购体现已发生的资本分配，不是新增经营收益，也不能代替投资回报率证明。资本开支仍保留原来的现金流口径限定：未核实含融资租赁的总投入，不将全部支出命名为AI投资。

## 三、原结论的更正与三类证据的边界

### 更正与补充

1. **MSFT稀释EPS应以本次官方稿的4.81美元为准**，原FMP表为4.80美元；保留来源差异，不影响收入、经营利润及自由现金流的方向判断。
2. 官方说明，当季相对先前公司指引，有若干离散项目合计带来 **每股0.27美元收益**，包括Anthropic投资收益等。公司称剔除这些项目后仍超过其预期，但这属于**相对公司自身原指引**，不能写成超过市场一致预期。
3. NVDA下一季度收入扩张现在有公司指引支持；**未来自由现金流上修仍未证实**。

| 证据类别 | 本轮实际取得 | 可支持的判断 |
|---|---|---|
| 公司自身指引 | NVDA下一季度收入、毛利率及费用指引 | 管理层预计业务规模继续扩大，但盈利能力存在约束 |
| 市场一致预期 | 未取得同季度、同口径的可比预测集合 | 不能判断指引是否高于市场预期 |
| 实际预期修订 | 未取得前后两个时点的可比预测版本 | 不能证明截至10月18日预期仍在上修 |
| 卖方评级 | 复用已有维持评级样本 | 只说明评级立场延续，不替代盈利或现金流修订 |

本轮没有新增请求评级端点，也没有把未取得修订数据写成“修订为零”。

## 四、什么证据会允许升级或推翻判断？

**允许升级的证据：**

- 后续披露相对上述已公开指引出现经营改善，且公司提高同口径未来指引；
- 同一预测季度的市场收入、经营利润或现金流预测，在可比样本中确实上修；
- MSFT经营现金流逐渐覆盖新增资本投入，自由现金流改善，并有近期收入确认或产能变现证据。

**削弱或推翻的证据：**

- NVDA收入低于指引区间、毛利率弱于指引，或费用压力超过收入增长带来的收益；
- MSFT合同义务增长未能转为近期收入和现金流，资本投入继续扩大而自由现金流进一步受压；
- 市场盈利预测下修，即便评级仍维持买入。

**交给多头及经理的最终判断：**本轮补上了“未来经营规模仍有增长预期”的一部分，但没有补上“市场预期正在新增上修、且尚未计价”。因此，增强的是**经营延续性的依据**，不是已验证的三个月上涨催化。
