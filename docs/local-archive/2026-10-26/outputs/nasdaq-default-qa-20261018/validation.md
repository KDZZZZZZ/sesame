# 投资研究按需 QA：实现与同题实测

2026-10-18。实现与实测已完成；本次未发布插件或替换日常使用的 Sesame 安装。

## 实现

- 投资研究插件新增团队内能力 `investment_research_ask({analyst, question})`，供多头、空头向 market、fundamentals、news、sentiment 原研究员提问。
- 沿用原研究选择、模型、能力范围和完整成果。回答记录在同一成员身份下的新 Agent Run 中，不新建团队或增加协作图成员。
- 可以连续追问；仅在问题影响判断且有进一步核查价值时继续，没有固定轮数，也不以达成共识为结束条件。
- 问题、完整 Markdown 回答、来源与 Run 引用进入固定 `qa` 成果，交给后续成员。最终报告仍只呈现经理综合。
- 复用原生 Run 等待、检查点和恢复；已接受的问答不会在恢复后重复派员。没有新增宿主 Agent 控制接口。
- 抽出共享成员交接与等待逻辑到 `members.js`，避免主流程与 QA 复制同一套执行代码。

主要文件位于 `sesame/plugins/optional-api-v1/packages/investment-research/`：`team.js`、`runtime.js`、`members.js`、`qa.js`、`index.js`、`capabilities.json`、`README.md`、`prompt.md`。同步更新声明锁文件及三份投资研究测试文件。另修正本地截图脚本的 iframe 高度与合成等待，避免长截图下方出现白块；没有改报告内容。

## 同题真实运行

原样问题：**研究纳斯达克指数未来三个月的趋势，给出综合判断和依据，并生成研究报告。**

- 模型：全部使用已配置的 OpenAI `gpt-6.1-sol`，thinking medium。
- 区间：2026-10-18 至 2027-01-18。
- 成功运行：`run-2`，2026-10-18 15:07:02 至 15:39:41 UTC。
- 8 名原成员全部完成，另有 2 个原研究员 QA 回答 Run。多空各自主动提问一次，不是强制讨论两轮。
- 没有父侧提供金融证据、网址、历史案例、搜索结果或方向结论。没有特别要求历史比较；没有执行交易。

| 问答 | 补充了什么 | 怎样改变推导 |
| --- | --- | --- |
| 多头 → 基本面 | 追问已实现增长能否支持未来三个月。研究员取得 NVIDIA 官方下一季营收和毛利率指引、Microsoft 商业剩余履约义务，并区分公司指引、市场一致预期和预期修订。12 条工具调用记录。 | 多头把经营延续性作为条件性修复依据，但承认公开指引可能早已计价、合同期限与兑现不明、没有证明市场预期上修；未升级成无条件上涨预测。 |
| 空头 → 新闻 | 追问通胀是否广泛持续、弱就业下是否存在前瞻政策依据。复用 CPI 全文并补读完整 FOMC 纪要，核对核心、住房、服务分项及会议/发布日期。8 条工具调用记录。 | 空头接受实际利率下降的反证，区分局部黏性与全面持续加速；承认旧会议未观察到后来的就业和 CPI，不能据此直接推出当前持续紧缩和折现率上升。 |

两次回答均进入多空主论证、信心判断与反证条件。经理读取全部结果和 QA 后给出：**震荡整理、回撤风险仍在，同时保留盈利支撑下的条件性修复**。经理没有重新抓取金融资料；只读取既有证据并制作、发布、检查报告。

与上一轮相比，改善是从“指出缺口”发展到“定向提问、原研究员补证、修订论证”。微软现金流同比比较来自本轮初始研究，不能归功于 QA；完整 FOMC 纪要是本轮新闻包的补充，但上一轮研究整体已用过它，不能声称是相对上一轮新发现的来源。能确认取证与推导质量改善，不能由一次运行证明预测准确率提高。

## 局限与实际干预

1. 初次尝试 `run-1` 因将 Reddit 当成必需来源、将研究截止时点误解成必须已提前采集而暂停，已取消并保留证据。修正通用提示词后才启动 `run-2`：可在已授予来源中选择；一个可选来源不可用不等于整类证据不可用；当前研究可在启动后获取已发布材料并记录真实获取时间，历史研究仍须核验当时可知版本。
2. `run-2` 中一条 Microsoft 网页请求的 HTTP 404 被宿主升级为工作流中断，父侧对同一 Run 执行了一次运行恢复，没有提供替代网址或研究内容。研究员自行继续取证。因此本轮不能称为完全无人干预；单个失败网址触发整个工作流暂停仍是运行时限制。
3. 本轮价格只取得 10 月 15 日收盘，缺少 10 月 16 日及 OHLCV；上一轮曾取得更晚的 Yahoo OHLC，因此行情覆盖并非全面改善。
4. 当前指数估值、可比盈利与现金流预期修订、AI 投资回报及订单兑现期限仍不完整；个别权重公司的结果不能代表完整指数。没有用追问次数或口头一致掩盖这些缺口。
