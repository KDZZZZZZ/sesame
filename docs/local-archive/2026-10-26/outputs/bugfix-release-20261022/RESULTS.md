# Sesame 本轮修复与当前运行状态 · 2026-10-22

当前程序仍使用 release/win32-x64-agent-messages-20261020/win-unpacked/Sesame.exe，已更新其中的宿主运行文件、前端构建和正式安装的插件。沿用原 Sesame 配置目录与 workspace。

## 当前版本与核心修复

- **CCXT 2.0.8**：按用户最新要求，正常轮询恢复为 **1 秒**（每次读取结束后的等待时间），初始快照立即发起。目录和内部 descriptor 使用同一常量。
- **共享请求处理**：撤掉 2.0.7 新加的 Kraken 2000 ms 覆盖值，沿用 CCXT 原有限速。复用 Python CCXT 实例，保留共享冷却及持续成功后逐步恢复；没有增加新的接口或配置项。
- **限流界面**：有实际 K 线时，订阅、历史初次补数和增量历史请求的 RATE_LIMITED 都不显示原始错误与手动重连。历史请求保留 ApiError.code；仅历史补数限流不会把 live 订阅改成 stale。对应请求成功后清理诊断。
- **错误可见性**：健康回执保留诊断，其他类型的指标、数据或协议错误仍正常显示；多个错误并存时不会被限流遮住。没有可显示数据时沿用既有错误处理。
- **MT5 2.1.11**：连接诊断先检查配置指向的终端进程；连接拒绝不直接等同于终端关闭。mt5_trading_permissions 补齐顶层 type: object，保留原 anyOf 严格分支，修正切换 DS 后的工具 schema 校验错误。
- **插入消息连续性**：成功在安全点插入的用户消息接续同一回复，保留消息顺序、工具过程与折叠/展开显示；普通排队和显式重试保持原有边界。
- **历史完整性文案**：删除前端自行合成的“来源未证明历史区间完整……”提示；缓存对完整区间的判定没有放宽。
