## 修正的接口与指引

1. plugin_create、plugin_install_catalog 的 command_id 声明现在与实现一致：16–128 位字母、数字、下划线或连字符。
2. 目录 update 必须传 expected_digest；默认或显式 install 不接受它。plugin_read 的 resource 分支必须传 path。
3. 删除目录回执中让 Agent 调用不存在的 rollback 工具的指引。
4. 宿主加载失败现在指向 plugin_inspect，不再建议无效的 plugin_read(part:"status")。
5. 配置统一入口使用 configuration_integration_catalog/check/apply；host.configuration.* 是能力 ID，不是第九个端口。
6. 原生包的安装检查不执行作者的全部业务测试；MCP 工具目录检查也不能代替业务验收。

有效输入和运行行为保持不变；只将原来运行时就会拒绝的参数准确写入 schema。Data Access 的 8 个执行契约、报告执行契约、宿主 Agent/Run 接口均未改动。
