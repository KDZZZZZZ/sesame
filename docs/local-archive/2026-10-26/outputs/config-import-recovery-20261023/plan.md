# 配置恢复与权限简化

用户要求：检查当前最新构建的 MCP 配置导入失败，减少停下来要求用户操作的情况；本地权限更自由、逻辑更简单。

1. 保存当前脏工作区的待改文件。用回归用例证明已启用插件无需额外授权即可使用声明的本地能力；显式关闭仍有效，升级保留开关，外部消息来源授权仍独立。
2. 在现有 PluginAuthority 内统一默认值，复用现有消息查询和配置接口；不增加 receipt 接口、权限旁路或第二套凭据存储。设置页和契约文档同步说明默认行为。
3. MT5 继续使用私有配置引用，修正来源字段与当前消息投影不一致的问题，保留会话、来源、过期及密钥隔离检查。更新通用和 MT5 提示，配置请求应完成发现、保存、必要恢复及连接验证，不重复索取已给信息。
4. 使用隔离插件组装目录进行权限、导入、配置、提示词回归，检查前端类型和构建。保存精确差异，不混入其他已有改动。
5. 确认实际运行的数据目录及空闲状态，备份后更新当前构建，继续使用同一数据。让真实模型继续已有配置导入及连接验证，不代替它配置，不进行交易或恢复历史暂停任务。

完成依据：权限默认行为测试通过；有效安全引用能够导入且密钥不进入模型/历史；被关闭权限及无效来源仍被拒绝；当前构建的真实模型能够继续配置而不重复要求用户授权。连接或本机外部条件仍有问题时记录实际结果，不宣称连接成功。
