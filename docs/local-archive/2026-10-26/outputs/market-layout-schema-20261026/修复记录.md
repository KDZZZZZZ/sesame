# 布局切换触发行情订阅校验过载

## 原因

图表进入或离开可见区域会增减实时频道，现有前端会在 40 ms 内合并变化并重建多频道连接。普通尺寸变化不会逐帧重建订阅。

宿主此前为每次行情绑定、订阅和历史读取生成整个插件配置目录。MT5 有 22 个配置字段，即使只需确认少数账户/连接字段，也会读取无关配置，并额外并行校验 12 个字符串能否清空。取消布局请求时，取消信号也未传入配置读取。短时过载之后，行情恢复列表遗漏了 Schema 服务的临时故障，导致受影响频道不自动恢复。

## 修改

- 配置预检只读取能力声明所需的字段及其配置来源，不生成设置界面的清空状态和字段描述。
- 传递取消信号，使失效布局请求及时结束预检。
- Schema 临时过载、超时和 worker 故障使用已有的逐频道退避恢复；其他正常频道继续工作，关闭频道会取消待执行的恢复。
- 保留凭据要求、配置语义、校验预算、插件接口和前端布局行为。
