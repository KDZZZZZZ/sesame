# MT5 交易权限入口修复

用户已授权模拟交易、策略挂载和权限配置。本次根因证据：已连接的 demo 账户非只读，MCP 交易权限为 true，终端 experts_trade_allowed 为 false；Python trade_allowed=false、tradeapi_disabled=false。不能将终端算法权限拒绝称为账户不能交易。

1. 在 MT5 插件增加主 Agent 能力 `mt5_trading_permissions`：read 分层读取真实权限；enable 使用稳定命令 ID、配置版本和已绑定账户，复用现有 `prepareTerminal`，不修改宿主或增加依赖。
2. 正常重启仅沿原有空闲、空仓、无挂单/EA检查；已启用不重复重启。主 Agent 沿用用户已有授权。保存前后权限、账户和错误的脱敏回执；失败或状态未知不得重放同一命令。
3. 声明真实配置依赖，更新能力、主入口与使用说明。原生 MCP 授权、券商限制、Python API 禁用、行情新鲜度仍分别诊断；本入口只解决可验证的算法交易准备，不伪称所有开关都已打开。
4. 用隔离 fixture 验证主会话限制、CAS、幂等、并发、账户变更和未生效失败；复用真实终端准备回归。安装包通过正式插件管理更新，保留原模型/账户/14暂停/其它插件。
5. 用正常聊天让真实 Sesame Agent 调新能力完成当前已授权终端的权限准备、重复命令检查和读回。根助手不代替 Agent 操作交易业务；本次不自动重放旧订单。保留准确的现场结果。

改动前已冻结 12 个受影响文件的当前工作区内容。后端和其单元测试由有界子任务负责，注册/声明/提示词、整体验证、安装与现场验收由主助手负责。只提交本轮能独立归因的差异，不纳入其它未提交工作。
