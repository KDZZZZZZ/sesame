Sesame 0.2.4 keeps interrupted work bound to the same Agent and Run, hides internal collaboration messages from the user conversation, and shows explicit Agent workflows separately from ordinary Agent history. Reports stay in the same window, render Markdown, and retain their original task binding.

The release adds explicit Windows/Linux update notifications, verified downloads and idle-only restart installation while preserving user data. Ordinary quit remains graceful after an update shutdown timeout, and late Agent pumps cannot access a closed store. Configuration and credential updates use declared capabilities; the updated plugins support explicit MT5 terminal launch and preserve read-only analysis and risk calculations. Obsolete run failure/budget restrictions are removed. Core/test plugin locks pin source 4e153a4474285e162d88a484d517fa37283a465c and the dev.6 distribution.

Schema validation waits for the Worker to initialize before starting the existing three-second execution deadline, preventing startup load from misclassifying valid plugins as invalid. Configuration test fixtures release their resources when initialization fails, so CI reports the original failure instead of hanging.

Validation: all 167 original host test files executed; after fixes and reruns, 1,161 cases have passing evidence and 10 explicit live/native environment checks were skipped. This is not a claim that the first full run passed. Six UI regression scripts, OpenAPI validation, frontend lint/typecheck/build, targeted shutdown regressions and independent source review passed. The final plugin changes passed 64 relevant tests. The schema and fixture repair passed 76 targeted cases with no skips, including the new Worker lifecycle regression and the existing expensive-regex deadline. The long-loop test also passed locally (34 tool calls, at least 35 turns, 54.6 seconds); its test-runner deadline now allows slow Windows runners to finish without changing any behavior assertion or runtime budget. Native Windows x64, Linux x64 and macOS arm64 builds and extracted-installer checks are tracked in [the final candidate run](https://github.com/KDZZZZZZ/mt5agent/actions/runs/39059008826) and must pass before publication.

Published 0.2.3 users need the installer for this first updater-enabled version; subsequent Windows/Linux updates use the new channel. This release does not automatically restart users' running tasks.
