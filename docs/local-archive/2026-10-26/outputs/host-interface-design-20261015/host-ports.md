## 作用域与共同边界

`host.scope = {kind, conversationId, runId}`；`kind` 为 `service / main / subagent`。下表用 **S/M/A** 表示这三种作用域。标注“会话”表示要求仍开放的 Agent 会话，因此不包含 service。`allowedConversation` 允许 S/M 访问任意目标会话，A 只能访问自身或直接子会话。上下文创建时固定 runId；涉及子任务提供方和 worker 时还检查它仍为当前 Run。证据：[context.js:53](E:/brief2great/sesame/mt5agent/modules/plugins/context.js:53)。

宿主对大多数命名空间套上 `assertLive` 与异步失败观察器；这会记录 `plugin.host_call.failed`，保留原 Promise/错误。它不替插件 `await`，也不表示任意方法都支持 AbortSignal。`svl` 是纯函数端口；长期 callback 应捕获插件自己的持久运行对象，不能保存过期调用 host。证据：[context.js:85](E:/brief2great/sesame/mt5agent/modules/plugins/context.js:85)、[context.js:232](E:/brief2great/sesame/mt5agent/modules/plugins/context.js:232)、[tool-contract.js:54](E:/brief2great/sesame/mt5agent/modules/plugins/tool-contract.js:54)。

`host.providers.call/subscribe` 的 method 不能是任意后端动作。实际注册仅允许两个只读契约；声明 capability 才可调用。证据：[protocol.js:4](E:/brief2great/sesame/mt5agent/modules/plugins/protocol.js:4)、[protocol.js:12](E:/brief2great/sesame/mt5agent/modules/plugins/protocol.js:12)。

| 契约 | 一次性读取方法 | 订阅方法 |
| --- | --- | --- |
| sesame.market | searchInstruments、describeInstrument、queryBars、queryTicks、readExtension、queryExtension | subscribeQuotes、subscribeBars、subscribeExtension |
| sesame.account | listAccounts、snapshot、queryPositions、queryOrders、queryFills、queryHistory、readExtension、queryExtension | subscribeAccount、subscribeExtension |

订阅句柄的 `.snapshot` 内有 subscriptionId/at/snapshot/resumeToken/recovery/consistency，`.ready(emit)` 开始增量，`.close()` 释放。seq 为字符串整数，stream/epoch改变、序号缺口或同eventId不同内容都会要求重新同步。当前实现返回的对象还携带 registry内部 `entry`/bindingId；制定规范应固定消费侧稳定字段，勿把 `entry.implementation` 等内部对象写成可依赖的宿主能力。证据：[providers.js:254](E:/brief2great/sesame/mt5agent/modules/plugins/providers.js:254)。

`sesame.indicator / sesame.report / sesame.strategy` 在协议常量里存在，但方法表为空，靠 artifacts 与 records 表达产品成果；当前没有通用 `providers.order/compile/backtest/deploy`。
