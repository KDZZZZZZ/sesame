Additional verified distinctions already checked by the parent:

- `latest_summary_line` scans nonempty reasoning lines in reverse, skips HTML-comment starts and strips heading/bold syntax. It feeds the live bottom status row, not a persistent tool-group title. The last useful header survives tools and later empty reasoning items. [Source](https://github.com/openai/codex/blob/01fc69f4026735edfdf6789820549727a4867b11/codex-rs/tui/src/chatwidget/streaming.rs#L9-L23), [header updates and finalization](https://github.com/openai/codex/blob/01fc69f4026735edfdf6789820549727a4867b11/codex-rs/tui/src/chatwidget/streaming.rs#L302-L381).
- Hidden reasoning can be retained inside an existing compatible exploration/computer group without splitting its compact presentation. Thus each new thought is not automatically a new tool group. [Source](https://github.com/openai/codex/blob/01fc69f4026735edfdf6789820549727a4867b11/codex-rs/tui/src/chatwidget/activity_groups.rs#L7-L40).
- While assistant lines stream, the bottom working indicator is hidden to avoid duplicate in-progress affordances. After a commentary item completes, it is restored only if the turn is still running and stream queues are drained; final-answer completion clears that restore flag. [Source](https://github.com/openai/codex/blob/01fc69f4026735edfdf6789820549727a4867b11/codex-rs/tui/src/chatwidget/streaming.rs#L163-L184), [phase handling](https://github.com/openai/codex/blob/01fc69f4026735edfdf6789820549727a4867b11/codex-rs/tui/src/chatwidget/streaming.rs#L407-L481).

Sesame's confirmed first-sentence group title, every nonempty thought starting a phase, and completion-level View process disclosure are deliberate product rules and should not be attributed to Codex TUI. Keeping real assistant message boundaries and preventing duplicate live-status indicators are shared ideas.
