# 信息获取插件可用性审计

目标：用真实、只读请求验证现有信息获取能力，修复可恢复问题，让 Agent 通过明确的注册能力组合来源与解析；只有无法可靠提供其宣称功能的入口才考虑删除。

1. 分别审计金融研究、网页/订阅解析、行情适配器；区分代码错误、网络故障、缺配置、套餐限制和时间覆盖不足。
2. 为确定的接口缺陷补回归，优先复用现有能力和资源引用，保持能力正交；不新增重复入口、不绕过访问限制。
3. 研究投资实践采用的真实信源，优先官方披露、原始统计和有来源的研究；记录信息用途、接入方式、费用与限制。
4. 在隔离目录中重跑真实获取与组合；不执行交易，不复制凭据，不修改用户历史，不发布或替换安装版。
5. 汇总逐项验证证据、改动、配置要求和残余限制。代码及依赖声明变更同步相关锁条目，保留其他未提交工作。

通过标准：可用结论有此次真实请求支持；不可用结论有明确原因；关键修复有针对性回归与实际复测；自动解析大正文不需要 Agent 手工搬运全文。
