# Sesame 插件总表（含 Dev）

排序口径：当前插件与历史插件分别按源码行数降序排列，同值按插件 ID 排序。源码行数：非空、非纯注释行。计入运行时模板及自有 MQL SDK；排除测试、示例、检查脚本、文档、配置清单、依赖和构建产物。 HTML 内嵌脚本和样式按物理行去重；未追溯计入宿主及其他插件的代码。

按 2026-10-14 当前 Sesame 工作区整理，已去掉“适用范围”列。共 55 个当前插件：9 个核心、46 个可选；另附 13 个历史独立名称的归并表。

状态依据当前 `development` 安装目录：32 个插件已收录，其中 MT5、QMT、Agent 手动交易的 Dev 源码版本高于目录；23 个源码新增尚未进入当前目录。目录收录、已安装与实际运行验收是不同状态。本表总结源码和现有验证记录，未在本次盘点中运行交易或逐个安装插件。

“使用的宿主接口”已改为插件实现实际调用的 HostContext 方法和宿主桥。`host.x.{a,b}` 表示 `host.x.a` 与 `host.x.b`；属性读取单独标注。SDK 模块名省略统一的 `@sesame/plugin-sdk/` 前缀，模块导入与运行时宿主调用分开。Node 内置库、外部交易 SDK 和插件自身工具名不计作宿主接口。

10 个纯 Skill 插件没有直接 HostContext 调用；4 个 Python MCP 插件由宿主经 stdio/JSON-RPC 调用，不反向调用 host.*。历史工厂用到的 runtime、box 等私有接口单独保留；归档缺失的桥实现不推测。

18 个 ABU 插件都是可修改研究基线：原生工具保存输入与结果数据集；包内 CLI 输出 JSON，报告展示复用 reports。它们不自动下载行情或下单。
