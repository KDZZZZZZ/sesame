# 思考阶段分组修复

用户规则：没有新思考的工具追加到前面相邻的思考分组，不新增操作摘要行。后续明确覆盖：正文更新作为分界，之后操作另起组。

1. 先用回归锁定：上下文整理和同轮内部续接不拆分工具阶段；新的非空思考、正文或真实用户输入分隔；开头无思考不能倒借后面的标题。
2. 修改现有分组与思考标题归属规则。继续使用原始工具 ID、独立展开缓存和首段第一句标题，不新增模型请求或分类推断。
3. 工具在阶段摘要中按原先后汇总，公开正文仍独立显示。各显示模式使用相同工具归属。完成后的外层折叠保留。
4. 运行相关单元、类型、lint、构建和界面回归。通过后仅更新当前 E 盘实例的前端资源，保留正在运行的任务和数据。

范围：仅对话展示和回归测试，不改宿主、模型、插件、账户或历史记录。
