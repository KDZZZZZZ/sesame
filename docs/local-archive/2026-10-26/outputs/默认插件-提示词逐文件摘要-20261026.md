# 默认插件提示词 · 逐文件摘要

核对日期：2026-10-26。按当前官方源码的 `default_state: mounted` 统计，共 9 个默认挂载插件、22 份默认注入文件：9 个 prompt.md、13 个 SKILL.md。当前包未将这 13 个技能设为禁止自动调用。Ultra 自 1.0.3 起默认挂载；这不代表自动开启 Ultra 模式，也不覆盖用户已有的显式停用设置。

## 是否直接进入上下文

**是。在正常的默认主会话中，下列 22 份文件都会全文进入系统提示词，不是只加载名称与摘要，也不会先根据本轮问题筛选。** 因此，普通市场问答也会携带插件开发、产品使用、报告、策略、记忆和 Ultra 使用指南。

- prompt.md 以插件提示词正文加入；SKILL.md 的完整入口文件由宿主放入 plugin-skills 段。
- references、示例、模板及其他 reference 资源不因挂载而全文加入，Agent 需要时再读取。文件名不是唯一依据，实际取决于插件声明的资源种类。
- 用户禁用、依赖不可用、插件加载失败或子 Agent 未选入该插件时，不保证加载；默认挂载不代表每个子 Agent 都得到全部内容。
- 工具的用途说明、参数 schema 和动态记忆索引另行提供，不计入这 22 份文本。
- 默认随包提供和默认挂载不同：canvas-control、configuration 的默认状态为 discoverable，不计入这 22 份；会话后来主动加载的其他插件也不在本次默认清单内。

22 份文本合计约 48,272 个字符（统一换行后统计，包含入口元信息；这是字符数，不是 token 数）。
