fix(workflow): restore a missing report binding when resuming

A report-name collision can fail after an execution session has been saved.
Resuming then skipped report reservation, leaving downstream parent report
delivery unbound. Check the actual report binding before reusing that session.
Preserve an existing binding even when its report has moved.
