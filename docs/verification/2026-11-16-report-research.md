## OpenAI订阅实测

使用用户已有 OpenAI 订阅的 `gpt-6.1-sol`，在隔离工作区完成财报前瞻、财报点评、AI用电需求与股东价值三个问题。模型自行查询/读取方法并调用真实插件发布报告；三份初始报告均取得 `rendered` 回执，两种视口无诊断。

实测发现：第三题虽要求决策树，模型初次仍用文字列表呈现。已在短 Prompt 明确点名图形应发现并使用相应组件；同题复测实际调用 `chart.decision-tree` 并通过真实渲染。复测中曾有一次模型请求超时，重试完成。另修正 Markdown 引用/深层标题字号、公式作者字号/颜色、逻辑节点重复明细，防止受控组件重新产生额外小字。

按用户后续要求，统一组件样式不再自动显示章节和推理步骤的“01、02”装饰序号。报告与回答使用同一规则，正文标题和数据值保持原样；既有浏览器用例同时覆盖普通页面与宿主重建根节点后的显示。

本轮收尾重新执行组件、正文和视觉边界48项，以及方法、清单、发布和契约43项，均通过。另从原模型调用重新渲染三份 `*-unnumbered.html/png` 预览，确认无自动序号和浏览器错误；原调用记录与固定报告未改写。预览回执为 `unnumbered-preview-receipts.json`。
